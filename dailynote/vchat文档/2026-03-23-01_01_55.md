# VCPdesktop CSS样式体系
## 入口文件：desktop.css (1.31KB)
通过@import引入9个模块化CSS文件，加载顺序：基础→组件→主题覆盖。
```
@import './css/base.css';           ← 全局重置、壁纸层、标题栏、画布
@import './css/widgets.css';        ← 挂件容器、施工态、动画
@import './css/shortcuts.css';      ← 桌面快捷方式图标
@import './css/ui-components.css';  ← 状态指示器、右键菜单、收藏模态窗
@import './css/sidebar.css';        ← 侧栏面板、分页、收藏/预设卡片
@import './css/dock.css';           ← Dock栏、应用抽屉、排序指示器
@import './css/icon-picker.css';    ← 图标选择器面板
@import './css/settings.css';       ← 全局设置面板、壁纸配置
@import './css/theme-overrides.css'; ← 浅色主题适配（必须最后！）
```
## 主题继承
desktop.html引入../styles/themes.css → 获得CSS变量体系(--primary-text, --border-color, --highlight-text等) → 所有CSS使用var()引用 → 桌面与主窗口共享设计语言。

## 1. base.css (5.17KB) — 基础样式
### 全局重置
* box-sizing:border-box，html/body 100%宽高 overflow:hidden
### 壁纸层
- #desktop-wallpaper-layer: fixed全屏, z-index:0, pointer-events:none(事件穿透)
- 三种壁纸class: .desktop-wallpaper-image(background-image cover), .desktop-wallpaper-video(居中cover), .desktop-wallpaper-html(iframe, opacity:0→loaded时1)
- 渐入动画: wallpaper-fade-in 0.8s(图片/视频), opacity transition 1.2s(HTML壁纸更慢)
- body.desktop-custom-wallpaper-active: 隐藏themes.css壁纸
### 沉浸式标题栏
- #desktop-title-bar: fixed top, z-index:9999, -webkit-app-region:drag
- 默认opacity:0.15, hover时opacity:1 — 几乎透明的沉浸式设计
- 背景: linear-gradient(rgba(0,0,0,0.4)→transparent) + backdrop-filter:blur(4px)
- 关闭按钮hover: #e81123(Windows红)
### 画布区域
- #desktop-canvas: fixed全屏, z-index:1
### 冻结样式
- body.desktop-frozen *: animation-play-state:paused + transition:none
- .vcp-widget-frozen *: 同上(挂件级)
- .vcp-dock-frozen .desktop-dock-icon-img: 暂停Dock图标动画
---
## 2. widgets.css (4.68KB) — 挂件样式
### 挂件容器
- .desktop-widget: absolute, min-width:120px, min-height:60px, border-radius:12px
- **contain: layout style** — CSS性能优化，防止挂件样式影响外部
- hover: box-shadow 0 4px 20px
### 关闭按钮
- 默认全透明(rgba 0.0), widget hover时出现(rgba 0.6)
- 施工态中pointer-events:auto(可关闭正在渲染的挂件)
### 抓手带(grip)
- 默认6px高全透明, hover时8px+微光gradient, active时grabbing光标+更亮
### 施工态动画
- @keyframes desktop-construction-breathe: 蓝色box-shadow呼吸(2s循环)
- ::after伪元素: 12px旋转spinner角标(0.8s/圈)
- pointer-events:none(施工中不可交互)
### 进入/移除动画
- entering: scale(0.9)+translateY(10px)→normal, 0.4s cubic-bezier
- removing: scale(1)→scale(0.85)+opacity:0, 0.3s ease-out

## 3. shortcuts.css (2.82KB) — 桌面快捷方式图标
- .desktop-shortcut-icon: 72px宽, z-index:5, 图标40px+标签10px
- hover: rgba白色背景, selected: 蓝色背景+outline
- 启动动画: @keyframes desktop-shortcut-launch scale(1→0.85→1.1→1) 0.6s
- 图标类型: img/emoji/svg/placeholder, 均带drop-shadow
- 标签: text-shadow投影增加可读性
---
## 4. ui-components.css (5.5KB) — 通用UI组件
### 状态指示器
- fixed bottom-right, z-index:9998, backdrop-filter:blur(10px)
- 三色圆点: 默认橙(#ff9800), connected绿(#4caf50+glow), streaming蓝(#2196f3+呼吸)
- hidden: opacity:0 + translateY(10px)
### 右键菜单
- fixed z-index:10000, backdrop-filter:blur(16px) saturate(1.5)
- 显示: scale(0.95)→scale(1) + opacity 0.15s
- danger项: #ff6b6b颜色 + 红色hover背景
### 收藏模态窗
- fixed z-index:10001, backdrop-filter:blur(4px)
- 模态框: 340px宽, scale(0.95)→scale(1)进入动画
- 输入框: focus时蓝色border+glow, error时红色border+shake动画(0.4s)
---
## 5. sidebar.css (11.69KB) — 侧栏面板
- 280px宽, translateX(100%)→0滑入, cubic-bezier(0.4,0,0.2,1)
- 分页标签: active时蓝色下划线
- 收藏卡片: 120px缩略图+名称+操作按钮, hover放大阴影
- 官方挂件卡片: 36px emoji图标+名称+描述
- 布局预设: 保存按钮+空白预设(虚线边框), 默认预设金色徽章
- 滚动区域上下渐变遮罩: ::before/::after伪元素linear-gradient
- 底部设置按钮: 固定在侧栏底部
---
## 6. dock.css (10.43KB) — Dock栏
- fixed bottom居中, z-index:9995, backdrop-filter:blur(28px)
- 图标hover: translateY(-6px) scale(1.1) — macOS风格弹起效果
- 拖拽排序插入线: 2px蓝色竖线+脉冲动画
- 图标尺寸: CSS变量--desktop-dock-icon-size(默认32px)
- 应用抽屉: fixed全屏蒙层+480px面板, bottom:80px, 搜索框+列表
- SVG图标: currentColor主题适配
---
## 7. icon-picker.css (6.93KB) — 图标选择器
- 560px面板, grid布局(auto-fill minmax(68px,1fr))
- 图标cell: 72px高, hover/selected样式, 类型徽章(top-right)
- HTML图标预览: 36px容器(Shadow DOM渲染)
- 分页: 上一页/下一页按钮+页码

## 8. settings.css (9.81KB) — 全局设置
- 420px面板, 分section(壁纸/窗口行为/Dock栏)
- Toggle开关: 40x22px, checked时蓝色滑块
- 数值选择器: ±按钮+居中数字
- Range滑块: 100px宽, 蓝色thumb 14px圆形
- 壁纸预览: 120px高预览框+类型徽章+选择/清除按钮+滤镜滑块

## 9. theme-overrides.css (12.49KB) — 浅色主题
**最大的CSS文件**，覆盖暗色主题下所有组件的颜色。
body.light-theme下的完整适配：
- 标题栏: 白色渐变背景, 深色文字/图标
- 挂件grip: 黑色gradient
- 状态指示器: 白色背景
- 右键菜单: 浅灰背景+深色文字
- 模态窗: 浅色背景
- 侧栏: 白色半透明背景, 渐变遮罩用浅色
- Dock: 白色半透明+浅色阴影
- 桌面图标标签: 白色text-shadow(暗色背景下用黑色)
- 图标选择器: 全部浅色适配
- 全局设置: 全部浅色适配
- 壁纸设置: 全部浅色适配
