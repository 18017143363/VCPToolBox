# zIndexManager.js + dragSystem.js — VCPdesktop空间管理
## zIndexManager.js (4.66KB) — 层级管理
### 文件信息
| 属性 | 值 |
|------|-----|
| 路径 | E:\VCPCHAT\Desktopmodules\core\zIndexManager.js |
| 大小 | 4.66KB |
| 职责 | 管理挂件和桌面图标的z-index层级 |
| 导出 | bringToFront, sendToBack, moveUp, moveDown, allocate, peekNext |
| 全局挂载 | window.VCPDesktop.zIndex |
### 层级规则
```
z-index 1~4   : 置底区域（sendToBack后的挂件）
z-index 5     : DESKTOP_ICON_Z — 桌面快捷方式图标固定层级
z-index 10+   : 普通挂件层级（递增分配）
```
### 接口详解
| 方法 | 功能 | 实现 |
|------|------|------|
| bringToFront(el) | 置顶 | nextZIndex++赋值，更新state.nextZIndex |
| sendToBack(el) | 置底 | 找当前最小z-index，设为min-1，下限clamp到1(不低于0) |
| moveUp(el) | 上移一层 | 找z-index刚好大于当前的挂件，交换z-index |
| moveDown(el) | 下移一层 | 找z-index刚好小于当前的挂件，交换z-index(不低于DESKTOP_ICON_Z+1) |
| allocate() | 分配新z-index | 返回nextZIndex++ |
| peekNext() | 查看下一个z-index | 返回nextZIndex但不递增 |
### moveUp/moveDown的查找算法
遍历canvas下所有.desktop-widget元素，收集z-index列表，排序后找到当前元素的相邻元素进行交换。

| 职责 | 挂件拖拽移动 |
| 导出 | startDrag |
| 全局挂载 | window.VCPDesktop.drag |
### 拖拽流程
```
mousedown(grip元素)
  → 记录startX/startY/initialLeft/initialTop
  → 调用zIndex.bringToFront(widget)
  ↓
mousemove(document级)
  → deltaX = clientX - startX
  → deltaY = clientY - startY
  → newLeft = initialLeft + deltaX
  → newTop = initialTop + deltaY
  → 边界限位(clamp)
  → widget.style.left/top赋值
  ↓
mouseup(document级)
  → 移除mousemove/mouseup监听
  → 清空dragState
```
### 边界限位规则
| 方向 | 限制 | 常量 |
|------|------|------|
| 上 | newTop >= 0 (不超出标题栏上方) | — |
| 下 | newTop <= innerHeight - DRAG_MIN_VISIBLE | DRAG_MIN_VISIBLE=40 |
| 左 | newLeft >= -(width - DRAG_MIN_VISIBLE) | 至少40px可见 |
| 右 | newLeft <= innerWidth - DRAG_MIN_VISIBLE | 至少40px可见 |
### 与其他模块的交互
- widgetManager.js：创建widget时在grip元素上绑定mousedown→drag.startDrag()
- zIndexManager.js：拖拽开始时自动bringToFront
- state.js：dragState存储在desktopState中
