# VCPAlarm 插件技术文档

## 概述
VCPAlarm是VChat分布式服务器的闹钟插件，通过双脚本分离设计实现定时提醒。

## 插件信息
| 属性 | 值 |
|------|-----|
| 路径 | VCPDistributedServer/Plugin/VCPAlarm |
| 类型 | synchronous |
| 入口 | python set_alarm.py |

## 架构设计
**双脚本分离模式**：
- set_alarm.py：入口脚本，立即返回
- run_alarm.py：后台进程，等待+GUI

## 核心特性
1. **自然语言时间** - dateparser解析"5分钟后"、"晚上10点"
2. **日夜主题** - 6-18点浅色，其他深色
3. **精美GUI** - 圆角窗口+阴影+呼吸动画+淡入
4. **进程独立** - DETACHED_PROCESS确保闹钟独立运行

## 调用参数
| 参数 | 说明 |
|------|------|
| time_description | 时间描述（必需）|

## 依赖库
dateparser, pygame, Pillow, tkinter

### set_alarm.py 核心逻辑

```python
# 使用DETACHED_PROCESS确保进程独立
if sys.platform == "win32":
    creation_flags = subprocess.DETACHED_PROCESS
subprocess.Popen(command, creationflags=creation_flags, close_fds=True)
```
