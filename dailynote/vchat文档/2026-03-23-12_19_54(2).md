# VCPdesktop核心机制：Shadow DOM隔离 + 脚本沙箱 + 流式渲染

## 1. Shadow DOM挂件隔离

### 核心原理
每个挂件运行在独立的Shadow DOM中，实现CSS/JS完全隔离。widgetManager.js负责创建和管理所有挂件。

### 隔离机制
| 层面 | 隔离方式 | 效果 |
|------|----------|------|
| CSS | Shadow DOM边界 | 挂件A的样式不会影响挂件B |
| JS作用域 | 脚本沙箱闭包 | 每个script在独立闭包中执行 |
| DOM查询 | document代理 | querySelector等方法被代理到Shadow DOM内部 |

### document代理注入
挂件内的script自动注入以下代理：
```javascript
// 挂件内的document已被代理到Shadow DOM
document.querySelector(sel)    // → shadowRoot.querySelector(sel)
document.getElementById(id)    // → shadowRoot.getElementById(id)
document.body                  // → 挂件内容容器元素
```
开发者（或AI）在挂件script中正常写document操作即可，沙箱自动将其限定在当前挂件的Shadow DOM范围内。

## 2. 流式渲染 + 施工态动画

### 流式推送语法
AI在聊天输出中使用特殊语法标记桌面推送内容：
```
<<<[DESKTOP_PUSH]>>>
<div>挂件HTML内容...</div>
<script>挂件脚本...</script>
<<<[DESKTOP_PUSH_END]>>>
```

### 渲染流程
1. chatManager/streamManager检测到DESKTOP_PUSH标记
2. 通过IPC将HTML token逐个发送到desktop.html
3. ipcBridge接收token → widgetManager创建/更新挂件
4. 渲染过程中挂件显示**施工态动画**（呼吸光效）
5. DESKTOP_PUSH_END接收完毕 → 切换为**正常交互态**
6. script标签在内容完成后执行

### 自动尺寸调整
- MutationObserver监听Shadow DOM内容变化
- 异步脚本修改内容后自动触发尺寸重算
- 150ms防抖避免频繁重排

## 3. 挂件内可用API

### vcpAPI — 后端数据访问
```javascript
vcpAPI.weather()              // 获取天气JSON
vcpAPI.fetch('/admin_api/xxx') // 通用后端API（自动Basic Auth认证）
vcpAPI.post(messages, options) // OpenAI兼容chat completion
  // messages: [{role:'user', content:'翻译这段话'}]
  // options: {model, temperature, max_tokens, ...}
  // 返回: {success, content, usage, raw, error}
```
**关键设计**：vcpAPI.post()通过IPC桥接到主进程，主进程持有API URL和Key，挂件内完全不暴露敏感信息。

### musicAPI — 跨窗口音乐控制
```javascript
musicAPI.getState()           // 获取播放状态
musicAPI.play() / pause()     // 播放/暂停
musicAPI.seek(秒数)           // 跳转
musicAPI.setVolume(0-100)     // 音量
musicAPI.send('music-remote-command', 'next')  // 切歌
```
通过IPC与HIFI播放器窗口通信。

## 4. 窗口可见性冻结（visibilityFreezer.js）

### 触发条件
桌面窗口被其他程序遮挡或最小化时自动激活。

### 冻结的6种动画类型
| 动画类型 | 冻结方式 | 恢复方式 |
|----------|----------|----------|
| CSS动画 | animation-play-state: paused | 恢复running |
| Web Animations API | 精确暂停每个动画实例 | 精确恢复 |
| Canvas/rAF | 隐藏canvas阻止GPU渲染 | 恢复显示 |
| Video/Audio | 暂停媒体播放 | 恢复播放 |
| SVG SMIL | 暂停矢量动画 | 恢复 |
| HTML壁纸iframe | 发送冻结消息+visibility:hidden | 发送恢复消息 |
| Dock GIF图标 | CSS暂停 | 恢复 |

### 性能意义
避免被遮挡的桌面窗口持续消耗GPU/CPU资源，对笔记本电池和系统整体性能有显著帮助。
