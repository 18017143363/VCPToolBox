## 三种壁纸类型
| 类型 | 实现元素 | 特性 | 支持格式 |
|------|----------|------|----------|
| image | `<div>` + background-image | cover/center/no-repeat | jpg,png,gif,webp,svg,avif,bmp |
| video | `<video>` | autoplay,loop,playsinline,可控muted/playbackRate | mp4,webm,ogg,mov |
| html | `<iframe>` sandbox | allow-scripts+allow-same-origin,pointerEvents:none | html,htm |
## 壁纸层结构
```
<body>
  <div id="desktop-wallpaper-layer" style="z-index:0">
    ├── [image] <div style="background-image:url(...)">
    ├── [video] <video src="..." autoplay loop>
    └── [html]  <iframe src="..." sandbox="allow-scripts allow-same-origin">
  </div>
  <div id="desktop-canvas" style="z-index:1">  ← 挂件在上层
```
## 核心流程
### apply(config) — 应用壁纸
```
1. 验证config有效性(enabled+source)
2. clearWithTransition(0.4s opacity渐出)
3. 清除旧壁纸元素(video: pause+清src+load释放内存; iframe: src=about:blank)
4. 根据type创建对应元素
5. applyFilters(blur/brightness/opacity)
6. 追加到wallpaperLayer
7. [video] 绑定loadeddata事件→0.3s渐入
8. [html] 绑定load事件→0.5s渐入; 绑定error事件→清除
```
### 滤镜系统
```css
/* applyFilters生成的CSS */
filter: blur({blur}px) brightness({brightness});
opacity: {opacity};
```
### 视频专属控制
| 方法 | 功能 |
|------|------|
| updateVideoSettings(muted, rate) | 实时调整静音和播放速率 |
### 文件类型检测
detectType(source)：先检URL后缀(.mp4→video)，再检文件路径后缀，html/htm→html，默认image
## 内存管理
视频清除时的三步释放：video.pause() → video.src='' → video.load()
iframe清除：src='about:blank' 释放页面资源
## 与其他模块的交互
- globalSettings.js：壁纸设置UI，调用wallpaper.apply(config)
- ipcBridge.js：DesktopRemote SetWallpaper指令，调用wallpaper.apply()
- visibilityFreezer.js：冻结时暂停video/iframe
