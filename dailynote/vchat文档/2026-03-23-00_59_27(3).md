# desktopRemoteHandlers.js — VCPdesktop远程控制处理器
## 文件信息
| 属性 | 值 |
|------|-----|
| 路径 | E:\VCPCHAT\modules\ipc\desktopRemoteHandlers.js |
| 大小 | 22.05KB |
| 职责 | DesktopRemote插件命令处理、Canvas控制、Flowlock心流锁控制 |
| 导出 | initialize, handleDesktopRemoteControl, handleCanvasControl, handleFlowlockControl |
## 设计特点
**不注册IPC监听器**——作为函数导出给VCPDistributedServer调用。这是因为DesktopRemote指令来自分布式服务器而非本地渲染进程。
## 三大处理器
### 1. handleDesktopRemoteControl — 桌面远程控制（4个子命令）
#### SetWallpaper (_handleSetWallpaper)
```
输入wallpaperSource → 判断类型:
  HTML内容(<!DOCTYPE|<html开头) → 保存为AppData/DesktopData/ai_wallpaper_{timestamp}.html → file://URL
  HTTP/HTTPS URL → 按扩展名检测类型(image/video/html)
  file:// URL → 按扩展名检测类型
→ 构建wallpaperConfig →
  桌面窗口已打开: send('desktop-remote-set-wallpaper', config)
  桌面窗口未打开: openDesktopWindow() → 延迟2000ms → send
→ 返回Markdown格式报告
```
#### QueryDesktop (_handleQueryDesktop)
```
桌面窗口未打开 → 返回"未打开"报告
桌面窗口已打开 →
  send('desktop-remote-query') →
  等待IPC响应'desktop-remote-query-response'(5秒超时) →
  生成Markdown报告(活跃挂件表格+桌面图标列表)
```
#### ViewWidgetSource (_handleViewWidgetSource)
```
send('desktop-remote-view-source', {widgetId}) →
等待IPC响应'desktop-remote-view-source-response'(5秒超时) →
返回Markdown报告(收藏信息+HTML代码块)
```
#### CreateWidget (_handleCreateWidget)
```
桌面窗口未打开 → openDesktopWindow() → 等待2000ms
生成widgetId: 自定义或'remote-widget-{timestamp}-{random6}'
send('desktop-remote-create-widget', {widgetId, htmlContent, options, autoSave, saveName}) →
等待IPC响应'desktop-remote-create-widget-response'(8秒超时，超时也认为可能成功) →
返回Markdown报告(含收藏状态和持久化目录)
```
### 2. handleCanvasControl — Canvas控制
```
require('./canvasHandlers').createCanvasWindow(filePath)
```
简单转发，供分布式服务器触发打开Canvas窗口。
### 3. handleFlowlockControl — 心流锁控制
```
get/status命令 → send('flowlock-command') → 等待'flowlock-response'(5秒超时) → 返回结果
其他命令(start/stop/promptee/prompter/clear/remove/edit) → send后立即返回自然语言响应
```
## IPC通信模式
所有远程控制都使用**请求-响应模式**：
1. 主进程通过webContents.send发送命令到桌面渲染进程
2. 注册一次性ipcMain.on监听响应事件
3. 设置超时保护(5-8秒)
4. 收到响应后清除监听器和超时计时器
5. 返回结构化结果(Markdown格式报告)
## 与其他模块的交互
| 模块 | 交互方式 |
|------|----------|
| desktopHandlers | getDesktopWindow()/openDesktopWindow() |
| canvasHandlers | createCanvasWindow() |
| mainWindow | send flowlock-command |
| 桌面渲染进程(ipcBridge.js) | send/receive远程控制IPC |
| VCPDistributedServer | 被调用方(函数导出) |
