[21:10] VCP Code 2.0 重大更新分析 — Kilo Code → Nova Code v1.2.0

## 品牌与架构变化
- **项目名**: kilo-code → **nova-code**
- **上游组织**: Kilo-Org/kilocode → **Nova-Org/novacode**
- **VCP Fork仓库**: https://github.com/DerstedtCasper/vcp-code-2.0.git
- **版本体系**: 从7.0.x重置为1.x.x（当前1.2.0）
- **架构**: 单包 → **pnpm monorepo + turbo**
- **包管理器**: Bun → **pnpm@10.8.1**
- **Node版本**: 18+ → **22.22.0**
- **IDE支持**: VS Code only → **VS Code + JetBrains**
- **命令前缀**: kilo. → **nova-code.**
- **Publisher**: vcpcode → **novacode**
- **i18n**: 16种 → **22种语言**

## Monorepo结构
- src/ — VS Code扩展主体
- webview-ui/ — WebView前端
- packages/（11个）: agent-runtime, core, core-schemas, ipc, types, cloud, telemetry, evals, build, config-eslint, config-typescript
- apps/（7个）: novacode-docs, storybook, vscode-e2e, playwright-e2e, vscode-nightly, web-evals, web-roo-code

## Nova Code Provider 与 VCP 兼容性
| Provider | 端点 | VCP兼容 | 说明 |
|----------|------|---------|------|
| openai | /v1/chat/completions | ✅ | 标准OpenAI |
| openai-compatible | /v1/chat/completions | ✅ | Vercel AI SDK，推荐 |
| openai-responses | /v1/responses | ❌ | OpenAI新Responses API，VCP无此端点 |

连接VCP配置：Provider选openai-compatible，Base URL: http://127.0.0.1:6005/v1，API Key: VCP密钥
