导出: init, show
全局挂载: window.VCPDesktop.saveModal
### 工作流程
```
show(widgetId) → 弹出模态窗 → 预填已有名称 → 聚焦输入框
→ 用户输入名称 → 确认(或Enter)
→ 关闭模态窗 → 延迟350ms(等模态窗消失避免截图包含弹窗)
→ favorites.performSave(widgetId, name)
```
### 交互
- Enter确认，Escape取消
- 空名称时输入框抖动(error class, 600ms)
- 点击蒙层关闭

## iconPicker.js (13.15KB) — 图标选择器
### 文件信息
路径: E:\VCPCHAT\Desktopmodules\ui\iconPicker.js
导出: open, close
全局挂载: window.VCPDesktop.iconPicker
### 功能概述
从assets/iconset/预设文件夹中浏览和选择自定义图标，支持4种图标类型：image(PNG/JPG/ICO/WebP)、svg、gif、html(Shadow DOM隔离)。
### 核心机制
**预设下拉**：electronAPI.desktopIconsetListPresets() → 返回[{name, iconCount}] → 选择后加载该预设的图标
**分页加载**：PAGE_SIZE=60，electronAPI.desktopIconsetListIcons({presetName, page, pageSize, search}) → 返回{icons, total, page}
**搜索防抖**：300ms防抖，搜索文件名
**HTML图标懒加载**：IntersectionObserver检测可见性 → desktopIconsetGetIconData(relativePath) → Shadow DOM(closed mode)渲染预览
**选择回调**：点击图标 → desktopIconsetGetIconData获取完整数据 → callback({relativePath, dataUrl, htmlContent, svgContent, iconType})
### IPC接口
| 方法 | 功能 |
|------|------|
| desktopIconsetListPresets() | 列出所有图标预设文件夹 |
| desktopIconsetListIcons(opts) | 分页列出预设中的图标 |
| desktopIconsetGetIconData(path) | 获取图标完整数据(dataUrl/htmlContent/svgContent) |
