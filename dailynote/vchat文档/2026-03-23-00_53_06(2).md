# favoritesManager.js + thumbnail.js — VCPdesktop收藏系统
## favoritesManager.js (8.19KB) — 收藏管理核心
### 文件信息
路径: E:\VCPCHAT\Desktopmodules\favorites\favoritesManager.js
导出: performSave, loadList, spawnFromFavorite, refresh, deleteFavorite
全局挂载: window.VCPDesktop.favorites
### 5个核心方法
#### performSave(widgetId, name) — 执行收藏
```
1. 生成saveId: 已有savedId则复用，否则'fav_{timestamp}_{random6}'
2. 获取HTML: widgetData.contentBuffer || contentContainer.innerHTML
3. 截图缩略图: thumbnail.capture(widgetData) → dataURL
4. IPC持久化: electronAPI.desktopSaveWidget({id, name, html, thumbnail})
5. 更新状态: widgetData.savedName/savedId标记
6. 刷新侧栏: loadFavoritesList() → sidebar.render()
```
#### loadFavoritesList() — 加载收藏列表
electronAPI.desktopListWidgets() → state.favorites = result.widgets → sidebar.render()
#### spawnFromFavorite(favoriteId, x?, y?) — 从收藏恢复
```
electronAPI.desktopLoadWidget(favoriteId) → 获取{html, name}
→ widget.create(id, {x,y}) → 标记savedId/savedName
→ contentBuffer=html → innerHTML=html
→ processInlineStyles → 移除constructing
→ autoResize → 延迟100ms执行processInlineScripts
```
#### refresh(widgetId) — 刷新挂件(从文件重新加载)
前提：widgetData.savedId存在。desktopLoadWidget(savedId) → 重新填充html → processInlineStyles → autoResize → processInlineScripts
#### deleteFavorite(favoriteId) — 删除收藏
electronAPI.desktopDeleteWidget(favoriteId) → loadFavoritesList()
### IPC接口汇总
| 方法 | 功能 |
|------|------|
| desktopSaveWidget({id,name,html,thumbnail}) | 保存收藏(HTML+缩略图) |
| desktopListWidgets() | 列出所有收藏 |
| desktopLoadWidget(id) | 加载收藏的HTML内容 |
| desktopDeleteWidget(id) | 删除收藏 |

## thumbnail.js (4.34KB) — 缩略图捕获
### 文件信息
路径: E:\VCPCHAT\Desktopmodules\favorites\thumbnail.js
导出: capture, generateFallback
全局挂载: window.VCPDesktop.thumbnail
### 截图策略(双层回退)
| 优先级 | 方法 | 实现 |
|--------|------|------|
| 1 | Electron原生截图 | electronAPI.desktopCaptureWidget(rect) → webContents.capturePage() |
| 2 | Canvas文本预览 | 生成渐变背景+文本内容的Canvas截图 |
### Electron截图注意事项
getBoundingClientRect()返回CSS像素，capturePage()也接受CSS像素，Electron内部自动处理DPR缩放，无需手动乘devicePixelRatio。
### Fallback缩略图生成
```
Canvas绘制：
- 尺寸: 等比缩放到MAX_THUMB=300px内
- 背景: 线性渐变(rgba(40,40,60,0.9)→rgba(20,20,40,0.9)) + 圆角8px
- 文字: widget textContent前100字符，自动换行(逐字符measureText)，最多6行
- 输出: toDataURL('image/png', 0.8)
```
