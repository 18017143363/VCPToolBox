# VCPdesktop — 系统架构总览

## 一句话定位
VCPdesktop是VChat的桌面渲染层扩展，在Electron中创建独立画布窗口，让AI的流式HTML/CSS/JS输出实时渲染到操作系统桌面上。

## 三层架构

| 层级 | 窗口/进程 | 核心模块 | 职责 |
|------|-----------|----------|------|
| 聊天层 | main.html主窗口 | chatManager, streamManager | 流式输出源头，检测DESKTOP_PUSH语法 |
| 主进程层 | main.js | desktopHandlers, handleDesktopRemoteControl | IPC中转站，AI远程控制处理器，认证代理 |
| 桌面层 | desktop.html桌面窗口 | widgetManager, wallpaperManager, dock, sidebar | 渲染画布，挂件管理，壁纸，UI交互 |
| 分布式层 | VCPDistributedServer | DesktopRemote插件 | AI远程操控的数据管道（3个命令） |

## 通信链路
```
用户对话 → AI流式输出含DESKTOP_PUSH的HTML
→ chatManager/streamManager检测到推送语法
→ IPC发送到main.js主进程
→ 主进程转发到desktop.html桌面窗口
→ ipcBridge接收 → widgetManager创建Shadow DOM挂件
→ 实时逐token渲染到桌面
```

AI远程控制链路：
```
AI调用DesktopRemote插件 → VCP云端 → WebSocket → 分布式服务器
→ 插件验证参数输出stdout → 主进程handleDesktopRemoteControl
→ IPC转发到desktop.html → 执行壁纸/查询/源码查看操作
```

## 与VCP插件系统的关系
DesktopRemote插件（分布式端）是AI操控桌面的唯一入口：
- SetWallpaper: 推送壁纸（URL/文件/HTML动态壁纸）
- QueryDesktop: 查询桌面状态（所有挂件ID/收藏状态/路径）
- ViewWidgetSource: 查看指定挂件的HTML源码
- CreateWidget: 创建挂件（v1.2.0新增）

AI维护闭环：QueryDesktop感知 → CreateWidget/SetWallpaper创造 → ViewWidgetSource+FileOperator维护
