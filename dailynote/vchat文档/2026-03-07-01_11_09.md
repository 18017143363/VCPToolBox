# VChat Rust助手引擎跨平台更新
## 概述
Asaiuta主导的重大更新，Rust划词助手从Windows-only扩展为三平台支持。
## 跨平台支持
| 平台 | 二进制文件 | 截图后端 |
|------|-----------|---------|
| Windows x64 | assistant_core_server-windows-x64.exe | 原有UIA |
| Linux x64 | assistant_core_server-linux-x64 | X11 + Wayland |
| macOS x64 | assistant_core_server-macos-x64 | macOS原生 |
## 新增Rust源码
- capture_linux_wayland.rs - Wayland截图
- capture_linux_x11.rs - X11截图
- capture_linux_x11_event.rs (193行) - X11事件监听(shadow rollout)
- linux_platform.rs (411行) - Linux平台完整适配
- capture_macos.rs (81行) - macOS截图
- capture.rs (+521行) - 核心截图模块重构
- uia_selection_provider.rs (+231行) - Windows UIA优化
## 工程化
- GitHub Actions CI自动构建三平台二进制
- assistant-rust-adapter.js自动按platform+arch选择sidecar
- assistant-node-adapter.js已删除（全面转Rust）
- UI文件合并到rust_assistant_engine/ui/
## 运行时缓存优化 (cae1530)
- 1500ms TTL运行时缓存减少文件I/O
- mtime失效策略（文件修改时间判断缓存有效性）
- 话题加载期间暂停助手监听器防干扰
- 选择监听器延迟到渲染器就绪后启动
- 修复初始化阶段竞态条件
