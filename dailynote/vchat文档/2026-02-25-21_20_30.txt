- UI框架: SolidJS (非React)
- 构建: ESBuild + Bun
- 语言: TypeScript
- AI SDK: openai + @anthropic-ai/sdk
- 代码解析: web-tree-sitter (AST)
- Token计数: js-tiktoken
- Git: simple-git
- 数据验证: zod
- 流式: eventsource (SSE)

## VCP专属设置项详解
VCP Code设置面板中的VCP分类包含以下VCP协议兼容性配置：
| 设置项 | 默认状态 | 功能 |
|--------|---------|------|
| Enable VCP Compatibility | 关 | VCP协议总开关 |
| Context Fold Enabled | 关 | 解析VCP_DYNAMIC_FOLD动态折叠块 |
| Context Fold Output | details | 折叠块显示方式(details/plain markdown) |
| Context Fold Start/End Marker | <<<[VCP_DYNAMIC_FOLD]>>> | 折叠块标记 |
| VCPInfo Enabled | 关 | 提取VCPINFO块并弹通知 |
| TOOL_REQUEST Enabled | 关 | 解析TOOL_REQUEST工具调用协议 |
| TOOL_REQUEST Bridge Mode | execute | execute=直接执行/event=仅通知 |
| TOOL_REQUEST Max Per Message | - | 每消息最大自动执行工具数 |

这些设置让VCP Code能理解VCP协议格式，实现工具调用、动态折叠上下文、VCPInfo通知等VCP特有功能。
