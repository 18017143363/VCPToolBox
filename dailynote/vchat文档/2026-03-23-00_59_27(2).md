# DesktopRemote — 分布式端桌面远程控制插件

| 类型 | synchronous (stdio) |
| 作者 | VCPToolBox |
## 架构角色
DesktopRemote是一个**数据管道和验证器**——接收VCP后端的JSON参数，验证+规范化后输出到stdout。实际桌面控制逻辑由主进程的desktopRemoteHandlers.js(注入的handler)处理。
## 4个命令
| 命令 | 必需参数 | 可选参数 |
|------|----------|----------|
| SetWallpaper | wallpaperSource | — |
| QueryDesktop | — | — |
| ViewWidgetSource | widgetId | — |
| CreateWidget | htmlContent | x, y, width, height, widgetId, autoSave, saveName |
## 参数容错设计
**大量同义词支持**，提高AI调用成功率：
```javascript
// command: command/Command/action/Action
// wallpaperSource: wallpaperSource/wallpapersource/WallpaperSource/source/Source/url/URL/content/Content
// widgetId: widgetId/widgetid/WidgetId/widget_id/id/Id
// htmlContent: htmlContent/htmlcontent/HtmlContent/html/Html/content/Content
// autoSave: autoSave/autosave/AutoSave/auto_save
```
命令名也支持多种写法：setwallpaper/set_wallpaper, querydesktop/query_desktop/query, viewwidgetsource/view_widget_source/viewsource, createwidget/create_widget/create
## 工具函数
- _parseNumber(val): 安全数字解析，无效返回null
- _parseBoolean(val): 安全布尔解析，支持字符串'true'

```
default-src 'self' data:;
script-src 'self' 'unsafe-inline';        ← 允许内联脚本(widget需要)
style-src 'self' 'unsafe-inline' https:;  ← 允许内联样式+CDN字体
img-src * data: file: blob:;              ← 图片来源不限
media-src * data: file:;                  ← 媒体来源不限
```
