## 关键技术实现
### isIconValid — 图标有效性检测
解析NativeImage的RGBA位图，采样检测不透明像素比例。
- 大图(>1024px)只采样512个像素点(step=totalPixels/512)
- 不透明像素(alpha>20)占比<5%判定为空白图标
- 防止Windows对UWP/MSIX应用返回全透明/全白图标
### withTimeout — 超时保护
Promise.race包装，getFileIcon可能挂起，3秒超时返回null
### 窗口置底 — Win32原生实现
| 组件 | 实现 |
|------|------|
| bottomHelperProcess | 持久化PowerShell进程，避免每次spawn |
| VCPWinAPI C# | Add-Type定义SetWindowPos P/Invoke |
| nativePushToBottom | stdin写入[VCPWinAPI]::PushToBottom(hwnd) |
| 触发时机 | focus事件(50ms延迟)+定时器(1.5秒间隔) |
| 非Windows | setAlwaysOnTop(true,'screen-saver',-1)→setAlwaysOnTop(false)近似 |
### openDesktopWindow — 桌面窗口创建
```
读取主题设置 → new BrowserWindow(contextIsolation+preload) →
loadURL(desktop.html?currentThemeMode=xxx) →
ready-to-show:
  if autoMaximize → maximize() + 锁定(unmaximize→setImmediate→maximize)
  showInactive()(不抢焦点!) →
  if alwaysOnBottom → 延迟500ms启用 →
  通知桌面窗口+主窗口连接状态
closed:
  清理置底资源(clearInterval+stopBottomHelper) →
  通知主窗口桌面已关闭
```
