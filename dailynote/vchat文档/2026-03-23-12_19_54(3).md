# VCPdesktop UI系统：Dock栏 + 收藏 + 壁纸 + 全局设置

## 1. Dock应用栏

### 功能
底部Dock栏提供应用快捷启动，类似macOS Dock。

### 特性
- 应用抽屉：全屏面板展示所有可用应用
- 拖拽排序：自定义Dock图标顺序
- 可见性管理：控制哪些应用显示在Dock
- Windows快捷方式导入：自动扫描桌面.lnk文件+拖入导入+图标提取
- 桌面快捷方式图标：从Dock拖拽到桌面+双击启动+自由移动

### VChat子应用启动器（vchatApps.js）
10个VChat内部应用注册到Dock：
聊天、笔记、论坛、翻译、骰子、Canvas、音乐、RAG、记忆、主题

### 图标选择器（iconPicker.js）
从iconset预设库选择图标，支持PNG/SVG/GIF/HTML富图标。

### 数据持久化
Dock配置保存在 AppData/DesktopData/dock.json

## 2. 收藏系统

### 工作流
1. 右键挂件 → 选择"收藏"
2. 弹出模态窗（saveModal.js）→ 输入名称
3. 系统自动截取缩略图（thumbnail.js，原生截图）
4. 保存到 AppData/DesktopWidgets/{fav_id}/ 目录
   - widget.html：挂件完整HTML
   - meta.json：元数据（名称、位置、尺寸等）
   - thumbnail.png：缩略图预览

### 收藏侧栏（sidebar.js）
- 3个页签：挂件 / 收藏 / 预设
- 缩略图预览 + 点击恢复 + 拖放到桌面
- 布局预设的保存和加载

## 3. 壁纸系统（wallpaperManager.js）

### 支持的壁纸类型
| 类型 | 说明 |
|------|------|
| 图片 | 静态图片URL或本地文件 |
| 视频(mp4) | 循环播放的视频壁纸 |
| HTML动态壁纸 | 完整HTML页面作为壁纸（iframe渲染） |

### 壁纸调节参数
- 透明度调节
- 模糊度调节
- 亮度调节

### 壁纸切换动画
旧壁纸渐出 + 新壁纸渐入，HTML壁纸加载后1.2s渐入效果。

### AI推送壁纸
AI通过DesktopRemote的SetWallpaper命令推送：
- URL壁纸：直接传图片/视频URL
- 文件壁纸：传本地文件路径
- HTML动态壁纸：直接传HTML代码，系统自动保存为ai_wallpaper_*.html文件

## 4. 全局设置面板（globalSettings.js）

### 设置项
- 自动最大化开关
- 窗口置底开关
- 默认预设选择
- Dock图标大小调节
- 壁纸配置（类型/源/调节参数）

### 布局预设系统
- 保存当前桌面布局（所有挂件位置+尺寸+壁纸配置）
- 加载已保存的布局预设
- 支持设置默认预设（启动时自动恢复）
- 数据保存在 AppData/DesktopData/layout.json

## 5. 其他UI组件

### 右键菜单（contextMenu.js）
7个菜单项：收藏 / 刷新 / 关闭 / 置顶 / 置底 / 等

### Z-Index层级管理（zIndexManager.js）
- 点击挂件自动提升到最顶层
- 手动置顶/置底操作
- 防止层级冲突

### 拖拽系统（dragSystem.js）
- 抓手带拖拽
- 边界限位：防止拖出可视区域

### 主题同步（theme.js）
自动跟随VChat深色/浅色主题切换，引入../styles/themes.css共享CSS变量。

### 独立模式
支持 --desktop-only 参数独立启动桌面窗口，无需VChat主窗口。
