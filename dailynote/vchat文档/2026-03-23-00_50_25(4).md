## 挂件DOM结构
```
div.desktop-widget [data-widget-id] [style="left/top/width/height/z-index"]
  ├── div.desktop-widget-grip                  ← 拖拽抓手带
  ├── button.desktop-widget-close-btn          ← 关闭按钮(×)
  └── div.desktop-widget-content
       └── #shadow-root (open)                 ← Shadow DOM隔离
            ├── <style> :host{...}             ← 基础样式(overflow/scrollbar)
            ├── <style> ...                    ← 提升的widget内联样式(0~N个)
            └── div.widget-inner-content       ← 实际内容容器
                 └── [widget HTML]
```
## 挂件生命周期
### 1. create(id, options?) → widgetData
```
创建widget外壳DOM → attachShadow({mode:'open'}) →
注入基础style → 创建contentContainer →
绑定grip拖拽(drag.startDrag) + close按钮(removeWidget) →
分配z-index → 追加到canvas →
设置位置(options.x/y或智能偏移) →
添加CSS class: constructing(施工态光效) + entering(进入动画) →
注册到state.widgets Map →
创建contentBuffer='' 用于累积流式内容
```
**options参数**：x, y, width, height, savedId, savedName
### 2. appendContent(id, html) — 流式追加
```
contentBuffer += html (累积全量HTML)
contentContainer.innerHTML = contentBuffer (全量替换)
processStyles(shadowRoot, contentContainer)  ← 提升style标签
autoResize(widget, contentContainer)         ← 自动尺寸
```
**processStyles机制**：扫描contentContainer内的所有`<style>`标签 → 移动到shadowRoot级别(insertBefore contentContainer) → 避免style在innerHTML替换时反复解析
### 3. finalize(id) — 流结束
```
移除constructing class(关闭施工态光效) →
processInlineScripts(shadowRoot, id)  ← 执行脚本沙箱
```
### 4. removeWidget(id) — 销毁
```
添加removing class(退出动画) →
等待transitionend(兜底500ms超时) →
从DOM移除 → 从state.widgets删除
```
## 脚本沙箱——核心设计 (processInlineScripts)
### 原理
不使用iframe隔离，而是通过**IIFE(立即执行函数) + 假document代理**实现轻量沙箱：
```javascript
(function(_realDoc) {
    // 定位Shadow DOM
    var _shadowRoot = _realDoc.querySelector(
        '[data-widget-id="xxx"] .desktop-widget-content'
    ).shadowRoot;
    var root = _shadowRoot.querySelector('.widget-inner-content');
    // === 假 document 对象 ===
    var document = {
        querySelector: function(sel) {
            return root.querySelector(sel) || _shadowRoot.querySelector(sel);
        },
        querySelectorAll: function(sel) {
            return root.querySelectorAll(sel);
        },
        getElementById: function(id) {
            return root.querySelector('#' + id);
        },
        createElement: _realDoc.createElement.bind(_realDoc),
        createElementNS: _realDoc.createElementNS.bind(_realDoc),
        createTextNode: _realDoc.createTextNode.bind(_realDoc),
        body: root,  // document.body → widget内容容器
    };
    // === vcpAPI 注入 ===
    var vcpAPI = {
        fetch: function(endpoint, opts) {
            return window.__vcpProxyFetch(endpoint, opts);
        },
        post: function(messages, opts) {
            return window.__vcpProxyPost(messages, opts);
        },
        weather: function() {
            return window.__vcpProxyFetch('/admin_api/weather');
        },
    };
    // === musicAPI 注入 ===
    var musicAPI = {
        play: function() { return _electron.invoke('music-play'); },
        pause: function() { return _electron.invoke('music-pause'); },
        getState: function() { return _electron.invoke('music-get-state')...},
        seek: function(t) { return _electron.invoke('music-seek',t); },
        setVolume: function(v) { return _electron.invoke('music-set-volume',v); },
    };
    // --- widget脚本在此执行 ---
    ${scriptContent}
})(window.document);
```
### 沙箱安全分析
| 操作 | 行为 | 安全性 |
|------|------|--------|
| document.querySelector | 限定在Shadow DOM内搜索 | ✅ 隔离 |
| document.getElementById | 限定在widget内容容器 | ✅ 隔离 |
| document.body | 指向widget内容容器 | ✅ 隔离 |
| document.createElement | 绑定真实document(否则元素无法工作) | ⚠️ 必要妥协 |
| window对象 | 未遮蔽，可访问 | ⚠️ 非完全隔离 |
| vcpAPI | 通过全局代理函数，不暴露凭据 | ✅ 安全 |
| musicAPI | 通过Electron IPC | ✅ 安全 |
**注意**：这不是安全沙箱（widget仍可访问window），而是**便利性隔离**——让widget脚本自然地用document.xxx操作自己的DOM而不影响其他widget。
## 自动尺寸系统 (autoResize)
```
requestAnimationFrame →
  临时: display=inline-block, width=auto →
  测量: scrollWidth, scrollHeight →
  恢复: display原值 →
  计算: clamp(MIN, content+PADDING, innerWidth*MAX_RATIO) →
  应用: 0.15s transition动画调整width/height
```
### MutationObserver自动触发
```javascript
new MutationObserver(() => {
    clearTimeout(debounceTimer);
    debounceTimer = setTimeout(() => autoResize(), AUTO_RESIZE_DEBOUNCE);
}).observe(contentContainer, {
    childList: true, subtree: true, characterData: true
});
```
监听DOM变化(子元素增删/文本变化) → 14ms防抖 → 自动resize。用于处理异步加载内容(如fetch后插入数据)导致的尺寸变化。
## replaceInWidgets(targetSelector, newHtml) — 增量更新
```
遍历所有widget的shadowRoot →
  querySelector(targetSelector) →
  找到匹配元素 → innerHTML = newHtml →
  触发autoResize
```
用于DESKTOP_PUSH的target:语法，通过CSS选择器定位widget内部元素进行替换。
