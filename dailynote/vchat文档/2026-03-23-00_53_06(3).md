# 内置挂件系统 — VCPdesktop builtinWidgets
## 通用模式
所有内置挂件遵循相同的架构模式：
1. JS数组拼接HTML模板(包含style+div+script)
2. spawn函数：检查已存在→widget.create→填充HTML→processInlineStyles→移除constructing→autoResize→延迟100ms processInlineScripts
3. 脚本在沙箱内执行，通过vcpAPI/musicAPI/window.VCPDesktop访问外部能力
4. 导出到window.VCPDesktop.builtin{Name} = { spawn }

## weatherWidget.js (10.19KB) — 天气挂件
builtinId: builtinWeather | widgetId: builtin-weather | 默认位置: (40, 52) | 尺寸: 320×280
### 数据源

- 未来4天预报(daily[1:5])横向滚动卡片
- 30分钟自动刷新(setInterval)

## appTrayWidget.js (12.52KB) — 应用托盘
builtinId: builtinAppTray | widgetId: builtin-appTray | 默认位置: (80, 72) | 尺寸: 340×360(固定)
### 数据源
直接读取window.VCPDesktop.state.dock.items(实时引用)
### 特殊行为：固定尺寸
```javascript
widgetData.fixedSize = true;          // 标记固定尺寸
widgetData._resizeObserver.disconnect(); // 断开MutationObserver
element.style.width/height = '340px/360px'; // 强制尺寸
// 不调用autoResize
```
原因：应用托盘每5秒自动刷新(setInterval)，DOM变更会触发MutationObserver→autoResize导致尺寸不断变化。
### 功能
- 网格布局(grid-template-columns: repeat(auto-fill, minmax(64px, 1fr)))
- 搜索过滤(name匹配)
- 图标优先级: icon > animatedIcon > emoji
- GIF hover播放(同Dock)
- 单击启动: VCPDesktop.dock.launch(item)
- 拖拽到桌面: dragstart设置application/x-desktop-dock-item数据→画布区域drop创建桌面图标
- 5秒自动刷新(与Dock列表同步)
- 浅色主题适配(body.light-theme CSS)

### 图标体系(4级)
每个应用同时定义icon(PNG)+animatedIcon(GIF)+svgIcon(内联SVG)+emoji四种图标，由Dock渲染时按优先级选择。
### SVG图标设计
10个AI原生SVG内联图标，全部使用currentColor实现主题自适应。viewBox统一48×48，包含fill opacity层次感。
### 启动流程
launch(appDef) → electronAPI.desktopLaunchVchatApp(appAction) → 主进程IPC处理
### 注入流程(injectVchatAppsToDock)
```
遍历VCHAT_APPS:
  已存在(按id匹配): 同步更新属性(name/emoji/description/appAction/animatedIcon/svgIcon)
    但icon只在非data:URL时更新(保留用户自定义图标)
  不存在: push到state.dock.items, type='vchat-app'
→ dock.render() + dock.saveDockConfig()
```
在desktop.js初始化时延迟500ms调用inject，确保Dock数据已加载。
