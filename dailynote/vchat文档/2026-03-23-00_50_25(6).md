## 流式推送协议
### 6种action
| action | 触发时机 | 操作 | 调用的widgetManager方法 |
|--------|----------|------|------------------------|
| create | 检测到DESKTOP_PUSH开始 | 创建widget容器 | widget.create(id, options) |
| append | 每个流式token | 全量替换innerHTML | widget.appendContent(id, html) |
| finalize | DESKTOP_PUSH_END | 执行脚本+完成 | widget.finalize(id) |
| replace | target:语法 | CSS选择器定位替换 | widget.replaceInWidgets(sel, html) |
| remove | 移除指定widget | 销毁动画+DOM移除 | widget.removeWidget(id) |
| clear | 清除所有 | 清空画布 | widget.clearAll() |
### IPC事件监听
```javascript
electronAPI.onDesktopStreamPush((data) => {
    // data = { action, widgetId, content, targetSelector, options }
    switch(data.action) {
        case 'create': ...
        case 'append': ...
        case 'finalize': ...
        case 'replace': ...
        case 'remove': ...
        case 'clear': ...
    }
});
```
### append的节流机制
```
收到append → 累积content到pendingContent →
requestAnimationFrame → 批量flush到widget.appendContent
```
避免高频token导致DOM更新过于频繁。
## DesktopRemote远程控制（4种IPC监听）
### 1. SetWallpaper — 推送壁纸
```
监听: onDesktopRemoteSetWallpaper
输入: { wallpaperSource, type?, opacity?, blur?, brightness?, videoMuted?, videoPlaybackRate? }
流程:
  1. wallpaper.detectType(source) 自动识别类型
  2. 合并用户参数到config
  3. wallpaper.apply(config) 应用壁纸
  4. globalSettings.save() 持久化设置
  5. status.show('connected', '壁纸已更新') 状态提示
响应: 单向通知，无返回值
```
### 2. QueryDesktop — 查询桌面状态
```
监听: onDesktopRemoteQuery
输入: 无
流程:
  1. 遍历state.widgets Map → 收集每个widget的:
     { widgetId, x, y, width, height, savedName, savedId, savedDir }
  2. 遍历.desktop-shortcut-icon元素 → 收集桌面图标:
     { iconId, name, x, y }
  3. 组装响应
响应: { widgets: [...], desktopIcons: [...], totalWidgets, totalIcons }
```
### 3. ViewWidgetSource — 查看挂件源码
```
监听: onDesktopRemoteViewSource
输入: { widgetId }
流程:
  1. 从state.widgets找到widget
  2. 优先返回contentBuffer(完整累积HTML)
  3. 备选返回contentContainer.innerHTML
响应: { success, widgetId, htmlContent } 或 { success:false, error }
```
### 4. CreateWidget — 远程创建挂件
```
监听: onDesktopRemoteCreateWidget
输入: { htmlContent, x?, y?, width?, height?, widgetId?, autoSave?, saveName? }
流程:
  1. widget.create(id, {x,y,width,height})
  2. widget.appendContent(id, htmlContent)
  3. widget.finalize(id)
  4. if autoSave: _autoSaveWidget(id, saveName)
响应: { success, widgetId } 或 { success:false, error }
```
### _autoSaveWidget — 自动收藏流程
```
1. 生成savedId: 'saved-{timestamp}-{random6位}'
2. 获取htmlContent: contentBuffer优先 || innerHTML
3. 截图缩略图: electronAPI.desktopCaptureWidget(widgetId)
4. IPC保存: electronAPI.desktopSaveWidget({ savedId, name, htmlContent, thumbnail })
5. 更新widgetData: 标记savedName/savedId/savedDir
6. 刷新侧栏: sidebar.refreshFavorites()
```
## 连接状态管理
```
初始化时: status.show('waiting', '等待主窗口连接...')
收到第一个push: state.isConnected = true → status.show('connected')
流式推送中: status.show('streaming', '正在接收...')
流结束: status.show('connected', '已连接')
```
## 与其他模块的交互
| 模块 | 交互方式 |
|------|----------|
| widgetManager | 流式推送的直接消费者，调用全部6个方法 |
| wallpaperManager | SetWallpaper调用apply/detectType |
| globalSettings | SetWallpaper后调用save持久化 |
| statusIndicator | 各阶段更新状态显示 |
| sidebar | autoSave后刷新收藏列表 |
| state | 读写widgets/isConnected |
