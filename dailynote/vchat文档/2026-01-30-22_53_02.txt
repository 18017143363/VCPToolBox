# VCPTavern 插件完整技术文档

## 概述
VCPTavern是VCP的预设注入插件，负责将完整的角色设定注入到AI请求中。它是VChat与VCP之间的关键桥梁。

## 插件信息
- 路径: `E:\VCP\Plugin\VCPTavern\`
- 类型: messagePreprocessor + service (混合)
- 大小: VCPTavern.js (10.32 KB)

## 文件结构
| 文件 | 大小 | 说明 |
|------|------|------|
| VCPTavern.js | 10.32 KB | 核心逻辑 |
| plugin-manifest.json | 480 B | 插件清单 |
| presets/ | 目录 | 预设文件 |

## 预设文件列表

| rosa.json | 25.12 KB | Rosa完整角色设定 |

## 触发机制

### 触发器语法
```
{*2VCPTavern::预设名}*2
```
注意：为防止误触发，[*2表示为[[

### 检测正则
```javascript
const triggerRegex = /\{\{VCPTavern::(.+?)\}\}/;
```

### 处理流程
1. 在system消息中检测触发器
2. 提取预设名（如"rosa"）
3. 移除触发器文本
4. 加载对应的预设JSON
5. 按rules数组注入内容

## 注入规则类型

### 1. embed - 嵌入注入
直接修改现有消息内容。

| 参数 | 说明 |
|------|------|
| target | system / last_user |
| position | before / after |
| content | 要嵌入的文本 |

### 2. relative - 相对注入
在指定位置插入新消息。

| 参数 | 说明 |
|------|------|
| target | system / last_user |
| position | before / after |
| content | 完整消息对象 {role, content} |

### 3. depth - 深度注入
按消息深度插入。

| 参数 | 说明 |
|------|------|
| depth | 从末尾算起的位置 |
| content | 完整消息对象 |

## 预设JSON结构

```json
{
  "name": "预设名",
  "description": "描述",
  "rules": [
    {
      "id": "rule-xxx",
      "name": "规则名",
      "enabled": true,
      "type": "relative|embed|depth",
      "content": { "role": "system", "content": "..." },
      "position": "before|after",
      "target": "system|last_user",
      "depth": 0
    }
  ]
}
```

## API路由 (service功能)

| 端点 | 方法 | 功能 |
|------|------|------|
| /vcptavern/presets | GET | 获取所有预设名 |
| /vcptavern/presets/:name | GET | 获取预设详情 |
| /vcptavern/presets/:name | POST | 保存/更新预设 |
| /vcptavern/presets/:name | DELETE | 删除预设 |

## 与VChat的关系

### VChat端 (config.json)
```json
{
  "systemPrompt": "你是Rosa\n{*2VCPTavern::rosa}*2"
}
```
只存储简短的触发器。

### VCP端 (rosa.json)
存储完整的25KB角色设定，包含：
- 身份设定
- 工具调用说明
- 记忆系统配置
- 表情包系统
- 元思考链

## 设计优势

1. **分离存储**: VChat只需知道"用哪个预设"，具体内容在VCP
2. **集中管理**: 修改预设只需改VCP端，所有客户端自动生效
3. **灵活注入**: 支持多种注入方式和位置
4. **API管理**: 可通过HTTP API动态管理预设

## 手机连接的启示

由于预设存储在VCP端，手机ChatBox只需在System Prompt中写入触发器：
```
你是Rosa
{*2VCPTavern::rosa}*2
```
VCP会自动注入完整角色设定，**无需VChat参与**！
