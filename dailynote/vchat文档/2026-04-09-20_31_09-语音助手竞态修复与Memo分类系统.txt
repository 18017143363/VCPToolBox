## 核心问题
关闭窗口时，如果AI还在流式响应中，保存的历史可能不完整或竞态覆盖。
## 三大修复
### 1. 三重会话校验
旧：`eventData.messageId !== activeStreamingMessageId`（只检查messageId）
新：`isEventForCurrentVoiceSession(eventData)` / `isEventForCurrentAssistantSession(eventData)`
```javascript
function isEventForCurrentVoiceSession(eventData) {
    if (!eventData || !activeStreamingMessageId || eventData.messageId !== activeStreamingMessageId) return false;
    const expectedTopicId = getVoiceTopicId(); // voicechat_{agentId}
    const eventTopicId = eventData.context?.topicId;
    const eventAgentId = eventData.context?.agentId;
    return !!expectedTopicId && eventTopicId === expectedTopicId && eventAgentId === agentId;
}
```
三重匹配：messageId + topicId + agentId
### 2. 流式settle等待
关闭窗口前等待当前活跃的流式响应结束：
```javascript
async function waitForActiveStreamToSettle(timeoutMs = 4000) {
    // 80ms轮询检查activeStreamingMessageId是否变化
    // 4秒超时保护
    // resolve(true)=正常结束, resolve(false)=超时
}
```
saveVoiceChatToHistory开头：`await waitForActiveStreamToSettle();`
### 3. 关闭按钮防重复
```javascript
closeBtn.disabled = true;
try { await saveVoiceChatToHistory(); } finally { window.close(); }
```
