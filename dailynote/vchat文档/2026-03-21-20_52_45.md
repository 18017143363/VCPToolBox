## 核心定位
VCPDesktop是VChat的桌面渲染层扩展，在Electron实例中创建透明画布窗口，复用VChat流式渲染引擎，使Agent输出可直接渲染到操作系统桌面。
## 架构流程
AI输出token → streamManager.appendStreamChunk() → processDesktopPushToken()逐字符检测DESKTOP_PUSH开始标签 → buffer累积5字符后前缀白名单验证 → 创建挂件(施工态)+100ms节流推送 → IPC desktop-push → desktopHandlers.js转发 → desktop.js Shadow DOM渲染+autoResizeWidget() → 检测DESKTOP_PUSH_END → finalize+执行脚本
## 推送语法
完整推送: DESKTOP_PUSH标签包裹HTML/CSS/JS内容。支持裸div+内联CSS、完整HTML文档、SVG/Canvas、带fetch的动态挂件。
流式替换(热更新): target选择器+replace新内容，在所有活跃挂件Shadow DOM中查找并替换，替换后自动重算尺寸。
前缀白名单: doctype/div/section/article/main/header/nav/aside/canvas/svg/target:
## 关键技术点
1. Shadow DOM隔离: attachShadow mode open，样式互不污染
2. 脚本沙箱: document代理到Shadow DOM，querySelector/getElementById在Shadow DOM内查找，fetch正常工作
3. 主窗口转义封印: preprocessFullContent()第一步，聊天气泡显示占位符不渲染原始HTML
4. 防御性设计: 窗口不存在零IPC开销短路、150秒超时finalize、100ms节流、前缀白名单验证

## 深度源码分析补充

### streamManager.js — processDesktopPushToken()
逐字符状态机拦截器。状态对象：{active, widgetId, buffer, tagBuffer, created, validated, isReplaceMode, pushTimer, lastPushedLength, timeoutTimer}。
非active态逐字符匹配开始标签 → active态累积buffer → 5字符后二级验证前缀白名单 → 创建模式(IPC create+100ms定时推送) / 替换模式(等结束标签一次性解析target/replace) → 150秒超时保护。
desktopWindowAvailable缓存标志位避免每token做IPC查询。
在appendStreamChunk中，processDesktopPushToken返回过滤后正常文本，但accumulatedStreamText仍累积完整原始文本（含标签），用于转义封印。

### desktopHandlers.js — IPC转发中枢
Electron主进程模块。IPC通道：'desktop-push'(主窗口→桌面画布) + 'desktop-status'(双向状态通知)。
openDesktopWindow()创建无框BrowserWindow，复用preload.js，URL参数传递主题模式。ready-to-show时双向通知握手。closed时通知主窗口更新desktopWindowAvailable。
pushToDesktop()提供不经IPC的直接推送接口。

### desktop.js — 桌面画布渲染器
全局状态desktopState.widgets: Map<id, {element, shadowRoot, contentContainer, contentBuffer, isConstructing}>。
createWidget(): DOM构建(widget→grip抓手带→closeBtn→contentWrapper→attachShadow({mode:'open'})→shadowStyle→contentContainer)。
appendWidgetContent(): 全量覆盖式innerHTML替换实现"生长"效果。
autoResizeWidget(): 临时设inline-block+width:auto测量真实尺寸，clamp到[140px, 85%屏幕]，0.15s过渡动画。
processInlineScripts(): 脚本沙箱——IIFE包裹+局部document变量代理到shadowRoot，querySelector/getElementById自动在Shadow DOM内查找，createElement保持原始document绑定。
replaceInWidgets(): 遍历所有挂件Shadow DOM查找CSS选择器匹配元素并替换。
拖拽系统：grip专属mousedown，拖拽期间z-index提升。
IPC监听6种action: create/append/finalize/replace/remove/clear。

### messageRenderer.js — 转义封印
两个正则：DESKTOP_PUSH_REGEX(完整闭合) + DESKTOP_PUSH_PARTIAL_REGEX(流式未闭合)。
执行时机：代码块保护之后、transformSpecialBlocks之前。
完整闭合 → "🖥️已推送到桌面画布" + 120字符预览。未闭合 → "🖥️正在向桌面推送..." + 80字符预览 + thinking动画点。
内容用escapeHtml转义防XSS。

### 端到端数据流
AI token → appendStreamChunk() → processDesktopPushToken()逐字符拦截 → 分流：推送块内容→IPC→desktopHandlers→desktop.js渲染挂件 / 完整文本→accumulatedStreamText→morphdom流式渲染→finalize时转义封印→聊天气泡占位符卡片。
