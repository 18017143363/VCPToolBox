## 核心发现
1. ChromeBridge 的 execute_script 对复杂对象返回时，VCP 汇总可能只显示“脚本执行成功”，无法看到对象内容。
2. 解决办法：页面脚本必须 `return JSON.stringify(result).slice(0, N)`，确保返回值是可见纯字符串。
3. WPS WebOffice 页面刷新/加载期间，DOM 可能处于中间状态：
   - document.readyState 可能为 interactive 或 complete；
   - loading-page-mask 可能可见；
   - 缩略图容器和正文文本可能部分存在，但 SVG 未全部挂载。
4. WPS PPT 缩略图使用 `.thumbnail_slide`，总数可达实际页数；本例为 80。
5. 缩略图 SVG 存在懒加载/虚拟渲染：刷新后可出现 `thumbnailCount=80` 但 `svgSlideCount=33` 的状态。
6. 通过对每个 `.thumbnail_slide` 执行 `scrollIntoView({block:'center'})`、设置缩略图容器 scrollTop、派发 mouseover/mouseenter、等待，可以触发后续 SVG 挂载；本例最终 `svgSlideCount=80`，`noSvgPages=[]`。
7. 浏览器触发下载同名文件时可能自动生成编号文件，例如 `(1).html`；不要只检查无编号文件。

## 可复用流程
1. 等待页面稳定：
   - 检查 `.thumbnail_slide` 数量；
   - 检查 loading mask 是否可见；
   - 检查每页 `.thumbnail_view svg` 是否存在。
2. 如果 SVG 未全部挂载：
   - 遍历 `.thumbnail_slide`；
   - 调用 `scrollIntoView`；
   - 对缩略图容器设置 `scrollTop`；
   - 派发鼠标事件；
   - 每隔若干页 sleep。
3. SVG 全部挂载后再生成 HTML/导出，不足页数时必须跳过下载，避免生成空壳。
4. 下载后使用 LocalSearchController 搜索同名前缀，再用 FileOperator.FileInfo 验证文件大小。
