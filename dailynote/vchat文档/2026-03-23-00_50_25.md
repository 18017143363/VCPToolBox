# state.js — VCPdesktop全局状态中心
## 文件信息
| 属性 | 值 |
|------|-----|
| 路径 | E:\VCPCHAT\Desktopmodules\core\state.js |
| 大小 | 3.94KB |
| 职责 | 定义桌面系统的全部共享状态、常量和DOM引用 |
| 导出 | desktopState, CONSTANTS, domRefs |
| 全局挂载 | window.VCPDesktop.state |
## 核心数据结构
### desktopState — 运行时状态
```
desktopState = {
    widgets: new Map(),        // 挂件注册表 <id, widgetData>
    dragState: null,           // 当前拖拽状态对象
    isConnected: false,        // 主窗口连接状态
    nextZIndex: 10,            // z-index递增计数器
    sidebarOpen: false,        // 侧栏展开状态
    favorites: [],             // 收藏列表 [{id, name, thumbnail, dir, htmlFile}]
    dock: {
        items: [],             // Dock项 [{id,name,icon,animatedIcon,htmlIcon,svgIcon,emoji,targetPath,args,workingDir,originalPath,type,builtinId,visible}]
        maxVisible: 8,         // 最大可见数
    },
    desktopIcons: [],          // 桌面快捷方式图标 [{id,name,icon,targetPath,args,workingDir,x,y,type,builtinId}]
    globalSettings: {          // 全局设置（持久化到layout.json）
        autoMaximize: false,
        alwaysOnBottom: false,
        visibilityFreezerEnabled: true,
        defaultPresetId: null,
        dock: { maxVisible: 8, iconSize: 32 },
        wallpaper: {
            enabled: false, type: 'image', source: '',
            filePath: '', opacity: 1, blur: 0, brightness: 1,
            videoMuted: true, videoPlaybackRate: 1
        },
    },
}
```
### CONSTANTS — 不可变常量
| 常量 | 值 | 用途 |
|------|-----|------|
| TITLE_BAR_HEIGHT | 32 | 标题栏高度(px) |
| MIN_WIDGET_WIDTH | 120 | 挂件最小宽度 |
| MIN_WIDGET_HEIGHT | 60 | 挂件最小高度 |
| DRAG_MIN_VISIBLE | 40 | 拖拽时最小可见像素 |
| AUTO_RESIZE_MIN_WIDTH | 140 | 自动尺寸最小宽 |
| AUTO_RESIZE_MIN_HEIGHT | 60 | 自动尺寸最小高 |
| AUTO_RESIZE_MAX_WIDTH_RATIO | 0.85 | 自动尺寸最大宽度=屏幕85% |
| AUTO_RESIZE_PADDING | 8 | 自动尺寸内边距 |
| AUTO_RESIZE_DEBOUNCE | 14 | 自动尺寸防抖(ms) |
### domRefs — DOM引用缓存
| 引用 | 选择器 | 用途 |
|------|--------|------|
| canvas | #desktop-canvas | 挂件画布容器 |
| statusIndicator | #desktop-status-indicator | 状态指示器 |
| statusDot | .status-dot | 状态圆点 |
| statusText | .status-text | 状态文字 |
## 架构角色
state.js是VCPdesktop的"单一真相源"(Single Source of Truth)。所有模块通过window.VCPDesktop.state访问共享状态，无需模块间直接引用。这是无构建工具架构下的全局状态管理方案。
