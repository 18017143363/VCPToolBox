## 核心发现 - VChat与VCP通信机制

### send-to-vcp Handler（最重要！）

**通信方式**: 标准HTTP POST请求

```javascript
const response = await fetch(finalVcpUrl, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${vcpApiKey}`
    },
    body: serializedBody
});
```

**关键结论**:
- VChat使用标准的OpenAI Chat Completions API格式
- 任何OpenAI兼容客户端都可以直接连接VCP
- VChat不是必需的，只是增强型前端

## send-to-vcp 详细分析

### 消息预处理流程
1. **数据验证**: 确保content格式正确
2. **URL切换**: 根据enableVcpToolInjection切换端点
3. **音乐注入**: 如果启用agentMusicControl，注入播放列表
4. **气泡主题注入**: 如果启用enableAgentBubbleTheme
5. **思维链剥离**: 默认剥离元思考链（除非enableThoughtChainInjection=true）
6. **上下文净化**: 如果启用enableContextSanitizer

## 未读计数逻辑

### shouldActivateCount()
规则：上下文（排除系统消息）有且只有一个AI回复，且没有用户回复

### calculateTopicUnreadCount()
- 满足自动计数条件 → 返回计数
- 仅有unread标记 → 返回-1（显示小点）
- 其他 → 返回0
