## 壁纸设置UI
```
选择文件按钮 → electronAPI.desktopSelectWallpaper() → 返回filePath
→ detectType(filePath) 自动识别类型
→ 预览区域:
    image: <img src="file://path">
    video: <video src="file://path">
    html: 占位提示文字
→ 滤镜滑块:
    opacity: range 0~1 step 0.05
    blur: range 0~20 step 0.5
    brightness: range 0.1~2 step 0.05
→ 视频专属(type=video时显示):
    muted: checkbox
    playbackRate: range 0.1~3 step 0.1
→ 应用按钮 → wallpaper.apply(config)
→ 清除按钮 → wallpaper.clear()
```
## 持久化策略
```
save():
  1. loadLayoutData() 读取现有layout.json
  2. merged = { ...existing, globalSettings: currentSettings }
  3. desktopSaveLayout(merged)
load():
  1. loadLayoutData() 读取
  2. 深合并globalSettings(保留默认值)
  3. 返回settings
applyOnStartup():
  1. load()
  2. 应用各项设置(autoMaximize/alwaysOnBottom/freezer/dock/wallpaper)
  3. if defaultPresetId: setTimeout(1500ms) → sidebar.loadPreset(id)
```

## proxyFetch(endpoint, options?) — Admin API代理
```javascript
async function proxyFetch(endpoint, options = {}) {
    const { baseUrl, password } = _vcpCredentials;
    const url = `${baseUrl}${endpoint}`;
    const headers = {
        'Authorization': 'Basic ' + btoa(':' + password),
        ...options.headers
    };
    const response = await fetch(url, { ...options, headers });
    return response.json();
}
// widget中使用: vcpAPI.fetch('/admin_api/weather')
```
## vcpPost(messages, options?) — Chat API代理
```javascript
async function vcpPost(messages, options = {}) {
    const { apiUrl, apiKey, model } = _vcpApiCredentials;
    const body = {
        model: options.model || model,
        messages: messages,
        temperature: options.temperature ?? 0.7,
        stream: false,  // 非流式
    };
    const response = await fetch(apiUrl, {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${apiKey}`,
        },
        body: JSON.stringify(body),
    });
    const data = await response.json();
    return {
        success: true,
        content: data.choices[0].message.content,
        usage: data.usage,
        raw: data,
    };
}
// widget中使用: vcpAPI.post([{role:'user',content:'翻译xxx'}], {model:'gemini-2.5-flash-preview'})
```
## 安全设计
| 层级 | 保护措施 |
|------|----------|
| 凭据获取 | 通过Electron IPC从主进程获取，不在渲染进程硬编码 |
| 全局暴露 | 只暴露window.__vcpProxyFetch/Post函数，不暴露凭据对象 |
| 脚本沙箱 | widget脚本通过闭包var vcpAPI={...}访问，无法直接读取_vcpCredentials |
| 网络隔离 | widget不知道真实的baseUrl和apiKey |
