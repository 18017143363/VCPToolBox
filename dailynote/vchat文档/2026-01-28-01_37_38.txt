# VChat VCPDistributedServer/ 技术文档

## 概述
VCPDistributedServer是VChat的分布式服务器客户端模块，让VChat可以作为VCP的远程节点运行。

## 文件信息
- 路径: `E:\VCPCHAT\VCPDistributedServer\VCPDistributedServer.js`
- 大小: 21.11 KB

## 核心架构

### WebSocket连接
| 配置项 | 说明 |
|--------|------|
| mainServerUrl | VCP主服务器地址 |
| vcpKey | VCP密钥 |
| 连接路径 | `/vcp-distributed-server/VCP_Key=xxx` |

### 连接流程
1. 建立WebSocket连接
2. 注册工具列表 (register_tools)
3. 上报本机IP (report_ip)
4. 启动心跳 (30秒间隔)

## 消息协议

| type | 方向 | 说明 |
|------|------|------|
| register_tools | C→S | 注册工具 |
| report_ip | C→S | 上报IP |
| execute_tool | S→C | 执行请求 |
| tool_result | C→S | 返回结果 |
| heartbeat | 双向 | 心跳 |

## 工具执行路由
```
toolName.startsWith('music_') → handleMusicControl
toolName.startsWith('dice_') → handleDiceControl
toolName.startsWith('canvas_') → handleCanvasControl
toolName.startsWith('flowlock_') → handleFlowlockControl
toolName === 'internal_request_file' → handleFileRequest
```

## 心跳与重连
| 配置 | 值 |
|------|-----|
| heartbeatInterval | 30秒 |
| reconnectDelay | 5秒 |
| maxReconnectAttempts | 无限 |

## 设计亮点
1. VChat作为VCP远程节点
2. 将本地能力暴露给VCP主服务器
3. 双向WebSocket实时通信
4. Base64文件传输
5. 指数退避自动重连（5s→60s）

## 重要发现（深度分析）

### 1. 自带插件系统
VChat分布式服务器有**独立的Plugin.js**，可以加载Plugin/目录下的本地插件！

### 2. 静态占位符推送
每30秒推送一次静态插件的占位符值到VCP主服务器。

### 3. 双重服务器角色
- WebSocket客户端：连接VCP主服务器
- HTTP服务器：为服务类插件提供API

### 4. 特殊工具处理
| 工具 | 处理方式 |
|------|----------|
| internal_request_file | 读取本地文件Base64 |
| MusicController | 注入的handleMusicControl |
| SuperDice | 注入的handleDiceControl |
| Flowlock | 注入的handleFlowlockControl |
| create_canvas | 注入的handleCanvasControl |

### 5. 健壮的JSON解析
从插件输出中提取真正的JSON（跳过调试信息）

### 6. 公网IP检测
通过api.ipify.org获取公网IP并上报
