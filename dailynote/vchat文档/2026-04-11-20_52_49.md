## 保存逻辑
- 自动保存: debounce 3秒
- 标题改变 → renameItem(改文件名+写内容，返回newId)
- 仅内容改变 → writeTxtNote(轻量写入)
- 无变化 → 跳过
- 保存后: 更新本地模型+renderTree(避免全量reload闪烁)
- 自动保存反馈: button-autosave-feedback CSS类闪烁

## 创建笔记逻辑
createNewItem(type, ext)
- 选中文件夹 → 在该文件夹内创建
- 选中笔记 → 在其父目录创建
- 无选中 → 在根目录创建
- type='folder' → api.createNoteFolder
- type='note' → api.writeTxtNote, ext可选.md/.txt

## 选择系统
- 单击: clear → add(id)
- Ctrl+点击: toggle(id)
- Shift+点击: range select(allItems从startIndex到endIndex全选)

## 粘贴图片
textarea paste事件 → 检测image/* → FileReader → base64 → api.savePastedImageToFile → 返回attachment → 插入![name](internalPath) → 触发保存

## 笔记分享
api.onSharedNoteData(data) → 生成带毫秒时间戳标题(防burst冲突) → 原标题作为#标题注入content → writeTxtNote → selectNote

## 主题系统
applyTheme(theme): body.classList.toggle('light-theme') + 切换highlight.js主题CSS(atom-one-dark↔atom-one-light)

## 删除逻辑
handleDirectDelete(isFromContextMenu)
- 保护: isCloudItem + dailynote → 拒绝删除
- 含文件夹 → 强确认弹窗(不可撤销)
- 含云文件夹 → 更强警告(无法从回收站恢复)
- 仅笔记 → 普通确认
- 逐项调用api.deleteItem → 本地模型removeItemById → 清理选择状态
