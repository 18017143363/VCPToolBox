# VChat启动流程技术文档

## 概述

本文档记录VChat的完整启动流程，基于实际启动日志分析。

## 启动阶段

### 阶段1: Electron初始化

**关键模块加载时间**：
| 模块 | 耗时 | 说明 |
|------|------|------|
| fs-extra | 57ms | 文件操作增强库 |
| musicHandlers | 117ms | 音乐IPC处理器 |
| VCPDistributedServer | 268ms | 分布式服务器（最重） |

### 阶段2: 目录初始化

| 组件 | 目录 |
|------|------|
| FileManager | AppData/UserData/ |
| GroupChat | AppData/AgentGroups/ |
| attachments | AppData/UserData/attachments/ |

### 阶段3: 后台任务并行启动

1. **Python音频引擎**
   - 脚本: audio_engine/main.py
   - 端口: 5555
   - 就绪信号: FLASK_SERVER_READY
   - 常见问题: 端口被占用(WinError 10013)

2. **模型列表获取**
   - 目标: http://127.0.0.1:6005/v1/models
   - 失败处理: 优雅降级，不阻塞启动
   - 通知渲染进程: Background model fetch complete

3. **表情包库生成**
   - 组件: EmoticonFixer
   - 输出: emoticon_library.json

### 阶段4: 分布式服务器初始化

**启动流程**：
1. 读取config.env获取端口(默认5974)
2. 插件发现(DistPluginManager)
3. 启动HTTP服务器(0.0.0.0:端口)
4. WebSocket连接VCP主服务器
5. 注册工具列表
6. 上报IP地址(本地+公网)
7. 启动静态占位符更新(30秒间隔)

**插件类型**：
| 类型 | 说明 |
|------|------|
| synchronous | 同步插件，立即返回结果 |
| service | 服务插件，提供HTTP API |
| hybridservice | 混合服务插件 |

### 阶段5: WebSocket连接

**VCPLog连接**：
- 路径: ws://127.0.0.1:6005/VCPlog/VCP_Key=xxx
- 确认消息: connection_ack

### 阶段6: 渲染进程就绪

1. 主题应用(dark/light)
2. settings.json更新
3. FileWatcher启动监控当前话题

## 常见启动问题

### 1. 音频引擎端口冲突

**错误**：
```
PermissionError: [WinError 10013] 端口5555被占用
```

**解决**：
```powershell
netstat -ano | findstr :5555
taskkill /PID <进程ID> /F
```

### 2. VCP未启动时的模型获取失败

**错误**：
```
ECONNREFUSED 127.0.0.1:6005
```

**影响**：不影响启动，VChat会在VCP启动后重新获取

### 3. 分布式插件路径配置错误

**现象**：插件配置的路径与实际安装路径不符

**解决**：修改对应插件的config.env
