## 核心发现：NPC自定义数据存储API
mod可以在任何NPC身上存储任意键值对数据，无需修改存档结构：
- worldUnit.GetStr(key) / SetStr(key, value) — 字符串类型
- worldUnit.GetInt(key) / SetInt(key, value) — 整数类型
实例：SetStr("被谁操", npcId)、GetInt("堕落值")、SetInt("流产次数", count)
这是mod生态的基石级API，允许mod在不修改游戏底层的情况下扩展NPC数据模型。

## 气运系统API
- worldUnit.GetLuck(luckId) — 获取气运对象（返回WorldUnitLuckBase，含luckData.duration倒计时）
- worldUnit.AddLuck(luckId) / AddLuck(luckId, duration) — 添加气运（可带持续时间）
- worldUnit.RemoveLuck(luckId) — 移除气运
- worldUnit.HasLuck(luckId) — 检查是否有某气运
气运不仅是buff/debuff，也被mod用作状态标记和计时器（如怀孕气运duration=孕期月数）。

## 关系系统API
- worldUnit.data.unitData.relationData.AddHate(targetId, value, 0, "", true) — 增加仇恨
- worldUnit.data.unitData.relationData.AddIntim(targetId, value, 0, "", true) — 增加好感
- worldUnit.ChangedMarried(targetUnit, false) — 强制修改婚姻关系
- worldUnit.IsFriend(otherUnit) / IsVital(otherUnit) — 关系判断

## NPC日志系统
- worldUnit.AddMonthLog(eventKey, params) — 月报日志（每月事件记录）
- worldUnit.AddVitalLog(eventKey, params) — 重要事件日志（终身事件记录）
- worldUnit.LogCall(otherUnit) / LogName() — 日志中的称呼/名称格式化
eventKey格式如"eventLogRoleHuaiYun24328056"，对应LocalText配置表中的文本模板。

## NPC创建API
- Units.CreateChild(featureId, father, mother, sexType, age, -1, null) — 创建子女NPC
- featureId对应RoleCreateFeature表：1008611=玩家子女, 1008612=普通子女, 1008613=性奴子女
- worldUnit.SetFaceInherit(father, mother, percent) — 面部遗传（异步5步流程）

## 状态判断扩展方法
- worldUnit.IsPlayer() — 是否玩家
- worldUnit.IsWoman() / IsMan() — 性别判断
- worldUnit.IsSexSlave() — 是否性奴（mod自定义扩展方法，定义在Extensions.cs中）
- worldUnit.GetName() — 获取名称
- worldUnit.GetAge() — 获取年龄（单位：月，192月=16岁）
- worldUnit.GetID() — 获取NPC ID
- worldUnit.isDie — 是否死亡

## UI提示API
- UICostItemTool.AddTipText(richText) — 弹出富文本提示（支持<color>标签）

## 关键设计模式
1. 气运系统被复用为状态机：怀孕=添加气运+duration倒计时，到期=分娩触发
2. GetStr/SetStr作为NoSQL式键值存储：mod无需定义数据表即可扩展NPC属性
3. 月结事件(OnMonthEnd)是mod逻辑的主循环入口
4. IDisposable模式管理子系统生命周期
