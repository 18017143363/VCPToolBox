## objData 分组键值存储
游戏原生提供 unit.data.unitData.objData 作为NPC的自由数据存储区：
- objData.SetString(groupName, key, value) — 按组名+键名存储
- objData.GetString(groupName, key) — 按组名+键名读取
- objData.GetInt(groupName, key) — 读取整数
Mod_Tc85Yz使用"淫女宫"作为组名。不同mod使用不同组名可避免键名冲突。
这是mod生态最重要的数据扩展机制——无需修改游戏存档结构即可为NPC添加任意自定义属性。

## 扩展方法模式
Mod通过C# extension methods为WorldUnitBase添加方法：
- 定义为 public static class Extensions / Units，方法参数带 this WorldUnitBase unit
- 调用时语法为 unit.IsWoman() / unit.AddLuck(id) / unit.SetStr(key, value)
- 这些方法在DLL加载后全局可用，其他引用该DLL的mod也能直接调用

## 游戏事件系统
- g.events.On(eventName, handler, count, flag) — 注册事件监听
- g.events.Off(eventName, handler) — 注销事件监听
- count=0表示持续监听，count=1表示只触发一次
关键事件：
- EGameType.WorldRunEnd — 月结开始（用于月初处理）
- EGameType.WorldRunStart — 月结结束（用于月末处理）
- EBattleType.BattleExit — 战斗退出（用于延迟到战斗外执行的效果）

## NPC外观数据模型（PortraitModelData）
15个字段：sex, hat, hair, hairFront, head, eyebrows, eyes, nose, mouth, body, back, forehead, faceFull, faceLeft, faceRight
每个部位有对应的Beauty值和OffsetY偏移值
序列化格式：用"|"分隔的整数字符串

## 金钱系统
- 灵石的propsID = 10001
- unit.data.unitData.propData.GetPropsNum(10001) 获取
- 修改时遍历allProps找到propsID==10001的条目直接改propsCount

## NPC信件系统
- g.data.dataWorld.data.allLetter — 全局信件列表
- g.data.dataWorld.data.newTip.allNewTip["Email"] — 新信件提示
- 信件结构：soleID(UUID), sendUnitName, sendUnitID, month, state, letterID
