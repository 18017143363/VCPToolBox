## 核心概念
g 是游戏全局单例对象，鬼谷八荒Mod代码的所有核心操作均通过 g.* 进行。
Example.cs（9.8KB）是官方提供的完整API示例文件。
路径：modFQA\代码编写教程\ModMain\Example\Example.cs

## using 引用列表
HT.API / HT.Dispatcher / HT.Logic / HT.Model / System / System.Reflection / UnityEngine / Il2CppInterop.Runtime.Injection

## g.timer — 帧回调
- g.timer.Frame(action, interval, repeat) — 注册帧回调，替代MonoBehaviour.Update
- g.timer.Stop(coroutine) — 停止回调
- 返回值：TimerCoroutine（需保存以便Stop）

## g.events — 事件广播
- g.events.On(eventType, callback) / g.events.Off(eventType, callback)
- 广播枚举：EGameType（通用）、EMapType（大地图）、EBattleType（战斗）
- 数据转换：e.Cast<EBattleTypeData.UnitHitDynIntHandler>()
- 示例：EBattleType.UnitHitDynIntHandler → edata.hitUnit / edata.dynV

## g.world — 世界管理
- g.world.playerUnit — 玩家单位引用
- g.world.playerUnit.data.unitData.propertyData.GetName() — 玩家名
- g.world.battle.IntoBattle(new DataMap.MonstData(){id, level}) — 进入副本，对应DungeonBase表
- g.world.mapEvent.AddGridEvent(point, eventId) — 大地图添加事件，对应WorldFortuitousEventBase表
- g.world.unit.GetUnit("NPCID_XXXXXX") — 获取NPC，unitData含NPC全部存档信息

## UnitAction — 单位行为
- unit.CreateAction(new UnitActionLuckAdd(120)) — 添加气运（单人行为）
- unit.CreateAction(new UnitActionRoleTrains(g.world.playerUnit)) — 切磋（双人行为 UnitActionRole）
- 单人行为类：移动/添加气运/添加任务/使用道具/装备武学
- 双人行为类（UnitActionRole）：聊天/双修/切磋/论道

## DramaTool — 剧情系统
- DramaTool.OpenDrama(id, new DramaData(){unitLeft, unitRight}) — 打开剧情，对应DramaDialogue表
- UICustomDramaDyn — 动态剧情：SetOptionCall(buttonId, action) 设按钮回调；dramaData.dialogueOptionsAddText[1001]="文本" 加按钮；OpenUI()打开

## 条件与命令工具
- UnitConditionTool.Condition("grade_0_1_1", conditionData) — 判断条件，对应配置对照条件说明表
- DramaFunctionTool.OptionsFunction("openUI_xxx") — 剧情命令
- BattleFunctionTool.OptionsFunction("createMonst_7210_0_0_3") — 副本命令，仅副本内可用

## SceneType.battle — 战斗场景
- SceneType.battle.unit.CreateUnitHuman<UnitCtrlHumanNPC>(npc.data, UnitType.PlayerNPC) — 创建友方NPC
- SceneType.battle.unit.CreateUnitMonst(id, pos, UnitType.Monst) — 创建怪物，对应BattleUnitAttr表
- SceneType.battle.battleMap.playerUnitCtrl.AddEffect(effectId, source, skillData) — 施加战斗效果，对应BattleEffect表
- SceneType.battle.battleMap.roomCenterPosi — 战斗场景中心坐标

## SceneType.map — 大地图
- SceneType.map.world.CloseAllUI() — 关闭所有UI
- 大地图操作主要通过 g.world 进行

## g.res — 资源加载
- g.res.Load<GameObject>("Effect/Battle/Skill/jueyingjian") — 加载Resources或AB资源

## g.sounds — 声音
- g.sounds.PlayEffect("Battle/jineng/jian/jueyingjian", vol) — 播放音效，不加Effect前缀

- g.conf.roleGrade.GetGradeItem(1, 1) — 获取配置，Conf*系列

## g.data — 存档数据

## g.ui — UI控制
- g.ui.OpenUI(UIType.PlayerInfo) — 打开系统UI
- UITipItem.AddTip("提示") — 弹出提示框

- g.ui.OpenUI<UITextInfo>(UIType.TextInfo).InitData("标题","内容") — 文本信息框

## g.root — 根节点
- g.root.AddComponent<T>() — 添加组件，需先 ClassInjector.RegisterTypeInIl2Cpp<T>()

## 工具类
- CommonTool.Random(0, 10) — 随机整数
- GameTool.LS("common_tishi") — 国际化文本

## IL2CPP 特殊规则
- 自定义MonoBehaviour子类必须声明构造：public T(IntPtr ptr) : base(ptr) {}
- 动态添加组件前必须：ClassInjector.RegisterTypeInIl2Cpp<T>()
- 事件回调中IL2CPP对象需显式Cast，不能用C#泛型隐式转换

## 重要设计原则
1. 不在Init()里直接操作游戏对象，应监听事件后在回调里操作
2. Destroy()中必须清理所有g.timer和g.events注册
3. 配置数据通过g.conf而非硬编码
4. 国际化文本一律用GameTool.LS()
5. 自定义UI预制体需放在ModRes/Resources并打AB
