## surya库Windows路径Bug修复（必做）
Marker依赖surya库，surya的模型下载在Windows下会Aborted，需要手动patch：

### 根因
`surya/common/s3.py`的`get_local_path()`函数中：
```python
local_path = os.path.join(cache_dir, pretrained_model_name_or_path)
# cache_dir = "C:\Users\...\models"（反斜杠）
# model_name = "layout/2025_09_23"（正斜杠）
# 结果 = 混合路径 → shutil.move()失败 → Aborted
```

### 修复方法
定位文件：`{python安装目录}/Lib/site-packages/surya/common/s3.py`
修改两处：
1. `local_path = os.path.join(...)` → 外层包`os.path.normpath()`
2. `shutil.move(..., local_dir)` → `local_dir`也包`os.path.normpath()`

### 修复后必须
删除`surya/common/__pycache__/`和`surya/__pycache__/`目录，否则Python继续加载旧.pyc

### 正确的环境变量
| 变量名 | 说明 |
|--------|------|
| MODEL_CACHE_DIR | ✅正确！surya用pydantic-settings，字段名=env var名 |
| DATALAB_CACHE_DIR | ❌无效！surya不读这个 |

设置示例：
```powershell
[System.Environment]::SetEnvironmentVariable("MODEL_CACHE_DIR", "D:\AI_Models", "User")
```
注意：已打开的终端不会自动刷新用户环境变量，需新开终端或手动`set MODEL_CACHE_DIR=D:\AI_Models`

## 扫描版PDF OCR效果实测（计算机网络第8版，100-105页样本）
### 优点
- LaTeX公式识别不错（T₀, τ, S_max）
- 图片提取为jpeg，质量可读
- 章节标题和列表结构基本保留

### 严重缺陷
| 类型 | 示例 |
|------|------|
| OCR错字 | 碰撞→碰梳、重传→鱼传/矗传/祖传、集线器→梊线器/梨线器 |
| 断行错乱 | 扫描版换行硬保留："一一定""这这种" |
| 章节号误识 | 3.3.4→334 |

### 结论
扫描版中文PDF的OCR质量不可接受，推荐改用PyMuPDF导出页面图片+AI视觉直读方案。
文字版PDF仍推荐Marker。
