## 核心概念
PowerShellExecutor 让 Agent 在持久化的 PowerShell 会话中执行命令。VChat端版本维护一个长期活动的PTY伪终端窗口，支持连续操作（cd后再ls，路径会保留）。是系统管理、脚本执行、批量操作的核心工具。

## 双版本对比

VCP端（ServerPowerShellExecutor）
- 路径：E:\VCP\Plugin\PowerShellExecutor\
- 类型：synchronous (stdio)
- 特点：无状态，每次spawn新进程，命令间不保留上下文
- 参数：command + executionType(blocking/background) + requireAdmin(验证码)

VChat端（PowerShellExecutor）— 实际使用的版本
- 路径：E:\VCPCHAT\VCPDistributedServer\Plugin\PowerShellExecutor\
- 类型：hybridservice (direct)
- 特点：PTY持久化会话，连续操作保留上下文，有GUI终端窗口
- 参数：command + requireAdmin(布尔) + newSession(布尔) + returnMode(delta/full)

以下以VChat端为准。

## 技术参数
- 版本：1.0.0
- 调用名：PowerShellExecutor
- 超时：600秒（10分钟）
- 会话：node-pty伪终端，优先pwsh.exe，回退powershell.exe
- 初始编码：UTF8

## 命令：PowerShellExecutor（唯一命令）

### 参数类型表
参数command — 字符串，必需，要执行的PowerShell命令
参数requireAdmin — 布尔值，可选，默认false，管理员权限（触发GUI确认框+UAC）
参数newSession — 布尔值，可选，默认false，强制关闭当前会话并新建
参数returnMode — 字符串，可选，默认delta，delta=最新输出/full=全部终端内容

### 参数详解

#### command（字符串，必需）
怎么传: 直接写PowerShell命令，支持分号连接多条

正确示例:
- 简单: command: Get-ChildItem
- 切换目录: command: cd E:\VCP; ls
- 管道: command: Get-Process | Where-Object {$_.CPU -gt 100}
- 多命令: command: $a = 1; $b = 2; Write-Host ($a + $b)

常见错误:
- 错: 使用format关键字（VCP端被forbidden拦截）
- 错: 使用Here-String(@"..."@)，PTY环境下会导致会话永久卡死
- 错: 包含VCP界定符（会被解析器截断）

安全检查机制（VChat端）:
- FORBIDDEN: rm, del, rmdir（直接拒绝）
- AUTH_REQUIRED: net, shutdown, restart, Remove-Item, Clear-Content（需确认）
- 智能路径排除：路径中的关键字不触发拦截

#### requireAdmin（布尔值，可选，默认false）
设为true时弹出AdminConfirm.py GUI确认框+UAC提权，会强制创建新会话

#### newSession（布尔值，可选，默认false）
强制新建会话。使用场景: 会话卡死/异常恢复、Here-String导致永久等待、清理环境

#### returnMode（字符串，可选，默认delta）
delta: 只返回本次命令输出（推荐）
full: 返回整个终端所有内容（调试用）

## 使用心得
1. 持久化会话：cd后再ls路径会保留，不像VCP端每次重置
2. 分号连接多命令比多次调用效率高
3. 中文输出正常（初始化已设UTF8）
4. 管道操作强大：Get-Content | Select-String比手动分析快

## 踩坑记录（重灾区！）
1. Here-String卡死 — @"..."@在PTY中结束标记可能不被识别，导致会话永久等待。只能newSession:true恢复
2. format敏感词 — VCP端禁止，VChat端已移除此限制
3. 超时后僵死 — 60秒超时后dataListener被移除但PTY存活，后续命令被吞。解决：newSession:true
4. 路径空格 — 需引号包裹：cd "E:\Program Files\xxx"
5. 编码偶发乱码 — 某些旧cmdlet输出GBK，手动设置[Console]::OutputEncoding=[Text.Encoding]::UTF8
6. VCP界定符 — command中不能包含始末标记，会被解析器截断
