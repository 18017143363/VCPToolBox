[21:05] WPS COM自动化 — PPT转PDF/图片方案

## 核心概念
WPS Office自带COM接口，可通过Python comtypes库调用，实现PPT→PDF导出。配合PyMuPDF+Pillow可完成PPT→图片→拼接长图的完整链路。无需安装LibreOffice。

## 依赖安装
```
pip install comtypes PyMuPDF Pillow
```

## 前提条件
- 系统安装了WPS Office（本机路径：E:\WPS Office\12.1.0.25865\office6\）
- WPS的COM组件名：`Kwpp.Application`（演示文稿）、`Kwps.Application`（文字）、`Ket.Application`（表格）

## PPT→PDF导出
```python
import comtypes.client, os
wpp = comtypes.client.CreateObject('Kwpp.Application')
prs = wpp.Presentations.Open(r'输入路径.pptx')
prs.ExportAsFixedFormat(r'输出路径.pdf', 2)  # 2=PDF格式
prs.Close()
wpp.Quit()
```

## 完整链路：PPT→PDF→单页png→拼接长图
```python
import fitz, os
from PIL import Image

# 1. PyMuPDF导出每页图片
doc = fitz.open(r'导出的.pdf')
out = r'D:\output\pages'
os.makedirs(out, exist_ok=True)
pages = []
for i in range(doc.page_count):
    p = os.path.join(out, f'page_{i+1:03d}.png')
    doc[i].get_pixmap(dpi=150).save(p)
    pages.append(p)

# 2. Pillow拼接：每4页合成一张长图
merged_dir = r'D:\output\merged'
os.makedirs(merged_dir, exist_ok=True)
batch = 4
for start in range(0, len(pages), batch):
    imgs = [Image.open(p) for p in pages[start:start+batch]]
    w = max(im.width for im in imgs)
    h = sum(im.height for im in imgs)
    merged = Image.new('RGB', (w, h), (255,255,255))
    y = 0
    for im in imgs:
        merged.paste(im, (0, y))
        y += im.height
    merged.save(os.path.join(merged_dir, f'slides_{start+1}-{start+len(imgs)}.png'))
```

## 踩坑记录
1. **Visible=False会触发COM错误** — 首次尝试设wpp.Visible=False导致`_ctypes.COMError: (-2147467259, '未指定的错误')`，去掉这行后成功
2. **vbe6ext.olb警告** — comtypes解析WPS类型库时会报UserWarning(GetRefTypeInfo failed)，这是警告不影响功能
3. **pptx2img需要LibreOffice** — 不要用这个库，直接用WPS COM
4. **ExportAsFixedFormat第二个参数** — 2=PDF格式
