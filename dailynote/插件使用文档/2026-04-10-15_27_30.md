## 核心概念
DailyHot是VCP的**static类型插件**，每4小时自动从55个主流平台抓取热搜/热榜数据，通过vcp_dynamic_fold协议按语义相关度动态折叠后注入system prompt。不需要手动调用，全自动被动推送。

## 技术参数
| 属性 | 值 |
|------|-----|
| 路径 | E:\VCP\Plugin\DailyHot\ |
| 类型 | **static**（自动定时运行） |
| 定时 | cron `0 */4 * * *`（每4小时） |
| 入口 | node daily-hot.js |
| 占位符 | `{*2VCPDailyHot}*2` |
| 超时 | 120秒（manifest） + 30秒（内部脚本超时） |
| 版本 | 2.0.0 |
| 作者 | Kilo Code & Roo |
| 缓存文件 | dailyhot_cache.md（同目录，约120KB） |

## vcp_dynamic_fold三级折叠策略
| 阈值 | 触发场景 | 展示内容 |
|------|----------|----------|
| 0.5 | 用户聊热点/新闻/热搜 | 每源Top3标题 |
| 0.35 | 用户话题略相关 | 每源Top1头条 |
| 0.0 | 用户话题无关（兜底） | 仅"已缓存N个源" |

## 缓存降级机制
1. 主路径：实时抓取→构建fold
2. 降级1：抓取失败→从dailyhot_cache.md解析→构建fold
3. 降级2：缓存也没有→返回"数据不可用"的fold
4. 内部30秒超时保护（Promise.race）

## 与ArxivDailyPapers的对比
| 维度 | DailyHot | ArxivDailyPapers |
|------|:---:|:---:|
| 数据源数量 | 55个平台 | 1个(arXiv) |
| 刷新频率 | 每4小时 | 每30分钟 |
| 折叠协议 | vcp_dynamic_fold三级 | 无（纯文本） |
| 缓存方式 | Markdown文件 | JSON文件 |
| 数据格式 | {category, title, url} | 论文元数据 |
| 适用场景 | 全网热点追踪 | 学术前沿追踪 |

## 使用注意
- 这是static插件，无需也无法手动调用
- 需要在system prompt中放置占位符才能生效
- 缓存文件路径在fold输出中告知AI，AI可通过FileOperator读取完整热榜
- 55个源并发抓取，部分源可能因网络/反爬失败，但Promise.allSettled保证不影响整体
