## 核心概念
PyMuPDF是Python的PDF处理库（import名为fitz），可以将PDF每一页渲染为高质量图片。对于扫描版PDF，这是比OCR转文字更优的方案——直接导出页面图片让AI视觉模型阅读，零错字、零信息丢失。

## 安装
```
pip install PyMuPDF
```
极轻量，几MB，无GPU依赖，无模型下载。

## 核心API

### 打开PDF
```python
import fitz
doc = fitz.open("文件路径.pdf")
print(f"总页数: {doc.page_count}")
```

### 单页导出图片
```python
# page_idx从0开始
page = doc[page_idx]
pixmap = page.get_pixmap(dpi=150)
pixmap.save("output.png")
```

### 批量按范围导出
```python
import os
out_dir = "D:/output/pdf_pages"
os.makedirs(out_dir, exist_ok=True)
for i in range(start, end):  # start/end从0开始
    doc[i].get_pixmap(dpi=150).save(os.path.join(out_dir, f"page_{i+1:03d}.png"))
```

### 一行命令版（PowerShell可直接跑）
```
python -c "import fitz; doc=fitz.open(r'PDF路径'); [doc[i].get_pixmap(dpi=150).save(f'D:/output/page_{i+1:03d}.png') for i in range(100,106)]"
```

## 参数详解

### dpi（整数，可选，默认72）
控制输出图片分辨率：
| dpi | 适用场景 | 文件大小 |
|-----|---------|---------|
| 72 | 快速预览 | 小 |
| 150 | 推荐日常使用，清晰度与大小平衡 | 中 |
| 300 | 高清打印/精细分析 | 大 |

### page_idx（整数）
页码索引从0开始。doc[0]是第1页，doc[99]是第100页。

## 与Marker OCR对比（扫描版PDF场景）
| 维度 | PyMuPDF导图+AI视觉 | Marker OCR转md |
|------|-------------------|---------------|
| 文字准确率 | ✅零错字（AI直读） | ⚠️错字密集（碰撞→碰梳） |
| 图片处理 | ✅文字图片一起看 | 需额外UrlFetch逐张读 |
| 速度 | 瞬间导出 | GPU满载每页几十秒 |
| 依赖 | 几MB | surya 2.7G模型+GPU |
| 公式识别 | ✅AI视觉直读 | 基本OK偶有错 |

## 使用心得
1. 扫描版PDF首选PyMuPDF导图+AI视觉，完胜OCR方案
2. 文字版PDF仍推荐Marker，因为文字版直接提取文字很快
3. dpi=150是性价比最高的选择
4. 教案制作流程：按章节导出指定页码图片→UrlFetch读图→AI直接理解

## 踩坑记录
- import名是fitz不是PyMuPDF
- page_idx从0开始，第100页是doc[99]
- 导出png比jpg清晰，推荐png格式
