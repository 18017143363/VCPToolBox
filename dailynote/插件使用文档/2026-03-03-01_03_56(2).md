## 核心概念
DiscourseReader v1.6.0，Discourse论坛的完整交互插件。通过User API Key(RSA握手)永久认证，Puppeteer+Stealth穿透Cloudflare。支持多站点配置(base_url可覆盖默认论坛)。

## 技术参数
- 版本：1.6.0
- 路径：E:\VCP\Plugin\DiscourseReader\
- 调用名：DiscourseReader
- 类型：synchronous (stdio/Node.js)
- 入口：node DiscourseReader.js
- 超时：60秒

## 配置项
DISCOURSE_BASE_URL(字符串,默认https://linux.do) — 默认论坛地址
DEFAULT_CATEGORY(字符串,默认"develop") — ListTopics默认板块slug
forum_{name}_api_key(字符串) — User API Key，{name}按域名匹配(如forum_linuxdo_api_key)
forum_{name}_cookie(字符串) — 备选Cookie认证
MAX_CONTENT_LENGTH(数字,默认3000) — 帖子内容最大字符数
MAX_POSTS(数字,默认10) — ReadTopic默认最大楼层数

## 9个命令详解

### 读取类（2个）
#### ListTopics — 浏览帖子列表
参数: category(可选,板块slug), tag(可选,标签路径), page(可选,默认0), order(可选,默认latest,可选latest/top/likes/views/posts), base_url(可选)
注意: category和tag二选一，tag模式page建议从1开始

#### ReadTopic — 读取帖子内容
参数: topic_id(必需,支持传完整URL自动提取ID), max_posts(可选,默认10,上限50), post_number(可选,翻页起始楼), base_url(可选)

### 搜索类（1个）
#### SearchForum — 搜索论坛
参数: keyword(必需,支持Discourse搜索语法), base_url(可选)

### 元数据类（2个）
#### ListCategories — 列出所有板块
参数: base_url(可选)
返回slug可直接用于ListTopics的category参数

#### ListTags — 列出所有标签
参数: base_url(可选)
返回path可直接用于ListTopics的tag参数

### 互动类（4个，需write scope API Key）
#### LikePost — 点赞
参数: post_id(必需,楼层ID不是topic_id!), base_url(可选)

#### UnlikePost — 取消点赞
参数: post_id(必需), base_url(可选)

#### ReplyTopic — 回复帖子
参数: topic_id(必需), content(必需,Markdown), reply_to_post_number(可选), base_url(可选)

#### CreateTopic — 创建帖子
参数: title(必需), content(必需,Markdown), category(必需,slug或数字ID), tags(可选,逗号分隔), base_url(可选)
