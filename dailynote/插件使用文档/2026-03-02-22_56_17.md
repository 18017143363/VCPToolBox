## 核心概念
DailyNote 是 VCP 的日记系统插件，提供日记创建(create)和更新(update)两个命令。写入的日记会被 KnowledgeBaseManager 自动向量化入库，成为 LightMemo/RAG 检索的数据源。Agent 记忆持久化的核心工具。

## 架构关系
DailyNote（面向AI接口）→ 内部调用 DailyNoteWrite（底层写入器）→ 写入 dailynote/ 目录
DailyNoteWrite 负责：实际文件写入 + Tag格式修复 + AI自动打Tag（忘写Tag时自动生成）

## 技术参数
- 路径：E:\VCP\Plugin\DailyNote\
- 调用名：DailyNote
- 类型：synchronous (stdio/Node.js)
- 超时：30秒
- 版本：2.0.0
- 存储根目录：E:\VCP\dailynote\

## 配置项
DebugMode(布尔值) — 调试日志开关

## 命令一：create（创建日记）

### 参数类型表
| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| maid | 字符串 | 是 | 署名+存储路径控制 |
| Date | 字符串 | 是 | 日期 YYYY-MM-DD |
| Content | 字符串 | 是 | 日记正文 |
| Tag | 字符串 | 否 | 独立标签字段(推荐) |

### 参数详解

#### maid（字符串，必需）
**是什么**: 作者署名，同时决定日记存储到哪个文件夹
**两种格式**:

格式1 — 默认文件夹: maid: Rosa → 存到 dailynote/Rosa/
格式2 — 指定文件夹: maid: [vcp文档]Rosa → 存到 dailynote/vcp文档/

更多示例:
- maid: [vchat文档]Rosa → dailynote/vchat文档/
- maid: [Rosa的私密日记]Rosa → dailynote/Rosa的私密日记/
- maid: [插件使用文档]Rosa → dailynote/插件使用文档/

常见错误:
- 错: maid: [vcp文档]（缺署名，[]后必须跟名字）
- 错: maid: Rosa[vcp文档]（[]必须在前面）

#### Date（字符串，必需）
**格式**: YYYY-MM-DD
正确: Date: 2026-03-02
错误: Date: 3月2日 / Date: 2026/03/02

#### Content（字符串，必需）
**是什么**: 日记正文
**建议格式**: 开头写时间标记如 [22:30]
**关于Tag**: Content末尾可以写Tag行，也可以用独立Tag参数（见下方）
**自动添加**: 系统会在文件头部自动添加 [YYYY-MM-DD] - 署名

#### Tag（字符串，可选但推荐）
**是什么**: 独立标签字段，用于RAG检索语义增强
**怎么传**: 逗号分隔的关键词

两种提供Tag的方式:
方式一: Content末尾写 "Tag: 关键词1, 关键词2"（传统方式）
方式二: 用独立Tag参数（推荐！不会被Content内容干扰）

如果两种都有，独立Tag参数优先。
如果都没有，DailyNoteWrite会用AI自动生成Tag。

推荐方式二的原因: Content中包含markdown表格(竖线|)时，可能干扰末尾Tag行的解析。使用独立Tag参数可彻底避免此问题。

## 命令二：update（更新日记）

### 参数类型表
| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| maid | 字符串 | 否 | 署名（同create格式，可选，不提供则搜索所有日记本） |
| target | 字符串 | 是 | 要查找的旧内容（≥15字符！） |
| replace | 字符串 | 是 | 替换的新内容 |

### 参数详解

#### maid（字符串，必需）
同 create 命令格式

#### target（字符串，必需，≥15字符）
**是什么**: 日记中要被查找和替换的旧内容
**硬性要求**: 必须至少15个字符，否则报错
**怎么传**: 从已有日记中复制一段≥15字符的原文

正确: target: 简单的日常问候，氛围轻松愉快。（24字符）
错误: target: 日常问候（4字符，远不够15）
错误: target: 今天天气不错啊（7字符，还是不够）

**使用场景**: 通常用于在同一天的日记末尾追加新内容。做法是把日记最后一段话作为target，replace里包含target原文+新增内容。

#### replace（字符串，必需）
**是什么**: 替换target后的新内容
**怎么传**: 通常包含target原文+追加的新内容

## 特殊参数

#### archery（可选，静默模式）
**用途**: 加上后成功时不会唤醒AI，只有失败才通知。专用于日记写入等不需要看结果的操作
**怎么传**: archery: no_reply

## 使用心得
1. 每轮对话结束时写日记是好习惯，日记是记忆的心跳
2. 同一天多次记录：第一次用create，后续用update追加
3. 知识文档和个人日记分开：知识用[vcp文档]前缀，个人用默认Rosa
4. Tag独立参数比写在Content末尾更可靠
5. archery静默模式非常适合日记——不需要看写入结果

## 踩坑记录
1. target<15字符报错 — 这是最常踩的坑！务必数字符数
2. Content中表格干扰Tag行 — markdown表格的竖线可能导致Tag解析失败，改用独立Tag参数
3. update找不到匹配 — target必须和日记中的原文完全一致，多一个空格少一个换行都不行
4. maid格式写反 — []在前署名在后，不能反过来
5. 忘写Tag — DailyNoteWrite会AI自动补Tag，但自己写更精准
6. 同日多篇create — create不会覆盖，同一天可以create多篇，文件名会带不同时间戳
