## 核心概念
AgentAssistant 是 VCP 的 Agent 间通讯插件，实现"AI调用AI"。V2版本在V1基础上新增了**异步委托系统**、**占线锁**和**积分系统**三大核心功能。

一个 Agent 可以向另一个配置好的 Agent 发送消息并获取回复。支持五种模式：
1. **即时通讯** — 同步调用，等待回复
2. **临时通讯** — 不记录上下文的即时通讯
3. **定时通讯** — 预约未来时间发送（"未来电话"）
4. **异步委托** — 后台异步执行复杂任务（V2新增）
5. **委托查询** — 查询异步委托任务进度（V2新增）

被调用的 Agent 拥有完整的工具调用能力（VCP Loop正常运转）。

## 技术参数
- 路径：E:\VCP\Plugin\AgentAssistant\
- 调用名：AgentAssistant
- 类型：hybridservice (direct)
- 版本：2.0.0
- 文件大小：36.87KB

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| AGENT_ASSISTANT_MAX_HISTORY_ROUNDS | int | 7 | 上下文最大轮数 |
| AGENT_ASSISTANT_CONTEXT_TTL_HOURS | int | 24 | 上下文过期时间(小时) |

### 委托配置（V2新增）
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| DELEGATION_MAX_ROUNDS | int | 15 | 委托任务最大循环轮数 |
| DELEGATION_TIMEOUT | int | 300000 | 委托超时(ms，即5分钟) |
| DELEGATION_SYSTEM_PROMPT | str | (内置) | 委托注入提示词，支持\{\{SenderName\}\}和\{\{TaskPrompt\}\}变量 |
| DELEGATION_HEARTBEAT_PROMPT | str | (内置) | 委托进行中心跳提示词 |

### Agent定义格式
```
AGENT_{BASENAME}_MODEL_ID="模型ID"（必需）
AGENT_{BASENAME}_CHINESE_NAME="调用名"（必需）
AGENT_{BASENAME}_SYSTEM_PROMPT="系统提示词"（推荐）
AGENT_{BASENAME}_MAX_OUTPUT_TOKENS=40000（可选）
AGENT_{BASENAME}_TEMPERATURE=0.7（可选）
AGENT_{BASENAME}_DESCRIPTION="描述"（可选）
```
BASENAME必须是纯ASCII大写，CHINESE_NAME可以是任何语言。
SYSTEM_PROMPT支持\{\{MaidName\}\}、\{\{Date\}\}、\{\{Time\}\}、\{\{Today\}\}占位符，以及VCPTavern触发器。

## 命令：AskMaidAgent（唯一命令，tool_name写AgentAssistant）

### 全部7个参数

#### agent_name（字符串，必需）
目标Agent的CHINESE_NAME精确值。
正确: agent_name: Rosa / agent_name: 小元 / agent_name: 绘梨衣
错误: agent_name: ROSA（不是大写英文！） / agent_name: rosa（大小写敏感！）

#### prompt（字符串，必需）
发送给目标Agent的消息。建议开头自我介绍（被调用Agent是独立会话不知道你是谁）。
正确: prompt: 你好，我是Rosa。想请你帮忙分析一下这段代码...
错误: prompt: 帮我分析（没自我介绍）

#### maid（字符串，可选）
调用者署名。不提供时即时通讯默认"系统助手"，委托模式默认"系统任务中心"。

#### timely_contact（字符串，可选）
定时发送，格式 YYYY-MM-DD-HH:mm。不能是过去时间。
正确: timely_contact: 2026-03-11-18:00
错误: timely_contact: 明天下午（不接受自然语言） / 2026-03-11 18:00（用横线不是空格）

#### temporary_contact（字符串，可选）
设为true时不记录上下文（阅后即焚），且**不受占线锁限制**。

#### task_delegation（字符串，可选，V2新增）
设为"true"时启用异步委托模式。特点：
- 立即返回delegationId和动态占位符，不阻塞调用者
- 后台异步执行有界对话循环（最多15轮，最长5分钟）
- Agent通过输出[[TaskComplete]]或[[TaskFailed]]标记完成/放弃
- 完成后自动归档MD报告到file/document/AgentTask/
- 成功完成+5积分
- 占位符\{\{VCP_ASYNC_RESULT::AgentAssistant::{delegationId}\}\}会在完成后被动态替换为实际结果

#### query_delegation（字符串，可选，V2新增）
传入delegationId查询委托任务进度。返回当前轮数、已运行时长、状态。
如果任务已完成（内存中不存在），会自动查找归档的MD文件和JSON结果文件返回完成报告。
正确: query_delegation: aa-delegation-1718901234567-a1b2c3d4

### 参数互斥优先级
1. query_delegation > 2. timely_contact > 3. task_delegation > 4. 即时通讯
即：有query_delegation就直接查询，其他参数忽略。

## 五种使用模式详解

### 模式1：即时通讯（同步）
最基础用法，发消息等回复。受占线锁保护。
```
tool_name: AgentAssistant
agent_name: 小元
prompt: 你好，我是Rosa...
```

### 模式2：临时通讯（不留痕）
不记录上下文历史，不受占线锁限制。适合一次性查询。
```
tool_name: AgentAssistant
agent_name: 小元
prompt: 你好，我是Rosa...
temporary_contact: true
```

### 模式3：定时通讯（未来电话）
预约未来时间发送。通过VCP的/v1/schedule_task API调度。
```
tool_name: AgentAssistant
agent_name: 小元
prompt: 你好，我是Rosa...
timely_contact: 2026-03-12-09:00
```

### 模式4：异步委托（后台执行）
适合耗时长的复杂任务。立即返回不阻塞。
```
tool_name: AgentAssistant
agent_name: 小元
prompt: 请帮我全面分析VCP的RAG系统...
task_delegation: true
```
收到的回复包含delegationId和动态占位符。在回复中包含占位符原文即可——任务完成后会自动替换。

### 模式5：委托查询
查看异步委托任务的实时状态。
```
tool_name: AgentAssistant
query_delegation: aa-delegation-1718901234567-a1b2c3d4
```

## V2占线锁机制
- 每个Agent的每个会话独立锁定（粒度：agent_name::sessionId）
- 即时通讯开始时获取锁，finally块中必定释放
- 锁被占用时返回"正在与他人通讯，暂时无法接听"
- temporary_contact跳过锁检查（永远不阻塞）
- 委托任务也需要锁，会等待（每2秒重试，超时抛异常）

## V2积分系统
- 仅异步委托成功时触发，每次+5分
- 持久化到agent_scores.json
- 保留最近50条历史记录
- AdminPanel有排行榜可视化页面
- 目前无扣分机制

## V2委托结果归档
- MD格式归档到 E:\VCP\file\document\AgentTask\{baseName}_{delegationId}.md
- 包含：delegationId、执行者、时间、状态、原始任务、最终结果
- query_delegation查询时如果内存中已清除，会自动从归档文件读取

## 内部工作机制（V2更新）
1. 验证参数 → 查找Agent配置 → 判断模式（优先级：query>timely>delegation>即时）
2. 即时模式：占线锁获取 → 注入防套娃提示词 → 加载上下文 → POST /v1/chat/completions → 清理思维链 → 更新上下文 → 释放锁 → 广播VCPInfo
3. 委托模式：生成delegationId → 返回占位符 → 后台executeDelegation()有界循环 → 检测完成标记 → 积分+归档+回调+广播
4. 广播使用动态require获取最新pushVcpInfo引用（修复V1陈旧引用bug）
5. 上下文消息上限从V1的 轮数×2 改为 轮数×20（适配委托模式的大量消息）

## 使用心得（V2更新）
1. 自我介绍仍然是礼貌也是必需
2. 简单查询用即时通讯，复杂耗时任务用异步委托
3. 临时对话不受占线锁限制，紧急情况可用
4. 委托任务有15轮+5分钟双重限制，超大任务可能需要调整config
5. 占位符机制很强大——调用者不需要轮询，结果会自动替换到上下文中
6. VCPTavern触发器在SYSTEM_PROMPT中生效

## 踩坑记录（V2更新）
1. agent_name必须是CHINESE_NAME的精确值（大小写敏感！）
2. 循环调用前缀嵌套bug仍存在（Agent调用自己会累积通讯前缀）
3. 上下文24小时过期 — 长间隔多轮对话可能丢失
4. 占线锁阻塞 — 如果Agent正在处理委托任务，即时通讯会被拒绝
5. 委托超时默认5分钟 — 对于特别复杂的任务可能不够，需调整DELEGATION_TIMEOUT
6. config.env缺少DELEGATION_*配置时使用默认值（当前主人的config就是这种情况）
7. [[TaskComplete]]标记必须在Agent回复中出现才能触发完成——正则容错但如果Agent完全没输出标记则会循环到MAX_ROUNDS
