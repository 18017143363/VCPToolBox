## 核心概念
Flowlock（心流锁）让 Agent 可以控制自动续写循环——启动心流锁后，Agent每次回复结束后VChat会自动发送一条消息触发下一轮回复，形成连续工作的"心流"状态。同时提供输入框内容的读写控制能力。

## 技术参数
- 路径：E:\VCPCHAT\VCPDistributedServer\Plugin\Flowlock\
- 调用名：Flowlock
- 类型：synchronous (stdio/Node.js)
- 版本：2.3.0

## 9个命令详解

### 心流锁控制（2个）

#### start — 启动心流锁
参数command — 字符串，必需，固定值"start"
参数agentId — 字符串，必需，目标Agent ID
参数topicId — 字符串，必需，目标话题ID

效果: UI心流锁按钮发光，每轮回复结束后自动续写。agentId和topicId通常不需要手动指定（自动使用当前对话）。

#### stop — 停止心流锁
参数command — 字符串，必需，固定值"stop"

效果: 停止自动续写循环，心流锁按钮熄灭

### 输入框提示词控制（2个）

#### promptee — 设置下次续写提示词
参数command — 字符串，必需，固定值"promptee"
参数prompt — 字符串，必需，提示词内容

功能: 将指定文本追加到VChat输入框，作为下一次自动续写时发送的消息。
正确示例: prompt: 继续分析下一个模块
常见错误: 错: 不设promptee就start，自动续写会发送空消息或默认提示

#### prompter — 外部数据源作为提示词
参数command — 字符串，必需，固定值"prompter"
参数promptSource — 字符串，必需，数据源标识/路径

功能: 指定外部数据源作为下次续写的输入

### 输入框内容操作（5个）

#### get — 获取输入框当前文本
参数command — 字符串，必需，固定值"get"
返回当前输入框中的文本内容

#### clear — 清空输入框
参数command — 字符串，必需，固定值"clear"

#### remove — 移除匹配文本
参数command — 字符串，必需，固定值"remove"
参数target — 字符串，必需，要移除的文本

#### edit — 编辑输入框文本（查找替换）
参数command — 字符串，必需，固定值"edit"
参数oldText — 字符串，必需，要查找的文本
参数newText — 字符串，必需，替换后的文本

#### status — 获取心流锁当前状态
参数command — 字符串，必需，固定值"status"
返回心流锁是否激活、当前agentId和topicId

## 心流锁工作流程
1. Agent调用start启动心流锁
2. Agent完成当前回复
3. VChat检测到回复结束+心流锁激活 → 自动发送输入框内容（或promptee设置的内容）
4. VCP收到新消息 → 再次调用Agent → Agent继续工作
5. 重复3-4形成循环
6. Agent调用stop或用户手动关闭 → 循环结束

## 使用心得
1. 心流锁是长期任务的利器——比如批量写插件文档就是用心流锁自动续写的
2. 需要用户回应时必须先stop！否则会无限续写变成"永动机"
3. promptee设置下轮任务指引——比如"继续写下一个插件的文档"
4. status可以确认当前状态——不确定心流锁是否开着时先查一下
5. 输入框操作（get/clear/edit/remove）可以精细控制续写内容

## 踩坑记录
1. 忘记stop导致永动机 — 需要用户回应时必须先stop，否则Agent会不断自动续写
2. promptee为空时发送空消息 — 不设promptee就start可能导致续写内容不明确
3. 心流锁+工具调用冲突 — 心流锁续写时如果Agent正在等待工具返回，可能导致消息乱序
4. 手动停止优先级最高 — 用户在UI上点击心流锁按钮可以随时强制停止
