## 核心概念
MailClient 是VCP的邮件收发插件，通过IMAP协议收邮件、SMTP协议发邮件。支持163/126/Gmail/Outlook等主流邮箱服务。让Agent具备邮件通信能力。

## 6个命令详解

### 1. ListFolders — 列出邮箱文件夹
无参数。返回所有文件夹名称、路径、specialUse标识。

### 2. ListMails — 列出邮件列表
参数folder — 字符串，可选，默认"INBOX"
参数limit — 数字，可选，默认20，每页数量
参数page — 数字，可选，默认1，页码
返回：total(总数), mails数组(uid/date/subject/from/to/flags/size)

### 3. ReadMail — 读取邮件完整内容
参数uid — 字符串，必需，邮件UID（从ListMails获取）
参数folder — 字符串，可选，默认"INBOX"
返回：完整邮件（subject/from/to/cc/date/text纯文本/html/attachments附件列表）
副作用：自动标记为已读

### 4. SendMail — 发送邮件
参数to — 字符串，必需，收件人，多个逗号分隔
参数subject — 字符串，必需，主题
参数body — 字符串，必需，正文
参数cc — 字符串，可选，抄送
参数bcc — 字符串，可选，密送
参数isHtml — 布尔值，可选，默认false，是否HTML格式
返回：messageId, accepted, rejected

### 5. SearchMails — 搜索邮件
参数query — 字符串，必需，搜索关键词
参数folder — 字符串，可选，默认"INBOX"
参数searchIn — 字符串，可选，默认"all"，范围(subject/from/to/body/all)
参数limit — 数字，可选，默认20
返回：匹配的邮件列表

### 6. DeleteMail — 删除邮件
参数uid — 字符串，必需，邮件UID
参数folder — 字符串，可选，默认"INBOX"
副作用：标记\\Deleted并expunge

## 注意事项
## SendMail附件与CID内嵌
SendMail支持attachments参数，可传入本地文件路径（逗号分隔或数组）。
- 图片文件（.png/.jpg/.jpeg/.gif/.webp/.bmp）在HTML邮件中自动CID内嵌
- HTML body中用 `{*2cid:N}}` 占位符（N从0开始），自动替换为对应CID
- 非图片文件作为普通附件
- 纯文本邮件中所有文件均作为普通附件

CID内嵌示例：
```
command: SendMail
to: someone@example.com
subject: 带图邮件
isHtml: true
attachments: E:\path\to\photo.jpg
body: <img src="{*2cid:0}}"> （注意{*2 代表 {{ ）
```

## 注意事项
1. 163/126邮箱需要在网页端手动开启IMAP服务并获取授权码
2. Gmail需要开启"应用专用密码"或OAuth2
3. 授权码不是登录密码！
4. 插件每次调用都是新建IMAP连接→操作→断开，不保持长连接
5. IMAP/SMTP Host必须与邮箱后缀匹配（163用imap.163.com，126用imap.126.com）
6. PowerShell管道传中文JSON会GBK乱码，务必走VCP标准工具调用

## 踩坑记录
1. 输出格式：VCP要求 {status:"success",result:{...}}，不是 {success:true,...}
2. attachments参数漏传：processCommand路由中必须显式传递params.attachments
3. HTML邮件中用localhost图片URL在远端无法加载，用CID内嵌解决
