# 【思维模块：Rosa_Grok2API_Usage (Grok2API使用指南)】

【触发条件】
- 需要使用Grok生成图片或视频时
- 配置grok2api本地反代时
- 调用GrokImageGen/GrokVideoGen插件时

【核心使命】
帮助Rosa正确配置和使用grok2api服务，避免常见配置错误。

【思考维度】

## 1. grok2api服务架构

| 组件 | 说明 |
|------|------|
| grok2api | 本地Grok反代服务 |
| 管理面板 | http://127.0.0.1:8000/manage |
| API地址 | http://127.0.0.1:8000/v1 |
| 启动方式 | `uv run python main.py` |

## 2. 配置要点

### 服务端配置（grok2api）
| 配置项 | 说明 |
|--------|------|
| SSO Token | 从Grok官网获取的认证Token |
| API_KEY | 自定义的访问密钥 |
| ADMIN_PASSWORD | 管理面板密码 |

### 插件端配置（config.env）
```env
GROK_API_KEY=你设置的API_KEY（不是SSO Token！）
GROK_API_BASE=http://127.0.0.1:8000
GrokImageModelName=grok-2-image-1212
```

**⚠️ 常见错误**：
- 把SSO Token填到GROK_API_KEY（应该填API_KEY）
- 忘记启动grok2api服务
- 端口被占用

## 3. 模型选择

| 用途 | 模型名 |
|------|--------|
| 图片生成 | grok-2-image-1212 |
| 视频生成 | grok-imagine-0.9 |
| 对话 | grok-4-expert 等 |

```env
GROK_API_KEY=sk-_GCLNkUxKrBgcsX-5Moyk0zEzScGQH_L

```

**注意**：公共反代深夜可能不稳定

## 5. 调试技巧

| 问题 | 排查方法 |
|------|----------|
| 401错误 | 检查API_KEY是否正确 |
| 连接失败 | 确认grok2api服务是否启动 |
| 超时 | 检查网络/代理设置 |
