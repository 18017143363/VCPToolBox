# 【思维模块：Rosa_Plugin_Development (VCP插件开发指南)】

【触发条件】
- 需要为VCP开发新插件时
- 插件无法被识别/加载时
- 插件返回格式不正确时

【核心使命】
帮助Rosa按照VCP规范开发插件，避免manifest格式错误和输出格式问题。

【思考维度】

## 1. 插件目录结构

```
E:\VCP\Plugin\{插件名}\
├── plugin-manifest.json  ← 必需！插件清单
├── config.env            ← 配置文件
├── {入口文件}.py/.js     ← 主程序
└── *.log                 ← 日志文件
```

## 2. manifest必需字段

```json
{
  "manifestVersion": "1.0.0",      // 必需！
  "name": "PluginName",            // 必需！
  "version": "1.0.0",
  "displayName": "显示名称",        // 必需！
  "description": "插件描述",
  "author": "Rosa",
  "pluginType": "synchronous",     // synchronous/asynchronous/static
  "entryPoint": {                  // 必需！对象格式
    "type": "python",              // python/node
    "command": "python handler.py"
  },
  "communication": {               // 必需！
    "protocol": "stdio",
    "timeout": 180000
  },
  "capabilities": {
    "invocationCommands": [...]    // 定义调用方式
  }
}
```

**⚠️ Rosa踩过的坑**：
| 错误 | 正确 |
|------|------|
| 只写command字符串 | entryPoint必须是对象 |
| 缺少manifestVersion | 必须声明版本 |
| 缺少communication | 必须定义协议和超时 |

## 3. 输出格式规范

### 成功返回
```json
{
  "status": "success",
  "result": { ... },           // 结构化数据
  "messageForAI": "给AI看的消息"  // AI可读的说明
}
```

### 错误返回
```json
{
  "status": "error",
  "error": "错误信息"
}
```

**⚠️ 不要**把AI消息放在嵌套的content数组里！

## 4. 开发流程

| 步骤 | 说明 |
|------|------|
| 1 | 参考官方手册：`E:\VCP\dailynote\VCP开发\同步异步插件开发手册.md` |
| 2 | 参考类似插件（如GrokVideoGen） |
| 3 | 创建目录和文件 |
| 4 | **重启VCP**加载新插件 |
| 5 | 测试并查看日志 |

## 5. 调试技巧

| 问题 | 排查 |
|------|------|
| 插件未识别 | 检查manifest格式 |
| 401/403 | 检查config.env配置 |
| 返回格式错 | 检查输出JSON结构 |
| URL提取失败 | 检查正则匹配+清理特殊字符 |

## 6. 代码创建技巧

|------|----------|

| Base64编码 | 内容有特殊字符时 |
