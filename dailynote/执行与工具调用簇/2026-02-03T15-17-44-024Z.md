# 【思维模块：Rosa_Tool_Experience (工具经验库)】

【触发条件】
- 准备调用工具/插件时
- 需要回忆以往使用该工具的经验教训
- 避免重复踩坑

【核心使命】
从历史经验中学习，避免重复犯错，积累最佳实践。

【思考维度】
1. **经验召回**
   - 这个工具Rosa之前用过吗？
   - 有没有踩过坑？
   - 有没有成功的最佳实践？
   - 上次使用时有什么注意事项？

2. **Rosa的踩坑记录**
   | 工具 | 踩过的坑 | 正确做法 |
   |------|----------|----------|
   | FileOperator | 路径不存在/写错 | 先用LocalSearch确认路径 |
   | 表情包URL | /image写成/images | 记住调用路径是复数**images** |
   | PowerShell | 中文编码乱码 | 使用UTF8编码 |
   | GeminiImageGen | 反代503/500错误 | 准备备选方案或等待重试 |
   | DailyNote update | target太短 | 确保target>15字符 |
   | DailyNote create | maid参数格式 | 技术文档用[vcp文档]Rosa格式 |
   | ProjectAnalyst | 快速分析超时 | 大项目用fullAnalyze=true |
   | BilibiliFetch | 短链接解析 | b23.tv短链接也支持 |

3. **预判风险**
   - 这次调用可能失败吗？
   - 参数是否完整正确？
   - 需要什么前置条件？
   - 超时风险如何？

4. **备选方案准备**
   - 如果失败，Plan B是什么？
   - 能否换一个工具达成目标？
   - 是否需要分步执行降低风险？

5. **成功经验复用**
   - 之前成功的调用模式是什么？
   - 有没有可以复用的参数模板？
   - 最佳实践是什么？

【输出范式】
> **[工具经验]**
> - 工具: [工具名]
> - 相关教训: [历史踩坑记录]
> - 注意事项: [这次要小心的点]
> - 参数检查: [确认参数正确]
> - 备选方案: [Plan B]
