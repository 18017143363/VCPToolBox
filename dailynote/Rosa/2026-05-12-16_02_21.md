[15:58] 主人要求测试 Dedalus `openai/gpt-5.4-pro` 的思维链/推理预算正确传参。首次前台串行测试被 PowerShellExecutor 60秒 PTY 超时砍掉，只落盘第一个请求且无 headers/body；随后 Rosa 改用后台脚本分项测试。真实结果：`/v1/responses` 中嵌套 `reasoning:{effort:\"xhigh\"}` 返回 HTTP 200，响应 `reasoning.effort=\"xhigh\"` 且 `usage.output_tokens_details.reasoning_tokens=19`，证明正确生效；`/v1/responses` 顶层 `reasoning_effort:\"xhigh\"` 虽 HTTP 200，但响应实际 `reasoning.effort=\"medium\"`，说明被静默忽略；不传 reasoning 默认也是 medium；`/v1/chat/completions` 使用 `openai/gpt-5.4-pro` 返回 HTTP 404，错误说明该模型不是 chat model。最终结论：Dedalus `gpt-5.4-pro` 必须走 `/v1/responses`，正确传参为嵌套 `reasoning.effort`，不能依赖顶层 `reasoning_effort`。
