## 踩坑记录
1. newSession:true会重置PTY，暂存区丢失——不要在add之后用newSession
2. git restore --staged对untracked文件=完全移出暂存区（而非只unstage指定目录）
3. git reset HEAD -- path/对untracked add -f的文件同样会清空所有暂存（因为HEAD中这些文件不存在）
4. 排除特定目录的正确做法：从源头不add，而非add后再unstage
5. commit+push超时≠失败，要用git log确认实际状态
