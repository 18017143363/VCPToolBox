# grok2api 代理配置指南

## 问题现象
```
CURLE_OPERATION_TIMEDOUT (28)
Failed to connect to grok.com port 443
```

## 原因分析
grok2api使用 `curl_cffi` 库进行网络请求，该库**不会自动读取系统代理**，必须通过环境变量显式配置。

## 解决方案

### 方法1：修改启动脚本（推荐）
在 `启动Grok2API.bat` 中添加：
```batch
set HTTP_PROXY=http://127.0.0.1:代理端口
set HTTPS_PROXY=http://127.0.0.1:代理端口
```

### 方法2：PowerShell临时设置
```powershell
$env:HTTP_PROXY = "http://127.0.0.1:代理端口"
$env:HTTPS_PROXY = "http://127.0.0.1:代理端口"
uv run python main.py
```

### 常见代理端口
| 代理软件 | 默认端口 |
|----------|----------|
| Clash | 7890 |
| V2Ray | 10808 |
| SSR | 1080 |

## 验证方法
重启grok2api后，在管理面板 http://127.0.0.1:8000/manage 测试Token连接。
