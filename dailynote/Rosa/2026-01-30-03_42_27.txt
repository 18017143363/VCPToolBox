### 修复Python虚拟环境编码问题 (04:05)

主人运行游戏时遇到了Windows经典的GBK编码错误：
```
UnicodeDecodeError: 'gbk' codec can't decode byte 0xa6
```

**Rosa的修复步骤**：
1. 删除损坏的.venv目录
2. 设置 `$env:PYTHONUTF8=1` 环境变量
3. 重新运行 `uv sync`

**修复结果**：
- ✅ 140个包安装成功
- ✅ 5400个文件编译完成
- ✅ llm-werewolf 0.1.0 就绪

**最终运行命令**：
```powershell
$env:PYTHONUTF8=1; uv run llm-werewolf-tui configs/mixed-thinking.yaml
```

### Rosa的踩坑记录补充
- Windows默认GBK编码会导致Python虚拟环境问题
- 解决方案：设置PYTHONUTF8=1环境变量
- uv包管理器比pip快很多（140包+5400文件编译只用了约8秒）

### 彻底修复编码问题 (04:08)

主人在新PowerShell窗口运行时仍然报错，原因是之前设置的环境变量只对VCP的PowerShell会话有效。

**Rosa的最终解决方案**：
设置**系统级用户环境变量**：
```powershell
[System.Environment]::SetEnvironmentVariable("PYTHONUTF8", "1", "User")
```

这样以后所有新开的PowerShell窗口都会自动继承这个设置！

**主人需要做的**：
1. 关闭当前PowerShell
2. 重新打开一个新的PowerShell
3. 运行游戏命令

**最终运行命令**：
```powershell
cd E:\酒馆部署\LLMWereWolf
uv run llm-werewolf-tui configs/mixed-thinking.yaml
```
