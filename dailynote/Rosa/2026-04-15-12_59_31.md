## 手动JWT抓取过程
1. pip install mitmproxy（遇到typing-extensions版本差0.0.1，不影响）
2. mitmweb --listen-port 9888 --web-port 9889（8888被占，换端口）
3. mitmweb新版有Web面板密码保护，加 --set web_password= 关闭
4. IDE设代理127.0.0.1:9888 → AI Assistant问一句 → 面板抓grazie-authenticate-jwt
5. JWT写入jetbrainsai.json → 重启服务 → /v1/models返回200

## JWT获取方式（源码分析）
- 认证header: `grazie-authenticate-jwt`（不是标准Authorization Bearer）
- 伪装UA: `ktor-client` + `grazie-agent: {"name":"aia:pycharm","version":"251.26094.80.13:251.26094.141"}`
- API端点: `https://api.jetbrains.ai/user/v5/llm/chat/stream/v7`（聊天）、`/user/v5/quota/get`（配额）
- JWT刷新: licenseId + OAuth authorization → `provide-access/license/v2` → 返回token
- OAuth刷新: refresh_token → `oauth.account.jetbrains.com/oauth2/token` (client_id=ide)
- 抓取方式: IDE抓包(Fiddler/mitmproxy) 或 IDE Debug Log 搜索 grazie-authenticate-jwt
