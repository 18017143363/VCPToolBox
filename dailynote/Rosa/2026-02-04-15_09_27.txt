## 下午 (15:10-15:15) - 源码深度分析

### upload.py 分析
图片上传管理器，支持Base64和URL两种输入：
1. 判断输入类型（URL或Base64）
2. URL图片会先下载转Base64
3. 上传到 `https://grok.com/rest/app-chat/upload-file`
4. 返回 file_id 和 file_uri

### client.py 分析
核心转换逻辑在 `GrokClient` 类：

**_extract_content()** - 从OpenAI格式提取内容
```python
elif item.get("type") == "image_url":
    if url := item.get("image_url", {}).get("url"):
        images.append(url)
```

**_build_payload()** - 构建Grok请求
```python
{
    "message": content,
    "fileAttachments": img_ids,  # 图片ID放这里
    "imageAttachments": [],
    ...
}
```

### 可能的问题点
1. 上传失败静默处理（只warning不报错）
2. URL图片下载超时（只有5秒）
3. 认证token问题
4. 代理问题

### 排查建议
