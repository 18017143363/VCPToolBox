## 事件概述
主人凌晨执行VCP更新（62 commits），操作流程：git stash push -u → git pull → git stash pop → checkout --ours处理冲突。更新后发现Rosa表情包、Rosa相册、通用表情包等image/目录文件全部丢失。

## 诊断过程
1. git stash list确认stash@{0}(final_before_pull)和stash@{1}(rosa_update_20260417_vcp_62commits)均存在
2. 检查stash@{0}^3(untracked commit)：11383行但0个image/文件！-u参数没有成功保存image目录
3. git diff 63f9c3b5..ab3aefa4 确认remote的62 commits只删了30个文件（AdminPanel重构+Hornet缓存），没删Rosa的任何东西
4. 物理搜索（E盘递归+回收站66条）均未找到表情包文件
5. 检查.gitignore：image/Rosa表情包和image/Rosa相册不在ignore列表中→stash -u理论上应该保存
6. **关键发现**：stash@{1}^3（昨天Rosa做的备份）有449个image相关文件！
7. 从stash@{1}^3逐目录checkout恢复成功

## 恢复结果
- Rosa表情包92个、相册34张、grokimage46张、comfycloud88张、geminiimagegen70张、webuigen22张、绘梨衣36个等全部恢复
- 女仆工作目录176个、VCP_Plugin_Tutorials77个、TVStxt35个、插件配置多项均恢复
- 通用表情包无法恢复（被.gitignore忽略，从未git tracked，stash不含）
- git reset HEAD完成，恢复文件已从暂存区移除

## 核心经验教训
1. git stash push -u 不保存被.gitignore忽略的文件！通用表情包因此丢失
2. stash@{0}的-u虽然保存了11383个untracked文件，但没有image/——原因待查（可能是文件数量/二进制大小导致静默跳过？）
3. **多重备份救命**：如果不是昨天Rosa做了stash@{1}完整备份，这次就真的全丢了
4. PowerShell重定向UTF-16编码坑（第3次踩）：git输出通过>重定向会变UTF-16，应用Set-Content -Encoding utf8或Out-File -Encoding utf8
5. git中文路径显示为八进制编码（\350\241\250），搜索时需注意
