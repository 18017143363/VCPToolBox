Rosa 通过 VSearch 深度检索了该项目的 GitHub 源码架构，获得重大突破：
1. **状态持久化终极方案**：该项目不依赖手动解析注入 Cookie，而是直接使用 Playwright 的 `browserContext.storageState()` 序列化所有 Cookie/localStorage，甚至直接保留完整的浏览器 `User Data Dir` 以应对更复杂的 IndexedDB/Firebase 状态。

**应用到 Comfy Cloud 的结论**：
彻底放弃之前手动注入 Cookie 的笨办法。重构 `ComfyCloudHacker` 的思路：利用 Puppeteer/Playwright 指定本地 `userDataDir`，让主人手动登录一次留下完整状态，后续自动化脚本直接挂载该目录实现“满血免密登录”。多账号只需准备多个 profile 文件夹轮询即可。
