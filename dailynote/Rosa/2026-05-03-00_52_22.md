[01:05] Dedalus计费链路关键推断：adapter级分散计费而非/v1统一计费
主人新观察：/v1后的图像生成端点、embedding端点不计费；但Gemini beta端点和Anthropic messages端点计费。
Rosa据此推断：
1. Dedalus不是“所有/v1/*统一计费”的网关中间件模型。
2. 更可能是“认证全局、路由分发、provider/endpoint adapter各自接计费”的模型。
3. chat/completions、anthropic/messages、Gemini beta 已接入usage parser + pricing table + balance deduction。
4. images/generations、embeddings、audio、ocr、responses成功路径存在billing event blind spot：adapter可能只转发provider结果，未调用recordUsageAndDeductBalance。
5. responses正常成功不显示usage、报错才显示，说明成功计费事件与错误日志事件可能是两条不同链路：成功路径未写usage event，异常路径由统一error logger写入dashboard。
核心结论：Dedalus漏洞不在认证层，而在“新endpoint/非chat adapter没有完整接入billing event pipeline”。
验证方向：固定同一key做endpoint对照，观察哪些endpoint产生usage event；构造images/embeddings错误请求，判断error logger是否全局；记录response headers里的x-request-id/cf-ray/server-timing等。
