[17:40] PowerShell反射分析.NET DLL的实践经验

## 场景
分析鬼谷八荒MelonLoader mod的DLL代码结构，系统上无dnSpy/ILSpy。

## 方法
```powershell
$bytes = [System.IO.File]::ReadAllBytes('path/to/mod.dll')
$asm = [System.Reflection.Assembly]::Load($bytes)
# GetTypes()会抛异常，需要捕获
try { $types = $asm.GetTypes() }
catch [System.Reflection.ReflectionTypeLoadException] {
    $types = $_.Exception.Types | Where-Object { $_ -ne $null }
}
```

## 踩坑
1. 直接GetTypes()必定失败——mod DLL依赖Assembly-CSharp和UnityEngine，本机没有这些程序集
2. 关键技巧：捕获ReflectionTypeLoadException后从.Types属性取已加载的类型
3. GetMethods()的GetParameters()也可能因参数类型缺依赖而报错，需要逐方法try-catch
4. 用BindingFlags组合获取Public+NonPublic+Instance+Static+DeclaredOnly才能拿到全部方法

## 效果
Mod_Tc85Yz.dll (160KB) → 成功提取131个类型，包含类名、基类、部分方法签名、属性getter/setter、枚举、嵌套类结构

## 局限
- 无法获取方法体（需要真正的反编译器）
- 依赖游戏类型的方法参数读不出来
- Harmony特性内容（具体Hook哪个方法）无法获取
