## 新方向：AI修仙项目
主人提出核心构想：为鬼谷八荒添加接口层，让外部AI（大模型）接入游戏，拥有与玩家同等权限进行修仙。

### 初步架构构想
```
外部AI (LLM/Agent)
    ↕ HTTP/WebSocket JSON API
接口桥接Mod (MelonLoader DLL)
    ↕ Harmony Hook + 游戏内部API调用
鬼谷八荒游戏本体
```

### AI需要的接口分类（待细化）
1. **感知接口（读取）**
   - 玩家/NPC状态：WorldUnitBase.data/conf/allLuck/allEquips/allEffects/isDie
   - 世界状态：WorldMgr子管理器（地图/宗门/事件/剧情）
   - 配置数据：ConfMgr的953种配置表
   - 战斗状态：WorldBattleMgr.isBattle/data

2. **决策接口（写入/操作）**
   - 行为执行：WorldUnitBase.CreateAction(UnitActionBase)
   - 气运操作：CreateLuck/DestroyLuck
   - 装备管理：CreateEquip/DestroyEquip
   - 任务系统：CreateTask/DelTask
   - 战斗控制：WorldBattleMgr.IntoBattle/BattleEnd
   - NPC交互：Npc类(23方法)
   - UI操作：UI类(28方法)

3. **事件回调（通知AI）**
   - 月结事件：RoundStart/RoundEnd
   - 战斗事件：BattleEnd(isWin)
   - 死亡事件：onDieCall
   - 奇遇触发：fortuitousTrigger
   - 剧情触发：dramaTrigger

## AI修仙项目 — 技术方案确定
### 通信方案（VSearch验证）
- 协议：WebSocket + JSON-RPC 2.0（双向实时通信）
- C#端库：websocket-sharp（IL2CPP兼容性最佳，社区验证）
- 线程调度：ConcurrentQueue<Action> + OnUpdate主线程消费（业界标准模式）
- 端口：12701
### 关键开源参考
- WickerREST(github.com/derekShaheen/WickerREST) — 专为MelonLoader设计的REST框架，最直接参考
- secrethistories-api-mod — 完整游戏API桥接案例
- MCP-Unity — AI控制Unity的MCP协议实现
- SynthRiders-Websockets-Mod — MelonLoader WebSocket实现
### AI端架构（参考Voyager）
- Agent主循环：等待游戏事件→感知状态→LLM决策→执行行动→记录记忆
- 技能库：将修炼策略编码为可复用的行动模板
- 记忆系统：修仙经历的向量化存储与检索
### 接口分类
- 感知接口12个：getPlayerState/getLucks/getEquips/getEffects/getTasks/getNpcList/getNpcDetail/getWorldState/getBattleState/getSchoolInfo/getMapInfo/getConfTable
- 行动接口10个：createAction/addLuck/removeLuck/equipItem/unequipItem/createTask/interactNpc/enterBattle/exitBattle/executeCmd
- 事件回调7个：round_start/round_end/battle_end/unit_die/fortuitous/drama/task_complete
### MVP路线
v0.1: WebSocket服务器+getPlayerState+round_start事件(1-2天)
v0.2: 完整感知接口(2-3天)
v0.3: 基础行动接口(2-3天)
