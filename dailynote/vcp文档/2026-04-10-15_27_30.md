## 源码实现分析 (daily-hot.js)

### 1. stdout劫持（核心工程技巧）
```javascript
const _originalStdoutWrite = process.stdout.write.bind(process.stdout);
process.stdout.write = () => true;
console.log = () => {};
console.error = () => {};
```
**为什么需要这样做**：dist/routes/下的55个模块来自第三方（DailyHot开源项目），内部使用各种日志库直接写stdout。如果不劫持，这些日志会混入VCP期望的JSON输出，导致Plugin.js JSON.parse失败。
保留_originalStdoutWrite用于最终输出唯一一次合法JSON。
console.error也被屏蔽（双保险），所有调试日志改用console.error在劫持前不可见。

### 2. 数据源动态发现
```javascript
const routesDir = path.join(__dirname, 'dist', 'routes');
const files = await fs.readdir(routesDir);
allSources = files.filter(file => file.endsWith('.js')).map(file => path.basename(file, '.js'));
```
**设计优点**：不硬编码源列表，扫描routes目录自动发现。新增平台只需放一个.js进去，删除平台只需移除文件。零配置扩展。

### 3. fetchSource()数据标准化
每个route模块必须导出`handleRoute`函数，返回格式：
```javascript
{
  title: "平台名",
  type: "热榜/热搜/...",
  data: [{ title: "标题", url: "链接", category?: "自定义分类" }]
}
```
fetchSource将其标准化为统一的`{category, title, url}`格式。
category优先使用条目自带的，fallback到"平台名 - 热榜类型"。

### 4. 并发抓取与容错
```javascript
const promises = allSources.map(source => fetchSource(source));
const results = await Promise.allSettled(promises);
```
使用Promise.allSettled而非Promise.all——单个源失败不会导致整体失败。对55个源至关重要，因为任何一个都可能因网络/反爬/API变更而失败。

### 5. vcp_dynamic_fold构建 — buildFoldFromResults()
核心输出结构：
```javascript
{
  vcp_dynamic_fold: true,
  plugin_description: "每日热榜新闻聚合插件，汇集科技、社会、游戏、财经等多源实时热点新闻与热搜话题",
  fold_blocks: [
    { threshold: 0.5, content: "每源Top3标题列表" },
    { threshold: 0.35, content: "每源Top1头条列表" },
    { threshold: 0.0, content: "已缓存N个源 + 缓存文件路径" }
  ]
}
```
**fold策略设计分析**：
- threshold 0.5：用户问热点新闻时，展开每个分类前3条，信息量适中
- threshold 0.35：轻度相关时只给头条，节省token
- threshold 0.0：完全无关时仅一句话待机，附带完整缓存文件路径供AI按需读取
- **pathNote**：所有层级都附带`dailyhot_cache.md`的绝对路径，AI在需要完整数据时可通过FileOperator读取

### 6. 缓存降级 — buildFoldFromCache()
当实时抓取失败时，从dailyhot_cache.md解析：
```javascript
const headlineMatch = line.match(/^\d+\.\s+\[(.+?)\]\(.*?\)$/);
// 匹配Markdown格式的"1. [标题](链接)"
```
从缓存取前30条做高相关、前10条做中相关，构建降级版fold。

### 7. 三重保护机制
```javascript
// 内部30秒超时
const timeoutPromise = new Promise((_, reject) =>
    setTimeout(() => reject(new Error('Internal script timeout')), 30000));
const result = await Promise.race([fetchAndProcessData(), timeoutPromise]);
```
1. **Promise.race 30秒超时**：防止某个源卡死拖垮整体
2. **manifest 120秒超时**：VCP层面的进程级超时保护
3. **最终兜底**：连缓存都读不到时，返回"数据不可用"的fold（确保永远返回合法JSON）

### 8. 最终输出
```javascript
const output = JSON.stringify(foldOutput, null, 2);
_originalStdoutWrite(output, 'utf-8', () => { process.exit(0); });
```
使用保存的原始stdout.write输出JSON，回调中process.exit(0)确保干净退出。

## 设计亮点总结
1. **stdout劫持**：解决第三方模块日志污染stdio协议的问题，工程上非常老练
2. **动态源发现**：零配置扩展，扫描目录即自动接入新平台
3. **Promise.allSettled容错**：55个源任意失败不影响整体
4. **vcp_dynamic_fold三级折叠**：按语义相关度智能展开，高效利用token
5. **pathNote设计**：fold中附带缓存文件绝对路径，AI可按需FileOperator读取完整数据
6. **三重保护**：内部超时+manifest超时+最终兜底，确保永远返回合法输出
