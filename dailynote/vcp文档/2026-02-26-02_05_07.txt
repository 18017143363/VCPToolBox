[02:04] VCP Code 2.0 (Kilo Code) CLI配置体系

## 概述
VCP Code 2.0的CLI后端(kilo.exe)使用XDG规范管理配置、数据和缓存。

## 路径体系
| 类型 | Windows路径 | 用途 |
|------|------------|------|
| config | C:\Users\{user}\.config\kilo | 配置文件 |
| data | C:\Users\{user}\.local\share\kilo | 数据(DB/auth/log) |
| cache | C:\Users\{user}\.cache\kilo | 缓存(models/node_modules) |
| state | C:\Users\{user}\.local\state\kilo | 状态信息 |
| bin | C:\Users\{user}\.local\share\kilo\bin | 内置工具(rg.exe) |

## 配置文件加载顺序
kilo依次尝试加载（后者覆盖前者）：
1. config.json
2. opencode.json
3. opencode.jsonc

## 自定义Provider配置格式 (config.json)
```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "model-id",
  "provider": {
    "provider-id": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "显示名称",
      "options": {
        "baseURL": "http://api-base/v1",
        "apiKey": "key或{env:ENV_VAR}"
      }
    }
  }
}
```

## 凭据存储
- 文件: ~/.local/share/kilo/auth.json
- 通过 `kilo auth login/logout/list` 管理
- 通过VS Code UI或CLI /connect 交互式配置

## 数据库
- SQLite: ~/.local/share/kilo/kilo.db
- 存储会话、消息等数据

## CLI关键命令
| 命令 | 用途 |
|------|------|
| kilo serve | 启动headless服务器(VS Code扩展调用) |
| kilo auth list | 列出已配置凭据 |
| kilo debug paths | 显示所有路径 |
| kilo debug config | 显示当前配置 |
| kilo models | 列出可用模型 |

## VS Code扩展 vs CLI 双配置体系
- CLI: ~/.config/kilo/config.json（kilo.exe读取）
- VS Code: settings.json 的 kilocode.* 配置项（扩展UI读取）
- 两者独立，需分别配置
