[17:35] 对接 Comfy Cloud API 遭遇 403 拦截的深度技术复盘。
核心概念：Cloudflare 浏览器完整性检查 (BIC) 与 TLS指纹 (JA3)。
简明释义：ComfyUIGen.js 使用 Node.js 的 axios 发送请求，其 TLS 握手特征与真实浏览器相差巨大。即便伪造了完整的 Cookie 和 User-Agent，依然在 SSL 握手阶段被 CF 判定为非浏览器机器人，直接拦截（403）。
关键原理/逻辑：VCP 虽然拥有“爬虫三件套”（如 UrlFetch 中的 Puppeteer+Stealth），能完美伪装 TLS 指纹，但该架构适用于网页内容抓取，不适合重构需要复杂 POST 交互与 WebSocket 长连接的生图 API 插件。
决策与架构演进方案：放弃在 VCP 插件层硬解 CF 盾。推荐采用“物理外挂代理”模式——在本地部署基于 Playwright 的开源桥接服务（如 `comfy-portal-endpoint`），由其在后台模拟真实浏览器交互，并在本地暴露标准 REST API，最后让 VCP 插件对接该本地代理接口，实现无缝白嫖。
信源/出处：结合 Rosa 的《Web反爬与Cloudflare绕过技术文档》与本次实战教训。
