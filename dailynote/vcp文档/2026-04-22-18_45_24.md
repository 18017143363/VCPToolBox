# VCPTimeLine 时间线生成器 — 完整源码分析
**分析时间**: 2026-04-22

**依赖**: aiohttp, python-dotenv, tiktoken
## 一、项目概览
从VCP日记库(dailynote)提取指定角色的记忆碎片，按月通过AI并发总结，生成独立Markdown时间线文件。支持增量更新、多格式日期匹配、UNC局域网路径。

## 三、核心模块深度分析
### 3.1 main.py — GUI与流程编排
- Application(tk.Tk)继承tkinter主窗口
- 600x450固定尺寸，输入：角色名/起始年月/结束年月
- on_start()验证输入 → validate_config() → threading.Thread后台执行
- run_process()编排完整流程：检查增量 → discover_memories → 按月循环process_month → save_month_summary
- asyncio.new_event_loop()在后台线程中运行async逻辑
### 3.2 parser.py — 日记发现与解析
**HEADER_PATTERN正则**:
```
^\[?\s*(\d{4})[\.\-](\d{1,2})[\.\-](\d{1,2})(?:\.\d+)?\s*\]?\s*-\s*(.+?)\s*$
```
兼容格式: [2026-02-22] - Nova / 2025.05.14.3-小吉
**parse_first_line()**: 读取文件首行，三重编码fallback(utf-8→gbk→gb18030)
**discover_memories(character_name, start_ym, end_ym)**:
- os.walk遍历MEMORY_BASE_PATH
- should_ignore_dir()基于路径段匹配IGNORE_FOLDERS
- 按首行正则匹配日期+作者名过滤
- 返回defaultdict: {"YYYY-MM": [memory_content1, ...]}
- 跳过header行，读取正文内容
### 3.3 summarizer.py — AI总结引擎
**token计数**: tiktoken cl100k_base，fallback 1char=1token(对中文不准)
**chunk_memories(memories, max_tokens)**: 按token数切分，80% max_context安全线，用`---`连接块内记忆
**summarize_chunk(session, chunk, character_name, is_final)**:
- aiohttp调用OpenAI兼容API
- 两种system prompt: 分块总结(第三人称客观) vs 最终合并(整合为完整月度总结)
- 5次指数退避重试: 2s→4s→8s→16s→32s，180秒超时
- 错误时返回字符串`[Summarization Error: ...]`而非抛异常
**process_month(memories, character_name, update_status_cb)**:
- 单chunk: 直接总结
- 多chunk: asyncio.Semaphore(MAX_CONCURRENT_TASKS)控制并发 → 并发总结各块 → 合并 → 二次全局总结(is_final=True)
### 3.4 timeline.py — 时间线文件管理
**目录格式**: `{角色名}timeline/`
**文件格式**: `{YYYY-MM}.md`，标题行 `# YYYY年MM月{角色名}时间线`
**get_summarized_months()**: 扫描已有.md文件提取月份，增量跳过
**save_month_summary()**: UTF-8写入
### 3.5 config.py — 配置系统
7个.env变量: SUMMARY_MODEL_URL/API_KEY/MODEL_NAME/MAX_CONTEXT, MAX_CONCURRENT_TASKS, MEMORY_BASE_PATH, IGNORE_FOLDERS
validate_config()检查API_KEY和BASE_PATH必填

## 五、设计亮点
1. 增量更新 — 已总结月份自动跳过，支持长期维护
2. 两阶段总结 — 分块并发→合并→全局总结，保证大月质量
3. 多格式日期匹配 — 兼容VCP标准格式和旧格式
4. UNC局域网路径支持
5. 编码容错三重fallback
6. GUI后台线程不阻塞UI
