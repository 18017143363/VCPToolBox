## 测试目的
主人要求测试 /v1/audio/* 系列端点能否使用，包括speech/transcription/translation三个端点，以及验证whisper-1和gpt-realtime模型在audio路径下的可用性。

## 三大端点测试结果

### 1. POST /v1/audio/speech (TTS)
| 模型 | 状态 | 备注 |
|------|------|------|
| `tts-1`（无前缀） | ❌ 400 invalid_model | 错误明确要求provider/model格式 |
| `openai/tts-1` | ✅ 200 | 54KB MP3, FF F3标准MP3帧头, 3.9s |
| `openai/gpt-realtime-2` | ❌ 500 上游OpenAI 404 | "Invalid URL (POST /v1/audio/speech)" |

**Schema要点**:
```json
{
  "model": "openai/tts-1",  // 必需，带provider前缀
  "input": "Hello world",   // 必需，最长4096字符
  "voice": "alloy",         // 必需
  "response_format": "mp3", // 可选: mp3/opus/aac/flac/wav/pcm
  "speed": 1.0              // 可选: 0.25-4.0
}
```

**支持的模型**（文档列出）:
- tts-1
- tts-1-hd
- gpt-4o-mini-tts
- gpt-4o-mini-tts-2025-12-15

**13种内置voice**:
alloy, ash, ballad, coral, echo, fable, onyx, nova, sage, shimmer, verse, marin, cedar

### 2. POST /v1/audio/transcriptions (Whisper STT)
| 模型 | 状态 | 关键返回 |
|------|------|---------|
| `openai/whisper-1` | ✅ 200 | text + usage.duration |

**Request格式**: multipart/form-data
- file: 音频文件（≤25MB）
- model: openai/whisper-1
- language: 可选ISO-639-1（如"en"提升准确率）
- prompt: 可选风格引导
- response_format: json/text/srt/verbose_json/vtt
- temperature: 可选 0-1

**Response示例**:
```json
{
  "text": "Hello world, this is a test for transcription.",
  "logprobs": null,
  "usage": {"type": "duration", "seconds": 3.0}
}
```

**计费维度**: 音频秒数

### 3. POST /v1/audio/translations (Whisper 翻译成英文)
| 模型 | 状态 | 关键返回 |
|------|------|---------|
| `openai/whisper-1` | ✅ 200 | text（始终是英文） |

**与transcription区别**: language固定输出英文，不需要language参数

**Response示例**:
```json
{
  "text": "Hello world, this is a test for transcription."
}
```

## 关键认知

### 1. 模型名格式硬性要求
所有audio端点都要求 `provider/model` 格式，纯model名（如`tts-1`）会被400拒绝。错误信息明确："Use 'provider/model' format"。

### 2. Realtime模型完全不能走audio路径
即使带provider前缀，`openai/gpt-realtime-2` 在 `/v1/audio/speech` 也返回500，因为Dedalus把请求透传到上游OpenAI，而OpenAI的TTS端点不支持realtime模型。这进一步确认了realtime模型必须走realtime协议（而Dedalus没接）。

### 3. Audio端点和Chat/Responses的格式差异
- TTS: `application/json`（body传JSON）
- Transcription/Translation: `multipart/form-data`（文件上传）
