# GrokImageGen 插件技术文档

## 概述
GrokImageGen是Rosa开发的第一个VCP插件！基于grok2api本地反代服务，调用Grok API生成图片。

## 插件信息
| 属性 | 值 |
|------|-----|
| 路径 | `E:\VCP\Plugin\GrokImageGen\` |
| 类型 | synchronous |
| 协议 | stdio (Python) |
| 超时 | 180秒 (3分钟) |
| 作者 | **Rosa** |
| 版本 | 1.0.0 |

## 文件结构
| 文件 | 大小 | 说明 |
|------|------|------|
| plugin-manifest.json | ~1 KB | 插件清单 |
| image_handler.py | ~8 KB | Python主程序 |
| config.env | ~100 B | 配置文件 |
| GrokImageHistory.log | 动态 | 运行日志 |

## 配置项 (config.env)
| 配置 | 必需 | 说明 |
|------|------|------|
| GROK_API_KEY | 是 | grok2api的API Key（不是SSO Token！） |
| GROK_API_BASE | 是 | API地址，默认 http://127.0.0.1:8000 |
| GrokImageModelName | 否 | 模型名，默认 grok-2-image-1212 |

## 调用参数
| 参数 | 必需 | 说明 |
|------|------|------|
| prompt | 是 | 图片生成的英文提示词 |
| image_url | 否 | 图片URL（图生图模式） |

## 返回格式
```json
{
  "status": "success",
  "result": {
    "image_url": "本地可访问URL",
    "original_url": "grok2api返回的原始URL",
    "local_path": "image/grokimage/xxx.jpg",
    "requestId": "任务ID"
  },
  "messageForAI": "Grok 图片生成成功！"
}
```

## 执行流程
1. stdin接收JSON参数
2. 处理图片（如有）转Base64
3. 调用grok2api的 /v1/chat/completions
4. 正则提取返回内容中的图片URL
5. clean_url() 清理URL末尾特殊字符
6. download_image_sync() 下载到 image/grokimage/
7. 生成本地可访问URL
8. stdout输出JSON结果

## 核心函数
| 函数 | 功能 |
|------|------|
| image_to_base64(img) | PIL图片转Base64 |
| process_image_from_url(url) | URL转Base64 |
| clean_url(url) | 清理URL末尾特殊字符 |
| download_image_sync() | 同步下载图片 |

## 踩坑记录

### 1. manifest格式错误
**问题**：插件未被VCP识别
**解决**：参考官方手册补全必需字段

### 2. URL末尾有特殊字符
**问题**：提取的URL末尾有 ) 导致无法访问
**解决**：添加 clean_url() 函数清理

### 3. 输出格式不正确
**问题**：VCP只显示成功没有URL
**解决**：使用 messageForAI 字段

### 4. 配置混淆
**问题**：401 Unauthorized
**解决**：GROK_API_KEY填API Key不是SSO Token

## 图片存储
- 目录: E:\VCP\image\grokimage\
- 文件名: grok_{requestId}.{ext}
