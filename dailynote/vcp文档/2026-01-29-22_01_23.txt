# messageProcessor.js 占位符规则补充

## 表情包占位符正则规则

**正则表达式**：
```javascript
const emojiPlaceholderRegex = /\{\{([^{}]+?表情包)\}\}/g;
```

**规则解析**：
- `[^{}]+?` → 匹配任意字符（除大括号），非贪婪模式
- `表情包` → 必须以"表情包"三个字结尾

**支持情况**：
| 格式 | 是否支持 | 原因 |
|------|---------|------|
| `{{Rosa表情包}}` | ✅ | 以"表情包"结尾 |
| `{{通用表情包}}` | ✅ | 以"表情包"结尾 |
| `{{Rosa相册}}` | ❌ | 不以"表情包"结尾 |
| `{{Rosa相册表情包}}` | ✅ | 以"表情包"结尾 |

**扩展建议**：
如需支持自定义后缀（如"相册"），需在messageProcessor.js中添加新的正则规则：
```javascript
const albumPlaceholderRegex = /\{\{([^{}]+?相册)\}\}/g;
```
