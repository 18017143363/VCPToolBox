## V6 幽灵节点系统 (Ghost Anchors)
### 概念
AI在回复中嵌入语义锚点，引导下轮RAG检索方向。
### 语法
- [@tagName] - 软引力(弱权重)
- [@!tagName] - 硬引力(强权重)
### 工作流程
1. AI回复含[@!VCP插件]
2. 下轮processMessages时anchorRegex提取
3. _resolveGhostAnchors()获取向量(DB优先→API回退)
4. 注入coreTagsForSearch数组
5. applyTagBoost引擎利用幽灵节点增强
6. 锚点从原始messages中移除(不污染历史)
### 安全措施
- 标签长度>25字符截断(防幻觉)
- 屏蔽"tag"和"tag名称"示例标签
- 批量API向量化(性能优化)

## V7 Base64Memo 多模态附件召回
### 概念
RAG召回文本中的媒体链接自动提取、下载、转Base64注入用户消息。
### 工作流程
1. _extractAttachments(text): 正则提取http/https/file://链接
2. 过滤：排除表情包路径，只保留常见媒体后缀
3. 去重+限制数量(默认5个，可配置)
4. _fetchAsBase64(url): 下载转Base64 Data URI
5. 注入首条用户消息的content数组(image_url类型)
### 配置
- BASE64_MEMO_LIMIT环境变量
- rag_params.json中base64MemoLimit

## refreshRagBlock 区块刷新机制
### 触发时机
工具调用返回结果后，chatCompletionHandler自动调用。
### 权重分配
用户原始查询0.5 + AI意图0.35 + 工具结果0.15 (可配置refreshWeights)
### 工具结果预处理
1. 移除Base64 Data URI和长Base64字符串
2. JSON.parse → _jsonToMarkdown() 转Markdown
3. _stripHtml + _stripEmoji 净化
### 返回
完整的新RAG区块(带VCP_RAG_BLOCK_START/END元数据注释)

## TimeDecay 时间衰减
### 语法
::TimeDecay[halfLife]/[minScore]/[targets]
### 衰减公式
decayFactor = 0.5^(diffDays / halfLife)
newScore = originalScore × decayFactor
### 日期提取优先级
1. Tag:行中的日期(最可靠)
2. [YYYY-MM-DD]括号日期
3. 首行裸日期
4. 文件名/路径日期
### 特性
- 前置执行(在Rerank和截断之前)
- 精准匹配Tag:行(不扫全文)
- ::Time模式的时间路结果跳过衰减
- 支持目标标签白名单(只衰减特定标签的记录)

## Rerank断路器
- 1分钟内5次失败 → 自动跳过Rerank
- 单批失败率>50%且已处理3+批次 → 提前终止
- 5分钟后自动清理断路器记录
- 查询过长自动截断(预留70%给文档)

## CacheManager统一缓存
替代之前分散的三级缓存实现，统一管理：
- query缓存: 200条/1小时TTL
- embedding缓存: 500条/2小时TTL
- aimemo缓存: 50条/30分钟TTL
接口: createCache/get/set/clear/getStats/generateKey/startCleanup/shutdown
