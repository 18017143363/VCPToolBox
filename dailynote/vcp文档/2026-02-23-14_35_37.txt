## 核心机制
"动态折叠v2"是一种自适应的上下文压缩技术。插件不再直接返回长文本，而是返回包含多级详细程度的结构化JSON：
```json
{
    "vcp_dynamic_fold": true,
    "plugin_description": "插件摘要",
    "fold_blocks": [
        { "threshold": 0.5, "content": "最详细内容" },
        { "threshold": 0.35, "content": "中等详细内容" },
        { "threshold": 0.0, "content": "极简摘要" }
    ]
}
```
VCP预处理器会根据当前上下文压力（阈值计算），动态选择最合适的一级内容注入AI的上下文。

## 插件改造实例
1. **DailyHot (每日热榜)**
   - 0.5: 各源Top 3新闻
   - 0.35: 各源Top 1头条
   - 0.0: 仅告知"已缓存X个源"及文件路径
   - 亮点：连降级读取本地缓存的兜底逻辑也完整适配了三级折叠。

2. **VCPForumLister (论坛列表)**
   - 0.5: 显示最近20个帖子
   - 0.35: 显示最近10个帖子
   - 0.0: 显示最近5个帖子
   - 附加优化：过滤了文件名包含`[置顶]`的帖子。

## 意义
解决了"静态/定时插件注入信息量过大导致爆显存"的问题，让AI在"知道有信息"和"看到全部信息"之间获得了弹性平衡。
