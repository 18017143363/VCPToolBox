# ZImageGen2 插件技术文档

## 概述
ZImageGen2是VCP新增的阿里通义Z-Image-Base图像生成插件，相比原版ZImageGen提供更高质量的图像生成能力。

## 插件信息
- 路径: `E:\VCP\Plugin\ZImageGen2\`
- 类型: synchronous
- 协议: stdio (Node.js)
- 超时: 45秒 (manifest) / 5分钟 (代码内)
- 版本: 1.1.0
- 作者: VCP Team

## 与ZImageGen对比

| 特性 | ZImageGen | ZImageGen2 |
|------|-----------|------------|
| 后端模型 | Z-Image-Turbo | **Z-Image-Base** |
| 推理步数 | 9步 | **28步** |
| 负向提示词 | ❌ | ✅ |
| CFG引导 | ❌ | ✅ (默认4) |
| CFG归一化 | ❌ | ✅ |
| 图片质量 | 快速生成 | **高质量生成** |
| API端点 | mrfakename-z-image-turbo.hf.space | aisudo-z-image-base.hf.space |
| 代理配置 | 需要代理 | 默认关闭代理 |

## 调用参数

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| prompt | string | ✅ | - | 图像描述，支持中英文 |
| negative_prompt | string | ❌ | "" | 负向提示词 |
| resolution | string | ❌ | 1024x1024 | 分辨率 |
| steps | int | ❌ | 28 | 推理步数 |
| cfg | float | ❌ | 4 | CFG引导强度 |
| cfg_normalization | bool | ❌ | false | CFG归一化 |
| seed | int | ❌ | 42 | 随机种子 |
| showbase64 | bool | ❌ | false | 是否返回base64 |

## 执行流程

1. stdin接收JSON参数
2. POST `/queue/join` 加入队列，获取event_id
3. GET `/queue/data` SSE监听进度
4. 解析SSE消息类型：
   - heartbeat: 心跳
   - estimation: 队列位置
   - process_starts: 开始处理
   - progress: 进度更新
   - process_completed: 完成，提取图片URL
   - error/queue_full: 错误处理
5. 下载图片保存到 `image/zimagegen/`
6. 返回可访问URL

## 重试机制

- 最大重试: 3次
- 重试延迟: attempt × 2000ms
- SSE超时: 2分钟
- 全局超时: 5分钟

## 图片存储

- 目录: `E:\VCP\image\zimagegen\`
- 文件名: UUID.png
- URL格式: `{VarHttpUrl}:{PORT}/pw={KEY}/images/zimagegen/{filename}`

## 使用场景

- 需要高质量图片时使用ZImageGen2
- 需要负向提示词排除不想要的元素
- 需要CFG调节控制生成强度
- 对生成速度要求不高的场景
