## 一、server.js 优雅重启系统重做

### 生命周期状态机
RUNNING → DRAINING → SHUTTING_DOWN → EXITING

### 10阶段关闭流水线
| Phase | 操作 |
|-------|------|
| 0 | 记录shutdown请求 |
| 1 | WebSocket drain（停止接受升级） |
| 2 | HTTP server close + 销毁空闲socket |
| 3 | 等待活跃请求排空（30秒） |
| 4 | 强制中止剩余请求（SSE发[DONE]） |
| 5 | 状态→SHUTTING_DOWN |
| 6 | taskScheduler.shutdown |
| 7 | webSocketServer.shutdown |
| 8 | pluginManager.shutdownAllPlugins |
| 9 | knowledgeBaseManager.shutdown |
| 10 | 关闭日志流 |

### 关键机制
- 排水中间件：DRAINING状态拒绝新请求，白名单（restart/lifecycle/interrupt/callback）除外
- 流式请求优雅中止：给SSE流发shutdown消息+[DONE]
- 60秒强制超时兜底
- 幂等shutdown：shutdownPromise防止重复执行
- Socket追踪：trackedSockets/activeHttpRequests精确销毁空闲连接
- 新增API：GET /admin_api/server/lifecycle

## 二、toolCallParser.js 转义机制

### ESCAPE标记系统
- 「始ESCAPE」/「末ESCAPE」 — 包裹需要保护的内容
- 转义映射表：TOOL_REQUEST_ESCAPE → TOOL_REQUEST等

### 结构化重构
- extractNextToolBlock() — 公开静态方法，跳过ESCAPE区域
- parseBlock() — 公开静态方法，可复用（/v1/human/tool也用）
- _scanFields() — 逐字段扫描器，支持普通/ESCAPE两种标记
- _findBlockEnd() — 智能查找块结束标记（跳过ESCAPE）

## 三、Plugin.js 事件驱动改造
