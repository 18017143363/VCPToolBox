# WebUIGen 插件技术文档

## 概述
WebUIGen是VCP的Stable Diffusion云算力图像生成插件，调用外部SD API生成高质量图像。

## 插件信息
- 路径: `E:\VCP\Plugin\WebUIGen\`
- 类型: synchronous
- 协议: stdio
- 超时: 120秒 (manifest) / 180秒 (代码内)
- 作者: Kilo Code
- API端点: `https://sd.exacg.cc/api/v1/generate_image`

### Z-Image 特殊说明
- 基于阿里通义Z-Image-Turbo
- **必须设置steps=8**（不是默认的20）
- 支持**中文自然语言**提示词
- 适合不熟悉英文tag的用户

## 命令参数

### WebUIGenerate
| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| prompt | string | 是 | - | 图像生成提示词 |
| negative_prompt | string | 否 | "" | 负面提示词 |
| resolution | string | 否 | 512x512 | 分辨率 |
| steps | int | 否 | 20 | 生成步数 (1-50) |
| cfg | float | 否 | 7.0 | CFG引导强度 (1-10) |
| model_index | int | 否 | 0 | 模型索引 |
| seed | int | 否 | -1 | 随机种子 (-1为随机) |
| showbase64 | bool | 否 | false | 是否返回base64数据 |

## 分辨率预设
| 预设名 | 尺寸 |
|--------|------|
| square | 512x512 |
| landscape | 768x512 |
| portrait | 512x768 |
| 1024 | 1024x1024 |
| WxH格式 | 自定义 |

## 核心函数

### parseResolution(resolution)
解析分辨率字符串，支持预设名和WxH格式。

### callWebUIAPI(args)
调用云算力API，返回生成结果。

### saveImage(imageUrl)
下载并保存图片到 `image/webuigen/` 目录，返回可访问URL。

## 工作流程
1. stdin接收JSON参数
2. 验证API Key
3. 解析分辨率
4. 调用sd.exacg.cc API
5. 下载生成的图片
6. 保存到本地并生成URL
7. 返回结果

## 返回格式
返回包含text和可选image_url的content数组，以及details对象。

## 与GeminiImageGen对比
| 特性 | WebUIGen | GeminiImageGen |
|------|----------|----------------|
| 后端 | Stable Diffusion | Gemini AI |
| 模型选择 | 8个模型 | 单一模型 |
| 负面提示词 | 支持 | 不支持 |
| 参数可控性 | steps/cfg/seed | 有限 |
| 图片编辑 | 不支持 | 支持 |
| 计费方式 | 点数制 | API调用 |

## 使用场景
- 需要特定风格（像素、真人、动漫）的图片
- 需要负面提示词排除不想要的元素
- 需要精细控制生成参数（步数、CFG、种子）
- 需要可复现的生成结果（固定seed）
