# VCP 插件文档 - PowerShellExecutor

## 概述
PowerShellExecutor 是VCP的系统命令执行插件，提供持久化的PowerShell会话，允许进行连续的系统操作。

## 核心特性

### 1. 持久化会话
- 变量在多次调用间保持
- 工作目录状态保持
- 类似真实终端的连续操作体验

### 2. 参数说明
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| command | string | 必需 | 要执行的PowerShell命令 |
| requireAdmin | boolean | false | 是否需要管理员权限 |
| newSession | boolean | false | 是否强制新建会话 |
| returnMode | string | 'delta' | 返回模式：delta(增量)/full(完整) |

### 3. returnMode 详解
- **delta**: 只返回当前命令的输出（默认，推荐日常使用）
- **full**: 返回整个终端窗口内容（调试时使用）

## 使用示例

### 基础命令
```
command: Get-Date
```

### 设置并使用变量
```
# 第一次调用
command: $myVar = "Hello"; Write-Host $myVar

# 第二次调用（变量仍然存在）
command: Write-Host "变量值: $myVar"
```

### 目录操作
```
# 切换目录
command: cd E:\VCP

# 后续命令自动在该目录下执行
command: Get-ChildItem -Name
```

## ⚠️ 注意事项

### 并发问题
**重要**: 避免同时发起多个PowerShell命令！

并发调用会导致：
- 变量状态丢失
- 命令执行顺序混乱
- 输出结果交错

**正确做法**: 顺序执行，等待每个命令返回后再发起下一个。

### 会话重置
如果会话状态异常，使用 `newSession: true` 强制重建：
```
command: Get-Date
newSession: true
```

### 管理员权限
需要提权操作时使用 `requireAdmin: true`，会弹出UAC确认框。

### 🛡️ 安全限制机制 (重要!)
VCP 实施了严格的关键字拦截策略（全文匹配，不区分大小写，包含注释）：

#### 1. 绝对禁止 (Forbidden)
- **关键字**: `rm`, `del`, `format`, `rmdir`
- **后果**: 直接阻止执行，返回错误。
- **注意**: 即使在注释中出现也会被拦截！例如 `Get-Date -Format` 会触发 `format` 拦截。
- **解决方案**: 使用替代方法，如 `.ToString("yyyy-MM-dd")`。

#### 2. 需要授权 (Auth Required)
- **关键字**: `net`, `shutdown`, `restart`, `New-Item`, `Remove-Item`, `Get-Content` 等
- **后果**: 必须提供 `requireAdmin: true` 参数，或通过弹窗确认。
- **场景**: 文件读写、系统重启、网络配置等敏感操作。

## 典型应用场景
1. 文件系统操作（创建、移动、删除）
2. 进程管理（启动、停止服务）
3. 系统信息查询
4. 批量文件处理
5. 环境变量管理
6. 项目构建和部署脚本
