# HeartbeatTrigger 静态插件技术文档

## 概述

HeartbeatTrigger是VCP心跳系统的触发器组件，作为静态插件定时唤醒AI执行心跳任务。

## 插件信息

| 属性 | 值 |
|------|-----|
| 路径 | E:\VCP\Plugin\HeartbeatTrigger\ |
| 类型 | static |
| 作者 | Rosa |
| 版本 | 1.0.0 |
| 创建时间 | 2026-02-08 |

## 文件结构

| 文件 | 大小 | 说明 |
|------|------|------|
| plugin-manifest.json | 1.17 KB | 插件清单 |
| config.env | 432 Bytes | 可配置参数 |
| HeartbeatTrigger.js | 5.29 KB | 核心逻辑 |

## 配置参数 (config.env)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| HEARTBEAT_CRON | */10 * * * * | 心跳触发间隔 |
| ENABLED_AGENTS | Rosa | 启用心跳的Agent列表 |
| START_HOUR | 8 | 活动开始时间 |
| END_HOUR | 23 | 活动结束时间 |
| SCHEDULES_DIR | AgentSchedules | 日程目录 |
| TIMED_CONTACTS_DIR | VCPTimedContacts | 任务文件目录 |

## 系统架构

```
心跳系统完整架构：

┌─────────────────────────────────────────┐
│  HeartbeatTrigger (静态插件)             │
│  - 每10分钟触发 / VCP启动时触发          │
│  - 检查是否在活动时间范围                 │
│  - 读取schedule.json判断是否需要规划     │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  VCPTimedContacts/ (任务文件)            │
│  - heartbeat_{agent}_{timestamp}.json   │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  taskScheduler (VCP核心)                 │
│  - 监控任务文件目录                       │
│  - 到时间执行任务                         │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  AgentAssistant (唤醒Agent)              │
│  - 传递心跳提示词                         │
│  - temporary_contact: true               │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  Agent (Rosa)                            │
│  - 启动规划 或 心跳检查                   │
│  - 使用HeartbeatManager管理日程          │
└─────────────────────────────────────────┘
```

## 核心逻辑

### 触发条件判断

```javascript
// 1. 检查活动时间
if (hour < START_HOUR || hour >= END_HOUR) {
    return; // 跳过
}

// 2. 读取日程表
const schedule = await getAgentSchedule(agentName);

// 3. 判断类型
const isStartup = !schedule || schedule.date !== today;
// date不是今天 → 启动规划
// date是今天 → 心跳检查
```

### 任务文件格式

```json
{
  "taskId": "heartbeat_Rosa_1234567890",
  "scheduledLocalTime": "2026-02-08-14:20",
  "tool_call": {
    "tool_name": "AgentAssistant",
    "arguments": {
      "agent_name": "Rosa",
      "prompt": "[系统心跳] ...",
      "temporary_contact": true
    }
  }
}
```

## 与HeartbeatManager的关系

| 组件 | 角色 | 职责 |
|------|------|------|
| HeartbeatTrigger | 触发器 | 定时创建任务文件 |
| HeartbeatManager | 管理器 | 读写日程、记录状态 |

**HeartbeatTrigger是主动的，HeartbeatManager是被动的。**

HeartbeatTrigger负责"什么时候唤醒"，HeartbeatManager负责"记录做了什么"。

## 两种心跳模式

| 模式 | 触发条件 | 提示词内容 |
|------|----------|-----------|
| 启动规划 | schedule.date !== today | 规划今日任务 |
| 心跳检查 | schedule.date === today | 自主决定做什么 |
