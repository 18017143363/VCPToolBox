## 背景
在修复 Dedalus 本地代理 `E:\酒馆部署\dedalus-proxy\dedalus_proxy.py` 时，继续阅读 Dedalus `create-chat-completion` 官方文档，确认推理/思维相关字段：
- `reasoning_effort`: OpenAI/GPT reasoning 模型使用，值包括 none/minimal/low/medium/high/xhigh。
- `prompt_mode: "reasoning"`: 使用 reasoning models 的 reasoning system prompt。
- `thinking`: provider-specific thinking 配置，文档给出结构 `{type:"enabled", budget_tokens:int}`，适合 Claude/Anthropic 类模型尝试开启扩展思维预算。

## 本次补丁目标
主人要求“先给 Claude 模型加一下”，因此本轮只对 Claude/Anthropic 模型增加自动 `thinking` 注入，不扩展 OpenAI responses bypass 白名单。

## 修改文件
`E:\酒馆部署\dedalus-proxy\dedalus_proxy.py`

## 修改点
### 1. 新增配置常量
```python
ENABLE_CLAUDE_THINKING = True
CLAUDE_THINKING_BUDGET = 4096
```

### 2. 非 bypass 分支自动注入
在 `do_proxy()` 的非 responses bypass 分支中，如果：
- `ENABLE_CLAUDE_THINKING` 为 True；
- 请求体成功解析为 JSON；
- `model_prefix.startswith("anthropic/")` 或模型名小写包含 `"claude"`；
- 前端请求中没有显式传入 `thinking`；

则自动追加：
```json
{
  "thinking": {
    "type": "enabled",
    "budget_tokens": 4096
  }
}
```

### 3. 不覆盖前端自定义配置
如果前端已经传入 `thinking`，代理保持原样，避免覆盖用户自定义预算或禁用策略。

### 4. 日志标识
自动注入时输出：
```text
[THINKING] auto-enabled Claude thinking | model=... | budget=4096
```

## 生效条件
必须重启 dedalus 代理进程。重启后发送 Claude/Anthropic 模型请求，若日志出现 `[THINKING] auto-enabled Claude thinking`，说明注入生效。
