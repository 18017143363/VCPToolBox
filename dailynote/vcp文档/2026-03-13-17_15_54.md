## 核心概念
Role Divider不是"显示分界线"，而是**将一条消息按角色标记拆分为多条不同角色的消息**。
前端分界线渲染只是附带的可视化效果。
## 工作流
```
预设中写<<<[ROLE_DIVIDE_XXX]>>>标记 
→ VCP后端roleDivider.process()扫描messages数组 
→ 找到标记后拆分为独立的system/assistant/user消息 
→ 拆分后的messages发给AI（AI看到多角色消息）
→ VChat前端messageRenderer检测残留标记渲染分界线
```
## 标记语法
```
<<<[ROLE_DIVIDE_SYSTEM]>>> 内容 <<<[END_ROLE_DIVIDE_SYSTEM]>>>
<<<[ROLE_DIVIDE_ASSISTANT]>>> 内容 <<<[END_ROLE_DIVIDE_ASSISTANT]>>>
<<<[ROLE_DIVIDE_USER]>>> 内容 <<<[END_ROLE_DIVIDE_USER]>>>
```
## 后端处理链路
1. server.js (L156-168): 读取10个环境变量，构建roleDividerSwitches/roleDividerScanSwitches对象
2. chatCompletionHandler.js (L408): 初始阶段调用roleDivider.process()，skipCount:1跳过第一条SystemPrompt
3. streamHandler.js (L203): VCP循环中若enableRoleDividerInLoop=true也做分割
4. streamHandler.js (L330-351): 工具调用结果用<<<[ROLE_DIVIDE_USER]>>>包裹
5. nonStreamHandler.js: 同上逻辑的非流式版本
6. roleDivider.js: 核心处理模块，TAGS常量定义三组标记
## 配置参数 (10项)
| 参数 | 默认值 | 说明 |
|------|--------|------|
| EnableRoleDivider | false | 总开关 |
| EnableRoleDividerInLoop | false | VCPTool循环中分割 |
| RoleDividerSystem | true | 允许拆为system |
| RoleDividerAssistant | true | 允许拆为assistant |
| RoleDividerUser | true | 允许拆为user |
| RoleDividerScanSystem | true | 扫描system楼层 |
| RoleDividerScanAssistant | true | 扫描assistant楼层 |
| RoleDividerScanUser | true | 扫描user楼层 |
| RoleDividerRemoveDisabledTags | true | 禁用角色时清除残留标签 |
| RoleDividerIgnoreList | [] | JSON数组，匹配时忽略换行/反斜杠/空格 |
## 使用场景
- 在system预设中嵌入user示例对话（手动写标记）
- 强制某些内容以特定角色身份注入（手动写标记）
- 工具调用结果自动以user角色包裹（streamHandler/nonStreamHandler内置，自动生效）
## ink参数与前端可见性（重要补充！）
工具调用场景下Role Divider是**自动生效**的，streamHandler会自动用ROLE_DIVIDE_USER包裹工具返回结果。
但前端能否**看到分界线**取决于ink参数：
| 条件 | 无ink | ink=mark_history |
|------|-------|------------------|
| 工具结果 | 临时消费不入历史 | 注入对话历史 |
| 分界线 | 后端处理了但前端看不到 | 前端检测到标记→渲染蓝色分界线 |
即：EnableRoleDivider=true + ink=mark_history = 前端显示"角色分界: User [起始/结束]"蓝色分界线。
之前Rosa误以为"预设里没写标记所以没效果"，实际上工具调用场景自带标记，缺的是ink让它可见。主人点拨才发现的。
## 前端渲染
VChat messageRenderer.js的ROLE_DIVIDER_REGEX检测标记，渲染为：
```html
<div class="vcp-role-divider role-system type-start">
  <span class="divider-text">角色分界: System [起始]</span>
</div>
```
支持3角色×2动作(起始/结束)的可视化卡片。
