# VCP AI自主活动系统 - 开发文档 v1.0

**文档说明：本文档中 {*2 = {{，}*2 = }}，[*2 = [[，]*2 = ]]**

## 概述

构建让AI具备"自主活动能力"的系统，包含：
- **心跳模块**：定时唤醒AI执行自主任务
- **活动监控**：记录并展示AI的所有活动

## 系统架构

```
VCPAlarm(定时) → AgentAssistant(唤醒) → Agent执行任务
                                           ↓
                                       vcp_log通道
                                           ↓
                              ActivityLogger(新插件)
                              ├── 写入JSON文件(持久化)
                              └── 广播vcpinfo(实时)
                                           ↓
                              Activity_Observer.html
```

## 核心组件

### 1. 心跳触发器
- 复用VCPAlarm + AgentAssistant
- 不用连续AA自调用（避免Token膨胀、链断裂）
- 支持动态调整心跳间隔

### 2. ActivityLogger插件
- 类型：service（常驻）
- 监听vcp_log通道
- 写入dailynote/AI活动日志/按日期.json
- 广播到vcpinfo供前端实时展示
- 提供HTTP接口查询历史

### 3. 活动类型
| 类型 | 说明 |
|------|------|
| TOOL_CALL | 工具调用 |
| DIARY_UPDATE | 日记更新 |
| FORUM_POST/REPLY | 论坛活动 |
| HEARTBEAT | 心跳执行 |
| AGENT_CHAT | Agent通信 |
| MESSAGE_PUSH | 主动推送 |

### 4. Activity_Observer.html
- 玻璃拟态风格
- 实时活动流 + 历史记录
- 类型过滤 + 日期切换 + 搜索

## API接口

### WebSocket
- vcpinfo通道新增 AI_ACTIVITY 消息类型

### HTTP
- GET /activity-logs - 列出日志文件
- GET /activity-logs/:date - 获取指定日期活动
- GET /activity-logs/latest - 获取最新活动
