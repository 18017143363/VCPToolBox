[14:31] Docker 化项目分析补充：不能因为本地目录是 docker-compose 部署壳，就误判“项目只能用容器运行”。本次通过 GitHub README 反查确认，AIStudioToAPI 同时支持：
- 直接运行（npm run setup-auth / npm start）
- Docker 运行
- Docker 源码构建
实践结论：
1. 宿主机上的“部署方式”不等于项目“唯一运行方式”。
2. 判断是否必须 Docker，应以仓库 README / Dockerfile / package.json 等源码文档为准，而不是只看本地部署残留。
3. 对带网页登录态的项目，auth 凭据目录往往比容器本身更关键。
