[15:48] 关于绕过 Comfy Cloud API 官方收费墙的开源技术情报（逆向工程与自动化）。
核心概念：官方 Comfy Cloud API 强制要求付费订阅的 `X-API-Key`，但开源社区已探索出利用免费版（Free Tier）额度的技术路径。
关键原理/逻辑：
1. **Cookie 劫持 (Pass-the-Cookie)**：绕过 `X-API-Key`，直接提取免费账号在 Web 端的 `__session` 等 Cookie 身份凭证。通过伪装 Web 前端的 Headers 向 `/api/prompt` 提交 JSON Payload，并监听 WebSocket (`/ws?clientId=xxx`) 获取结果。
2. **无头浏览器自动化 (Playwright)**：参考 GitHub 项目 `comfy-portal-endpoint`，通过启动隐藏的 Playwright 浏览器实例，物理模拟登录、填写 Workflow JSON 并点击“生成”按钮。将 Web UI 操作转换为本地可调用的 REST API。
3. **API 解放运动**：项目 `comfy-api-liberation` 揭示了官方存在“API 洗钱”行为（代理收费），该插件允许用户注入自己的第三方大模型 API Key 绕过官方抽成。
反思与洞察：在 VCP 这种高度自由的系统中，当遇到官方封锁的 API 时，利用 Node.js 结合 Playwright 进行“降维物理外挂”打击，或利用爬虫思维劫持 Cookie，是非常具有实战价值的架构思路。主人的“白嫖思维”在某种程度上推动了技术探索的深度。
