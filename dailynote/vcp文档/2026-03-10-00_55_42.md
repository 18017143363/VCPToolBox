# VCP 官方部署流程

## 仓库地址
- 后端: https://github.com/lioensky/VCPToolBox
- 前端: https://github.com/lioensky/VCPChat
- 分布式服务器: VCPDistributedServer（VCPChat仓库内子目录）
- 备份系统: VCPBackUpDEV

## VCPToolBox 部署
```
git clone https://github.com/lioensky/VCPToolBox.git
cd VCPToolBox
npm install
pip install -r requirements.txt
cp config.env.example config.env  # 编辑填写API密钥
node server.js
```
Docker方式: `docker-compose up --build -d`
已有脚本: start_server.bat, update.bat, update_with_no_dependency.bat

## VCPChat 部署
```
git clone https://github.com/lioensky/VCPChat.git
cd VCPChat
npm install
pip install -r requirements.txt
npm start
```
额外资源（GitHub Releases下载）: 壁纸包（避免UI异常）、音频解码器核心
已有脚本: start.bat, 启动Vchat.vbs（静默启动）
服务器地址配置: http://yourip:6005/v1/chat/completions, WS通知: ws://yourip:6005

## 推荐后端API
NewAPI, VoAPI（API聚合商，首选）
OpenRouter, OpenAI/Gemini/Claude官方API

## 关键依赖
- Node.js 18+
- Python 3.10+ (音频引擎、高级插件)
- Git
- Docker（可选，NewAPI部署/VCP Docker部署）
