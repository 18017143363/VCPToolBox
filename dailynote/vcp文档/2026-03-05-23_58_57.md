## 配置文件
路径：E:\cursor2api\config.yaml
默认配置即可使用，主要字段：port(3010)、model(anthropic/claude-sonnet-4.6)
## 启动方式
一键脚本：E:\cursor2api\启动cursor2api.bat
手动：cd E:\cursor2api && npx tsx src/index.ts
## 部署记录
1. git clone通过ghfast.top镜像（直连GitHub超时）
2. npm install安装87个包(9秒)
3. 默认配置直接启动成功
## TS版技术亮点
- 场景融合式提示词注入（告诉模型"你在Cursor IDE里运行"）
- 三层身份保护+50+拒绝拦截模式
- 上下文清洗（历史拒绝响应自动改写为成功）
- Chrome TLS指纹模拟
- 双协议兼容（OpenAI + Anthropic）
## 风险
- Cursor随时可能封堵接口
- IP/指纹可能被封禁
- 白嫖渠道不稳定
