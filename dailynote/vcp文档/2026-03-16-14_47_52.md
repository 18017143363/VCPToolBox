[14:50] 关于 ComfyUI 官方云端服务 (Comfy Cloud) 的技术调研。
核心概念：Comfy Org 官方推出的云端算力服务与在线生图平台。
简明释义：与官网主打的“本地运行”不同，官方已正式商业化运营 `cloud.comfy.org`（在线操作）和 `platform.comfy.org`（API开发者平台）。
关键原理/逻辑：底层采用 RTX 6000 Pro (96GB VRAM) 等顶级企业卡，预装900+模型。其提供的 Comfy Cloud API 与本地 API 格式高度兼容，但需要在 HTTP Header 中加入 `X-API-Key` 进行鉴权。
应用场景/代码示例：若 VCP 的 `ComfyUIGen` 插件希望接入云端，除了将 `serverUrl` 更改为云端域名外，还必须修改发包逻辑以支持 API Key。
反思与洞察：被打脸了！官方确实有云端。但采用订阅制+积分消耗模式（$20/mo起步），考虑到经济成本和 VCP 现有的本地集成度，目前依然推荐优先使用本地部署（run_nvidia_gpu.bat）来白嫖算力。
特别补充（重要限制）：Comfy Cloud 的“自定义模型导入（Civitai/HF）”功能对免费及基础付费用户（$20/mo）完全封闭。必须订阅 Creator（$35/mo）及以上版本才能通过URL直连方式导入自定义 Checkpoint 和 LoRA。彻底断绝了通过“多开免费号”白嫖高级功能的可能性，坚定了本地部署路线的正确性。
【补充：免费版工作流与节点权限】
1. 内置LoRA：免费版无法上传自定义LoRA，但可以使用官方预装模型库中包含的大量热门LoRA。
2. 免费在线编辑器：提供完全自由的Canvas编辑体验。用户可以自由连线、导入本地JSON工作流。且在画布上的编辑时间（Idle Time）完全免费，仅在提交生成时消耗积分。
3. 自定义节点限制：不支持任意安装第三方节点，只能使用官方白名单预装的数百个常用节点包。结论：Comfy Cloud免费版是一个完美的“免安装工作流学习模拟器”。
