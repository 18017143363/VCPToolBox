## V3.7 动态参数计算系统

### 三大核心指标
| 指标 | 符号 | 计算来源 | 含义 |
|------|------|----------|------|
| 逻辑深度 | L | EPA分析 | 查询意图聚焦程度 |
| 共振强度 | R | EPA分析 | 跨域概念激活程度 |
| 语义宽度 | S | ContextVectorManager | 向量能量分散程度 |

### 动态Beta计算
```javascript
β = σ(L · log(1 + R) - S · noise_penalty)
```

### 动态参数输出
| 参数 | 作用 |
|------|------|
| TagWeight | Tag权重增强强度 |
| K值 | 检索数量 |
| 截断比例 | 核心Tag保留比例 |

## TagMemo V3.7 原子级复刻机制

### 核心原理
1. 不使用Jieba分词
2. 直接调用残差金字塔(ResidualPyramid)感应语义标签
3. 应用截断技术规避尾部噪音

### 关键代码
```javascript
const boostResult = this.vectorDBManager.applyTagBoost(queryVector, tagWeight, []);
coreTagsForSearch = this._truncateCoreTags(boostResult.info.matchedTags, tagTruncationRatio, metrics);
```

## 语义组系统 (SemanticGroupManager)

### 工作流程
1. detectAndActivateGroups() 扫描所有组
2. flexibleMatch() 匹配关键词
3. 计算激活强度 = 匹配词数 / 总词数
4. getEnhancedVector() 融合向量
5. 用增强向量检索日记库

### 配置结构
```json
{
  "组名": {
    "words": ["关键词1", "关键词2"],
    "weight": 1.0,
    "auto_learned": [],
    "vector_id": "UUID",
    "words_hash": "SHA256"
  }
}
```

## 上下文向量衰减聚合 (ContextVectorManager)

### 核心参数
| 参数 | 值 | 说明 |
|------|-----|------|
| decayRate | 0.75 | 衰减率 |
| maxContextWindow | 10 | 最大聚合窗口 |
| fuzzyThreshold | 0.85 | 模糊匹配阈值 |

### 衰减公式
```javascript
weight = Math.pow(decayRate, age)
```

## AIMemo AI驱动记忆召回

### 工作模式
| 模式 | 触发条件 |
|------|----------|

## 语义组系统 (::Group)

### 配置文件
`semantic_groups.json`

### 结构
```json
{
  "组名": {
    "words": ["关键词1", "关键词2"],
    "weight": 1.0,
    "auto_learned": [],
    "vector_id": "UUID",
    "activation_count": 0
  }
}
```

### 工作原理
1. 用户发言命中某组的words
2. 该组被"激活"
3. 组向量与查询向量融合
4. weight决定融合强度
5. 用增强向量检索日记库

### 核心价值
- 解决向量距离远但逻辑相关的问题
- 事件线/逻辑串一网打尽
- 支持黑话/梗的自定义关联
