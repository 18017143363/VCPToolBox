## 概述
Comfy Cloud（cloud.comfy.org）是ComfyUI官方云托管服务，免费层400积分/月，仅限Web UI使用。通过逆向其前端API，可在VCPDesktop挂件中直接调用云端GPU生成图片/视频。
## 认证体系
### 双层认证
| 层 | 类型 | 来源 | 有效期 | 用途 |
|---|------|------|--------|------|
| Layer 1 | Authorization: Bearer {JWT} | Firebase Auth (Google OAuth) | ~1小时 | 所有API请求主认证 |
| Layer 2 | Cookie: session={Session JWT} | POST /api/auth/session返回 | 2小时(7200s) | 维持登录态 |
### 认证流程
Google OAuth → Firebase Auth → JWT ID Token → POST /api/auth/session(JWT换Session Cookie) → 后续请求同时带Bearer JWT + Cookie session
### Firebase配置
- 项目ID: dreamboothy
- JWT签名算法: RS256
- JWT payload包含: name, picture, user_id, email, auth_time, iat, exp
## API端点完整清单
### 认证相关
| 端点 | 方法 | 认证 | 请求体 | 响应 |
|------|------|------|--------|------|
| /api/auth/session | POST | Bearer JWT | 无 | {expiresIn:7200, success:true} + Set-Cookie: session=... |
| /api/users | GET | Bearer JWT + Cookie | 无 | {migrated:true, storage:"server"} |
### 工作流提交（核心）
| 端点 | 方法 | 认证 | 说明 |
|------|------|------|------|
| /api/prompt | POST | Bearer JWT + Cookie | 提交生成任务 |
请求体结构：
```json
{
  "client_id": "{uuid}",
  "prompt": {
    "{nodeId}": {
      "inputs": {各节点参数},
      "class_type": "CLIPTextEncode|KSampler|SaveImage|...",
      "_meta": {"title": "节点标题"}
    }
  },
  "extra_data": {
    "auth_token_comfy_org": "{JWT再传一次}",
    "extra_pnginfo": {"workflow": {完整工作流元数据}}
  }
}
```
响应：{node_errors:{}, prompt_id:"{uuid}"}
### 任务状态轮询
| 端点 | 方法 | 参数 | 响应 |
|------|------|------|------|
| /api/jobs | GET | status=in_progress,pending&limit=200&offset=0 | {jobs:[{id,status,create_time}], pagination:{...}} |
| /api/jobs | GET | status=completed,failed,cancelled&limit=64&offset=0 | {jobs:[{id,status,execution_start_time,execution_end_time,outputs_count,preview_output:{filename,display_name,mediaType,nodeId,subfolder,type},workflow_id}]} |
### 图片下载
| 端点 | 方法 | 认证 | 响应 |
|------|------|------|------|
| /api/view?filename={hash}.png&subfolder=&type=output | GET | Bearer JWT | 302重定向到CDN签名URL |

## 任务生命周期（实测数据）
```
POST /api/prompt → prompt_id
    ↓ 0s
轮询 GET /api/jobs?status=in_progress,pending → status: "pending"
    ↓ +8.6s
轮询 → status: "in_progress"
    ↓ +14.4s
轮询 GET /api/jobs?status=completed → status: "completed"
    ↓
GET /api/view?filename={hash}.png → 302 → CDN图片
```
总耗时约23秒（排队8.6s + 执行14.4s），轮询间隔约3-5秒

## VCPDesktop挂件调用方案
### 为什么VCPDesktop可以直接调用
Electron的file://协议不属于任何域，发出的请求Origin=null，不触发标准CORS检查。CSP connect-src *进一步解除客户端限制。实测5项全通过。
### 挂件沙箱网络能力
widgetManager.js的buildSandboxCode()只代理document到Shadow DOM，未劫持fetch/WebSocket/window。挂件内可直接使用原生fetch、WebSocket、XMLHttpRequest。
### 通信方案
挂件→Rosa：autoSave创建挂件获得持久化目录 → widgetFS.saveFile()写结果 → Rosa用FileOperator读取
### Shadow DOM事件绑定注意
onclick内联事件在Shadow DOM沙箱中无效，必须使用addEventListener绑定。
