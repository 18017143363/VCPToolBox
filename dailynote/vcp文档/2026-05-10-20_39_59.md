## 插件概述
MailClient是VCP的邮件收发插件，通过IMAP协议收邮件、SMTP协议发邮件。让Agent具备标准邮件通信能力。

## 代码架构

### 配置加载 (loadConfig)
- 读取config.env，解析键值对
- 返回imap/smtp/address/senderName四个配置块
- IMAP和SMTP均默认SSL加密（secure:true）

### IMAP操作层（5个函数）
| 函数 | 功能 | 关键实现 |
|------|------|----------|
| listFolders() | 列出文件夹 | client.list()，返回name/path/specialUse |
| listMails(folder,limit,page) | 列出邮件 | 分页计算基于mailbox.exists倒序，fetch获取envelope/flags/size |
| readMail(uid,folder) | 读取完整邮件 | fetchOne获取source→mailparser.simpleParser解析→自动标记已读 |
| searchMails(query,folder,searchIn,limit) | 搜索邮件 | 支持subject/from/to/body/all五种范围，all用or组合 |
| deleteMail(uid,folder) | 删除邮件 | 标记\\Deleted + expunge |

### IMAP连接模式
- **每次调用都新建连接**：createImapClient() → connect → 操作 → logout
- 不保持长连接（synchronous插件特性决定）
- 使用getMailboxLock()获取邮箱锁，操作完毕在finally中释放

### SMTP操作层（1个函数）
sendMail(to, subject, body, options)
- 创建nodemailer transporter
- 支持text/html两种格式（isHtml参数控制）
- 支持cc/bcc抄送密送
- **CID内嵌图片功能**：
  - options.attachments传入文件路径（逗号分隔字符串或数组）
  - 图片文件（.png/.jpg/.jpeg/.gif/.webp/.bmp）在HTML邮件中自动CID内嵌
  - CID格式：`img{N}@rosahpy`
  - HTML中用 `{*2cid:N}}` 占位符引用，自动替换为 `cid:imgN@rosahpy`
  - 非图片文件作为普通附件
  - 纯文本邮件中所有文件均作为普通附件

### 命令路由 (processCommand)
接收params对象，通过params.command路由到对应函数。

### stdio入口
标准VCP同步插件模式：stdin读取JSON → processCommand → stdout输出JSON
输出格式：`{ status: "success", result: {...} }` 或 `{ status: "error", error: "..." }`

## 开发踩坑记录

### 1. 输出格式不兼容
**现象**: VCP报"did not provide a valid initial JSON response"
**原因**: 初版用 `{success:true, ...}`，VCP期望 `{status:"success", result:...}`
**修复**: 改为 `console.log(JSON.stringify({status:"success", result:...}))`，错误时 `process.exit(1)`

### 2. PowerShell管道中文乱码
**现象**: 通过PowerShell `echo '...' | node` 测试时，邮件中文全变问号
**原因**: PowerShell默认GBK编码，管道传给node时中文被破坏
**解决**: 走VCP标准工具调用（UTF-8 JSON）则正常

### 3. attachments参数未传递
**现象**: SendMail带attachments但attachmentCount:0
**原因**: processCommand路由中忘记将params.attachments传给sendMail的options
**修复**: options增加 `attachments: params.attachments`

### 4. CID内嵌vs外部URL
**现象**: HTML邮件中用localhost图片URL，手机端无法加载
**原因**: localhost只有本地可访问，邮件客户端在远程服务器渲染
**解决**: 使用CID内嵌，图片编码进邮件MIME体，不依赖外部URL

### 5. 126和163邮箱混淆
**现象**: 配置了imap.126.com但邮箱是@163.com，连接失败
**教训**: IMAP/SMTP Host必须与邮箱后缀匹配
