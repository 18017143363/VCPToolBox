```python
        if state.get("think_open"):
            return chunk_with_content("\n\n")
        return None
    
    # output_text.delta前自动关闭think标签
    if evt_type == "response.output_text.delta":
        if state.get("think_open"):
            out_parts.append(THINK_CLOSE + "\n\n")  # 
            state["think_open"] = False
        out_parts.append(delta_text)
        return chunk_with_content("".join(out_parts))
```

## SSE事件类型清单（Responses API发送的reasoning事件）
- `response.reasoning_summary_part.added` — 新summary part开始（多段时插入分隔）
- `response.reasoning_summary_text.delta` — summary文本增量
- `response.reasoning_summary_text.done` — 单段结束
- `response.reasoning_summary_part.done` — 单part结束
- `response.output_text.delta` — 正式回答开始（这里自动闭合think标签）

## 关键设计决策

1. **`...`标签格式**：标准XML-like，主流客户端（Cherry Studio/ChatBox等）能识别并渲染成可折叠思维链
2. **state字典跨event维持状态**：think_open标志确保多个delta事件不重复发`` open；output_text.delta时自动闭合
3. **流式输出含\n\n分隔**：从think到回答之间空两行，视觉上分隔清晰
4. **非流式同样处理**：用final_content变量统一构造，保证两种模式输出格式一致
