[13:19] Dedalus Labs `openai/gpt-5.4` 联网能力实测：Chat Completions 与 Responses 路径差异

## 背景
主人要求测试 Dedalus Labs 上游在两个路径中使用 `gpt-5.4` 开启联网能力：
- `POST https://api.dedaluslabs.ai/v1/chat/completions`
- `POST https://api.dedaluslabs.ai/v1/responses`

模型名使用 provider 前缀：
```text
openai/gpt-5.4
```

## 关键结论
`openai/gpt-5.4` 可以在 Dedalus 上成功联网，但必须走：
```text
/v1/responses + tools:[{type:"web_search_preview"}]
```

`/v1/chat/completions` 路径不支持直接传入 `web_search_options` 或 `search_parameters` 来联网。

## 实测 1：Chat Completions + web_search_options
请求路径：
```text
POST /v1/chat/completions
```

请求体核心：
```json
{
  "model": "openai/gpt-5.4",
  "messages": [
    {"role": "system", "content": "You are a concise web-enabled assistant. If browsing/search is available, use it."},
    {"role": "user", "content": "Use web search if available..."}
  ],
  "web_search_options": {
    "search_context_size": "low"
  },
  "max_tokens": 512,
  "stream": false
}
```

真实结果：
```text
HTTP_STATUS=400
```

错误体核心：
```json
{
  "detail": {
    "error": {
      "message": "Error code: 400 - {'error': {'message': \"Unknown parameter: 'web_search_options'.\", 'type': 'invalid_request_error', 'param': 'web_search_options', 'code': 'unknown_parameter'}}",
      "type": "provider_error"
    }
  }
}
```

结论：
Dedalus Chat Completions 路径会将 `web_search_options` 传给 OpenAI provider，但该 provider 在 Chat Completions schema 下不接受此字段。

## 实测 2：Responses + web_search_preview
请求路径：
```text
POST /v1/responses
```

请求体核心：
```json
{
  "model": "openai/gpt-5.4",
  "input": "Use web search if available. What is one very recent AI model or API update from May 2026? Cite the source or mention search evidence if you used browsing. Keep it short.",
  "tools": [
    {"type": "web_search_preview"}
  ],
  "tool_choice": "auto",
  "max_output_tokens": 512,
  "stream": false
}
```

真实结果：
```text
HTTP_STATUS=200
```

响应模型：
```json
"model": "gpt-5.4-2026-03-05"
```

联网证据：
响应 `output` 中出现真实搜索调用：
```json
{
  "type": "web_search_call",
  "status": "completed",
  "action": {
    "type": "search",
    "query": "site:openai.com May 2026 AI model API update OpenAI May 2026",
    "queries": [
      "site:openai.com May 2026 AI model API update OpenAI May 2026",
      "site:openai.com index May 2026 API update model release",
      "site:anthropic.com May 2026 model update API release"
    ],
    "sources": null
  }
}
```

引用证据：
最终 message 的 `content.annotations` 中出现：
```json
{
  "type": "url_citation",
  "title": "Advancing voice intelligence with new models in the API | OpenAI",
  "url": "https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/?utm_source=openai"
}
```

最终回答内容提到：
```text
May 7, 2026 OpenAI announced new voice models in the API, including GPT‑Realtime‑2 and GPT‑Realtime‑Translate.
```

使用量：
```json
{
  "input_tokens": 8568,
  "output_tokens": 184,
  "output_tokens_details": {
    "reasoning_tokens": 96
  },
  "total_tokens": 8752
}
```

结论：
Dedalus `/v1/responses` 对 `openai/gpt-5.4` 的 `web_search_preview` 工具支持成功，是真联网。

## 实测 3：Chat Completions + search_parameters
请求路径：
```text
POST /v1/chat/completions
```

请求体核心：
```json
{
  "model": "openai/gpt-5.4",
  "messages": [{"role": "user", "content": "..."}],
  "search_parameters": {
    "mode": "auto",
    "return_citations": true
  },
  "max_tokens": 512,
  "stream": false
}
```

真实结果：
```text
HTTP_STATUS=400
```

错误体核心：
```json
{
  "detail": {
    "error": {
      "message": "Unsupported fields for provider list ['openai']: search_parameters. These fields are not supported by any provider in the model list.",
      "type": "api_error",
      "code": "unsupported_provider_field",
      "request_id": "019e11a9f8d3075a0bd1322f25659874f"
    }
  }
}
```

结论：
`search_parameters` 被 Dedalus schema/provider 字段白名单拒绝，不适合 OpenAI provider。

## 实测 4：Responses + web_search_options
请求路径：
```text
POST /v1/responses
```

请求体核心：
```json
{
  "model": "openai/gpt-5.4",
  "input": "...",
  "web_search_options": {
    "search_context_size": "low"
  },
  "max_output_tokens": 512,
  "stream": false
}
```

真实结果：
```text
curl: (56) Failure when receiving data from the peer
HTTP_STATUS=000
```

没有响应头和业务错误体，因此不能作为字段非法或字段支持的直接证据。

## 推荐可用 payload
```json
{
  "model": "openai/gpt-5.4",
  "input": "Search the web and summarize the latest OpenAI API update in May 2026. Cite sources.",
  "tools": [
    {
      "type": "web_search_preview",
      "search_context_size": "medium"
    }
  ],
  "tool_choice": "auto",
  "max_output_tokens": 1024,
  "stream": false
}
```

## 对代理开发的建议
如果要让 NewAPI、酒馆或本地 Dedalus proxy 暴露“gpt-5.4 联网”能力，不建议在 `/v1/chat/completions` 直传联网字段。推荐做转换层：

```text
OpenAI Chat Completions 外壳
→ 检测联网开关
→ messages 转 input
→ 联网开关转 tools:[{type:"web_search_preview"}]
→ 调 Dedalus /v1/responses
→ 将 responses output_text/message content 还原为 chat.completion
```

## 关联知识
- Dedalus Labs `/v1/responses` 路径比 `/v1/chat/completions` 更接近 OpenAI Responses API 原生能力。
- OpenAI provider 的 `web_search_preview` 工具在 Responses 路径可用。
- `web_search_options` 在 Chat Completions 路径触发 provider unknown parameter。
- `search_parameters` 在 Dedalus 层触发 unsupported_provider_field，可能更偏 xAI/Grok provider 风格，不适用于 OpenAI provider。
