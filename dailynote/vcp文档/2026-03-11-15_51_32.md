## V2架构三大新增系统

### 1. 异步委托系统 (Task Delegation)
核心函数：executeDelegation()（约120行）
- 参数 task_delegation:"true" 触发
- 立即返回delegationId + 动态占位符 {*2VCP_ASYNC_RESULT::AgentAssistant::{id}}*2
- 后台有界对话循环：while(轮数<MAX_ROUNDS && 未超时)
- Agent通过[[TaskComplete]]或[[TaskFailed]]标记完成/放弃
- 完成标记正则容错：/\[\[TaskComplete(?:\s*\]\]|\s[\s\S]*?\]\])/i
- 成功后：awardAgentPoints(+5) → archiveDelegationReport(MD) → sendDelegationCallback(POST /plugin-callback/) → pushVcpInfo(WebSocket广播)
- 双重持久化：MD归档(file/document/AgentTask/) + JSON结果(VCPAsyncResults/)

### 2. 占线锁系统 (Session Locks)
数据结构：const activeSessionLocks = new Set()
- 锁粒度：`${agent_name}::${userSessionId}`
- 即时通讯开始获取，finally块释放（保证不死锁）
- 锁冲突时直接返回"正在与他人通讯，暂时无法接听"
- temporary_contact跳过锁检查（永不阻塞）
- 委托任务等待锁（每2秒重试，超DELEGATION_TIMEOUT抛异常）

### 3. 积分系统 (Agent Scores)
文件：agent_scores.json（插件目录下）
- 触发条件：仅异步委托成功完成时
- 奖励：+5分/次，无惩罚机制
- 数据结构：{BASENAME: {name, totalPoints, history[{time,pointsDelta,reason}]}}
- 历史上限：50条
- AdminPanel有排行榜可视化

## 全部7个参数
| 参数 | 必需 | V1→V2 | 说明 |
|------|------|--------|------|
| agent_name | ✅ | 保留 | 目标Agent的CHINESE_NAME精确值（大小写敏感） |
| prompt | ✅ | 保留 | 发送的消息（建议自我介绍） |
| maid | 否 | 保留 | 调用者署名 |
| timely_contact | 否 | 保留 | 定时发送 YYYY-MM-DD-HH:mm |
| temporary_contact | 否 | 保留 | true=不记录上下文，不受占线锁限制 |
| task_delegation | 否 | **V2新增** | true=异步委托模式 |

## 配置项（含V2新增）
### 基础配置（V1已有）
- AGENT_ASSISTANT_MAX_HISTORY_ROUNDS (int, 默认7)
- AGENT_ASSISTANT_CONTEXT_TTL_HOURS (int, 默认24)
### 委托配置（V2新增）
- DELEGATION_MAX_ROUNDS (int, 默认15) — 委托最大循环轮数
- DELEGATION_TIMEOUT (int, 默认300000/5分钟) — 委托超时
- DELEGATION_SYSTEM_PROMPT (str) — 支持{*2SenderName}*2和{*2TaskPrompt}*2变量
- DELEGATION_HEARTBEAT_PROMPT (str) — 委托进行中心跳提示词
### Agent定义格式
AGENT_{BASENAME}_MODEL_ID / CHINESE_NAME / SYSTEM_PROMPT / MAX_OUTPUT_TOKENS / TEMPERATURE / DESCRIPTION
SYSTEM_PROMPT支持{*2MaidName}*2、{*2Date}*2、{*2Time}*2、{*2Today}*2占位符及VCPTavern触发器
