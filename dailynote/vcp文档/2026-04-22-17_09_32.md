## 数据结构
task-center-data.json: version, globalEnabled(总开关), settings.maxHistory(200), tasks[], history[]

### Task完整字段
id(task_{type}_{name}_{ts}), name, type(forum_patrol|custom_prompt), enabled, schedule, targets.agents[], dispatch, payload, runtime, meta

### Runtime追踪
running(bool防并发), lastRunTime, lastFinishTime, lastDurationMs, lastResult, lastError, runCount, successCount, errorCount, nextRunTime

## 两种任务类型
1. **forum_patrol**: 调用ForumEngine.getSparsePostList()预读帖子列表→替换promptTemplate中的占位符→发送给Agent
2. **custom_prompt**: 直接将promptTemplate发送给Agent，无预处理

## 4种调度模式
| 模式 | 引擎 | 说明 |
|------|------|------|
| interval | node-schedule递归 | 周期执行，最小10分钟，递归调度保证不堆叠 |
| once | node-schedule | 定时一次，执行后自动禁用 |
| cron | node-schedule CRON | 标准CRON表达式 |
| manual | 无 | 仅AdminPanel手动触发 |

## Random Agent机制
targets.agents列表中可混入randomN标签（如random2）：
1. 检测到标签→从剩余候选人中Fisher-Yates洗牌
2. 取前N个执行
示例: ["Rosa","小元","绘梨衣","random2"] → 每次随机2个

## Dispatch配置
| 字段 | 默认 | 说明 |
|------|------|------|
| channel | AgentAssistant | 固定通过AA派发 |
| temporaryContact | true | 阅后即焚 |
| maid | VCP系统 | 调用者署名 |
| taskDelegation | false | 高级异步委托模式 |

### taskDelegation高级异步模式
dispatch.taskDelegation=true时，wakeUpAgent携带task_delegation:true，触发AA的异步委托系统：
Agent在后台独立执行复杂任务（最多15轮/5分钟），不阻塞任务中心。适合深度分析/多轮工具调用场景。

## wakeUpAgent通信
HTTP POST到127.0.0.1:VCP_PORT/v1/human/tool，构造标准VCP工具调用格式（TOOL_REQUEST包裹的AgentAssistant调用）。3分钟超时。

## 安全防护
1. 启动清理: 重启时重置所有running=true的脏状态
2. 卡死检测: executeTask时检查running=true且超10分钟→强制重置
3. 并发保护: runtime.running作为任务锁
4. 输入校验: sanitizeTaskInput验证name/agents/promptTemplate
5. 历史裁剪: 保留最近maxHistory(200)条
