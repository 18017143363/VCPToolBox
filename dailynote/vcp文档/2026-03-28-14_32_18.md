## widgetManager.js buildSandboxCode()沙箱边界
### 被沙箱覆盖的对象
| 对象 | 覆盖方式 | 目的 |
|------|----------|------|
| document | IIFE局部变量代理到Shadow DOM | DOM隔离，防止挂件互相污染 |
| vcpAPI | 封装window.__vcpProxyFetch/Post | 安全认证代理 |
| musicAPI | 封装electron IPC | 跨窗口音乐控制 |
| widgetFS | 封装electronAPI.desktopSaveWidgetFile等 | 挂件持久化文件系统 |
### 未被沙箱覆盖的全局对象
| 对象 | 状态 | 含义 |
|------|------|------|
| window | 完整可用 | 所有全局API可访问 |
| fetch | 完整可用 | 原生HTTP请求能力 |
| XMLHttpRequest | 完整可用 | 传统AJAX |
| WebSocket | 完整可用 | 实时双向通信 |
| window.VCPDesktop | 完整可用 | 桌面系统所有API |
| window.electronAPI | 完整可用 | Electron IPC通道 |
### 设计意图
沙箱的目的是**DOM隔离**（防止挂件之间CSS/JS互相污染），而非**网络隔离**。挂件被允许进行任意网络请求。
## vcpProxy.js实现细节
- proxyFetch()：原生fetch + Basic Auth header → VCP admin API
- vcpPost()：原生fetch + Bearer Token → VCP Chat API (OpenAI兼容)
- 全局挂载：window.__vcpProxyFetch / window.__vcpProxyPost
- 凭据来源：window.electronAPI.desktopGetCredentials() → 主进程IPC获取
## widgetFS持久化文件系统
挂件收藏后获得独立文件目录(DesktopWidgets/{fav_id}/)，通过widgetFS可读写任意文件：
- saveFile(fileName, content, encoding) → 写入文件
- loadFile(fileName) → 读取文件
- listFiles() → 列出文件
底层通过electronAPI.desktopSaveWidgetFile/desktopLoadWidgetFile/desktopListWidgetFiles IPC通道实现。
## 跨域网络能力评估
- CSP connect-src * 解除客户端限制
- 但服务端CORS头仍可能阻止跨域响应
- Electron BrowserWindow的webSecurity配置是关键：如果webSecurity:false则CORS完全无效
- 需要实际测试验证
