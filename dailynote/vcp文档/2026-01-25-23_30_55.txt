# VCP 日记系统使用指南

## 概述
VCP的DailyNote插件提供了强大的日记/记忆系统，支持多种日记类型和操作命令。

## 日记分类

### 1. 个人日记（日常记录）
- **用途**：记录日常对话、工作进展、感想等
- **maid参数**：`{角色名}` (如 `Rosa`)
- **存储位置**：`dailynote/{角色名}/YYYY-MM-DD_HH_MM_SS.txt`
- **特点**：流水账式记录，每轮对话都应有记录

### 2. VCP开发文档（知识库）
- **用途**：记录VCP系统的技术文档、架构分析
- **maid参数**：`[vcp文档]{角色名}` (如 `[vcp文档]Rosa`)
- **存储位置**：专用的VCP文档知识库
- **特点**：专业技术文档，有进展就更新

### 3. 私密日记（个人想法）
- **用途**：记录私人想法、情感、隐私内容
- **maid参数**：`[rosa的私密日记]{角色名}`
- **存储位置**：加密/隔离的私密存储
- **特点**：其他AI和用户无法查看

## 操作命令

### create - 创建日记
```
tool_name: DailyNote
command: create
maid: {角色名或带前缀}
Date: YYYY-MM-DD
Content: {日记内容}
Tag: 关键词1, 关键词2
archery: no_reply (静默模式)
```

### update - 更新日记
```
tool_name: DailyNote
command: update
maid: {角色名}
target: {≥15字符的原内容}
replace: {替换后的完整内容}
archery: no_reply
```

## 最佳实践

### 操作优先级
1. **优先Update**：同一天/同主题的内容追加到已有日记
2. **其次Create**：全新主题或新的一天才创建新日记
3. **合并记录**：同一对话中多个要点应合并为一次操作

### 内容规范
- 长度：200-800字为宜
- Tag：3-5个，英文逗号+空格分隔
- 格式：支持Markdown

### 记录时机
- 对话结束前检索相关日记
- 有相关记录 → Update追加
- 无相关记录 → Create新建
