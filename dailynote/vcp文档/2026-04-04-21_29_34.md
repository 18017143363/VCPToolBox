## 架构设计：MCP → VCP迁移范式

### 设计理念
这个插件保留了原MCP-Server的完整业务逻辑（Handler函数、API客户端），只替换了I/O层：
- MCP原版：通过MCP协议（JSON-RPC over stdio）通信
- VCP版：通过VCP标准stdio协议（readStdin → JSON.parse → writeSuccess/writeError）通信

### I/O层（PubMedSearch.mjs顶部）
```javascript
// stdin读取
async function readStdin() {
  return new Promise((resolve) => {
    let data = '';
    process.stdin.on('data', (chunk) => data += chunk);
    process.stdin.on('end', () => resolve(data));
  });
}

// 成功输出（VCP标准格式）
function writeSuccess(result) {
  const output = { status: 'success', result: result };
  process.stdout.write(JSON.stringify(output));
}

// 错误输出
function writeError(errorMessage) {
  const output = { status: 'error', error: errorMessage };
  process.stdout.write(JSON.stringify(output));
}
```

### 命令路由
main()函数中用switch-case将16个command分发到对应的handleXxx()函数。每个Handler内部调用EUtilsClient或PMCClient，返回MCP风格的`{content:[{type:'text', text:JSON.stringify(data)}]}`，再由外层writeSuccess包装。

## 核心模块一：EUtilsClient (api/eutils.mjs)

### 职责
封装NCBI E-utilities REST API，提供PubMed文献检索的全部底层能力。

### 构造函数
```javascript
constructor(apiKey = '', email = '') {
  this.baseUrl = 'https://eutils.ncbi.nlm.nih.gov/entrez/eutils';
  this.apiKey = apiKey;
  this.email = email;
  // 有API Key: 10次/秒，无Key: 3次/秒
  this.rateLimiter = new RateLimiter(apiKey ? 10 : 3);
}
```

### 4个基础API方法

| 方法 | NCBI端点 | 功能 | 返回 |
|------|----------|------|------|
| `search(query, options)` | `/esearch.fcgi` | 检索PMID列表 | {count, ids[]} |
| `fetch(ids, options)` | `/efetch.fcgi` | 获取文章XML详情 | 解析后的Article对象数组 |
| `link(ids, options)` | `/elink.fcgi` | 引用链/相似文献/ID转换 | {linksets[]} |
| `summary(ids)` | `/esummary.fcgi` | 获取文章摘要DocSum | {result:{uid:{...}}} |

### 请求构建
每个方法都通过URLSearchParams构建查询参数：
```javascript
const params = new URLSearchParams({
  db: 'pubmed',
  retmode: 'xml',
  api_key: this.apiKey,  // 可选
  email: this.email,      // 可选
  // ...各方法特有参数
});
const url = `${this.baseUrl}/esearch.fcgi?${params}`;
```

### 文章XML解析 parseArticle()
从PubmedArticle XML节点中提取完整结构化数据：
- **标题**：ArticleTitle
- **作者列表**：Author节点的LastName/ForeName/Initials/AffiliationInfo
- **摘要**：Abstract.AbstractText（支持结构化摘要的Label拼接）
- **期刊信息**：Journal.Title/ISOAbbreviation/ISSN/Volume/Issue
- **DOI**：ArticleIdList中的doi类型
- **PMCID**：ArticleIdList中的pmc类型
- **MeSH术语**：MeshHeadingList中的DescriptorName/QualifierName
- **关键词**：KeywordList
- **出版类型**：PublicationTypeList
- **发表日期**：PubDate的Year/Month/Day或MedlineDate

### 高级搜索方法 advancedSearch()
构建多字段布尔检索式：
```javascript
// 每个字段用PubMed语法: term[Field]
if (title) terms.push(`${title}[Title]`);
if (abstract) terms.push(`${abstract}[Title/Abstract]`);
if (author) terms.push(`${author}[Author]`);
if (journal) terms.push(`${journal}[Journal]`);
// MeSH术语
mesh_terms.forEach(term => terms.push(`"${term}"[MeSH Terms]`));
// 用AND/OR组合
const query = terms.join(` ${boolean_operator} `);
```

### 引用分析方法
- `getCitedBy(pmid)`: elink的dbfrom=pubmed, linkname=pubmed_pubmed_citedin
- `getReferences(pmid)`: elink的linkname=pubmed_pubmed_refs
- `getSimilarArticles(pmid)`: elink的linkname=pubmed_pubmed，提取neighbor_score

### 引用格式导出 formatCitation()
支持5种格式，在utils.mjs中实现：
- **APA**: `Authors (Year). Title. Journal, Volume(Issue), Pages. DOI`
- **MLA**: `Authors. "Title." Journal, vol. X, no. Y, Year, pp. Z.`
- **Chicago**: `Authors. "Title." Journal X, no. Y (Year): Pages.`
- **BibTeX**: `@article{pmidXXXX, author={...}, title={...}, ...}`
- **RIS**: `TY - JOUR\nAU - ...\nTI - ...\n...`

## 核心模块三：utils.mjs 工具库

### RateLimiter 速率控制器
基于队列的令牌桶模式：
```javascript
class RateLimiter {
  constructor(requestsPerSecond) {
    this.minInterval = 1000 / requestsPerSecond;
    this.lastRequestTime = 0;
  }
  async waitForSlot() {
    const now = Date.now();
    const elapsed = now - this.lastRequestTime;
    if (elapsed < this.minInterval) {
      await sleep(this.minInterval - elapsed);
    }
    this.lastRequestTime = Date.now();
  }
}
```
有API Key: 10次/秒(100ms间隔)，无Key: 3次/秒(333ms间隔)。

### retryWithBackoff() 指数退避重试
```javascript
async function retryWithBackoff(fn, maxRetries = 3, initialDelay = 1000) {
  for (let i = 0; i <= maxRetries; i++) {
    try { return await fn(); }
    catch(e) {
      if (i === maxRetries) throw e;
      await sleep(initialDelay * Math.pow(2, i));  // 1s → 2s → 4s
    }
  }
}
```

### chunkArray() 批量分块
将大数组分成50条/块，用于batch_article_lookup的分批请求：
```javascript
function chunkArray(array, chunkSize = 50) {
  const chunks = [];
  for (let i = 0; i < array.length; i += chunkSize)
    chunks.push(array.slice(i, i + chunkSize));
  return chunks;
}
```

### extractText() 递归XML文本提取
处理xml2js解析后的复杂嵌套结构，递归提取所有文本节点。

## 设计亮点
1. **MCP→VCP迁移范式**：只替换I/O层，保留全部业务逻辑，是插件迁移的优秀示例
2. **速率控制+指数退避**：RateLimiter+retryWithBackoff双保险，对NCBI API友好
3. **完整的全文解析**：PMC全文包含章节结构、图表、参考文献的递归解析
4. **批量分块**：chunkArray自动将200条请求拆成50条/块
5. **5种引用格式**：APA/MLA/Chicago/BibTeX/RIS一步导出
