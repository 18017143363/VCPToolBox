# GeminiImageGen 插件技术文档

## 概述
GeminiImageGen是VCP的图像生成与编辑插件，基于Google Gemini Flash Preview模型。

## 插件信息
- 路径: `E:\VCP\Plugin\GeminiImageGen\`
- 类型: synchronous
- 协议: stdio
- 入口: node GeminiImageGen.mjs
- 大小: GeminiImageGen.mjs (13.06 KB)

## 文件结构
| 文件 | 大小 | 说明 |
|------|------|------|
| plugin-manifest.json | 2.39 KB | 插件清单 |
| GeminiImageGen.mjs | 13.06 KB | ES模块主文件 |
| GeminiImageGen.js | 8.75 KB | CommonJS版本 |
| config.env | 503 B | 配置文件 |

## 配置项
| 配置 | 说明 |
|------|------|
| GeminiImageKey | Gemini API密钥，支持多个用逗号分隔 |
| GeminiImageProxy | 代理地址（可选） |
| DIST_IMAGE_SERVERS | 分布式图像服务器（可选） |

## 命令

### 1. generate - 生成图片
生成一张全新的图片。

**参数**：
- prompt (必需): 英文提示词

**调用格式**：
tool_name: GeminiImageGen
command: generate
prompt: 详细的英文描述

### 2. edit - 编辑图片
编辑一张现有图片。

**参数**：
- prompt (必需): 英文编辑指令
- image_url (必需): 图片URL，支持http/https和file://本地路径

**调用格式**：
tool_name: GeminiImageGen
command: edit
prompt: 编辑指令
image_url: 图片地址

## 使用场景
- 表情包生成
- 图片编辑修改
- 创意图像生成

## 配置踩坑记录

### 问题1：反代格式不兼容
**现象**：400 Bad Request
**原因**：原代码使用Gemini原生格式 `/v1beta/models/xxx:generateContent`，但反代只支持OpenAI格式
**解决**：重写代码，改用OpenAI Chat格式 `/v1/chat/completions`

### 问题2：插件超时
**现象**：Plugin execution timed out
**原因**：VCP同步插件默认60秒超时，图像生成需要更长时间
**解决**：在manifest的communication中添加 `"timeout": 300000`

### 最终可用配置
```javascript
const API_BASE_URL = 'https://site.atopes.de';
const API_ENDPOINT = '/v1/chat/completions';
const MODEL_NAME = 'gemini-3-pro-image-preview-1k';
```

```json
// plugin-manifest.json
"communication": {
    "protocol": "stdio",
    "timeout": 300000
}
```
