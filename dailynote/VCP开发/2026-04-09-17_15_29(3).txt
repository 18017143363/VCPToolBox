## 一、与CLIProxyAPI的根本差异

| | CLIProxyAPI | Sub2API |
|---|---|---|
| 实现 | `tls.HelloChrome_Auto` | **自定义ClientHello规格** |
| JA3 | Chrome通用指纹 | **Node.js 24.x精确指纹** |
| 可配置 | 无 | **数据库存储+管理面板CRUD+每账号绑定** |
| 代理 | 无（直连） | **Direct/HTTP Proxy/SOCKS5** |

CLIProxyAPI的注释说"Chrome's TLS fingerprint is closer to Node.js/OpenSSL"——但"close to"和"identical"完全不同。Sub2API直接从Node.js 24.x抓包构建精确指纹。

## 二、Profile数据结构

```go
type Profile struct {
    Name                string     // Profile名称
    CipherSuites        []uint16   // 密码套件列表（空=内置默认）
    Curves              []uint16   // 椭圆曲线（空=内置默认）
    PointFormats        []uint16   // 点格式
    EnableGREASE        bool       // 是否启用GREASE
    SignatureAlgorithms []uint16   // 签名算法
    ALPNProtocols       []string   // ALPN协议列表
    SupportedVersions   []uint16   // 支持的TLS版本
    KeyShareGroups      []uint16   // Key Share组
    PSKModes            []uint16   // PSK模式
    Extensions          []uint16   // 扩展ID列表（精确顺序）
}
```

**所有slice字段为空时使用内置默认值**——这意味着只需要创建一个空Profile就能获得Node.js 24.x默认指纹。

**ECH GREASE**（65037）：Node.js在没有真实ECHConfig时发送GREASE ECH随机载荷。Sub2API用`GREASEEncryptedClientHelloExtension`模拟。

### ALPN
```go
alpnProtocols := []string{"http/1.1"}  // 注意：不是h2！
```
Node.js默认ALPN是`http/1.1`，而Chrome默认是`h2, http/1.1`。这是JA3指纹差异的关键因素之一。

## 四、buildClientHelloSpecFromProfile()——核心构建函数

```go
func buildClientHelloSpecFromProfile(profile *Profile) *utls.ClientHelloSpec {
    // 1. 解析所有参数（profile覆盖 or 内置默认）
    cipherSuites := defaultCipherSuites
    if profile != nil && len(profile.CipherSuites) > 0 {
        cipherSuites = profile.CipherSuites
    }
    // ...其他参数同理
    
    // 2. 按Extension顺序构建TLS扩展列表
    extensions := []utls.TLSExtension{}
    for _, id := range extOrder {
        if isGREASEValue(id) {
            extensions = append(extensions, &utls.UtlsGREASEExtension{})
            continue
        }
        switch id {
        case 0:  extensions = append(extensions, &utls.SNIExtension{})
        case 10: extensions = append(extensions, &utls.SupportedCurvesExtension{Curves: curves})
        case 13: extensions = append(extensions, &utls.SignatureAlgorithmsExtension{...})
        case 16: extensions = append(extensions, &utls.ALPNExtension{AlpnProtocols: alpnProtocols})
        case 0xfe0d: extensions = append(extensions, &utls.GREASEEncryptedClientHelloExtension{})
        // ... 14种extension的精确映射
        default: extensions = append(extensions, &utls.GenericExtension{Id: id})
        }
    }
    
    // 3. GREASE包裹（如果启用且使用默认extension顺序）
    if enableGREASE && usingDefaultOrder {
        extensions = prepend(UtlsGREASEExtension, extensions)
        extensions = append(extensions, UtlsGREASEExtension)
    }
    
    return &utls.ClientHelloSpec{
        CipherSuites:       cipherSuites,
        CompressionMethods: []uint8{0},  // null compression
        Extensions:         extensions,
        TLSVersMax:         utls.VersionTLS13,
        TLSVersMin:         utls.VersionTLS10,
    }
}
```

## 五、三种Dialer实现

### DirectDialer
```
TCP连接 → uTLS握手
baseDialer.DialContext() → performTLSHandshake()
```

### HTTPProxyDialer
```
TCP连接到代理 → CONNECT隧道 → uTLS握手
net.Dialer.DialContext(proxyAddr) → CONNECT请求 → 200 OK → performTLSHandshake()
```
支持Proxy-Authorization（Basic认证）。

### SOCKS5ProxyDialer
```
SOCKS5隧道 → uTLS握手
proxy.SOCKS5().Dial(targetAddr) → performTLSHandshake()
```
支持SOCKS5认证。

### 统一TLS握手函数
```go
func performTLSHandshake(ctx context.Context, conn net.Conn, profile *Profile, addr string) (net.Conn, error) {
    host, _, _ := net.SplitHostPort(addr)
    spec := buildClientHelloSpecFromProfile(profile)
    tlsConn := utls.UClient(conn, &utls.Config{ServerName: host}, utls.HelloCustom)
    tlsConn.ApplyPreset(spec)
    tlsConn.HandshakeContext(ctx)
    return tlsConn, nil
}
```

### 账号绑定解析
```go
func (s *TLSFingerprintProfileService) ResolveTLSProfile(account *Account) *Profile {
    if !account.IsTLSFingerprintEnabled() {
        return nil  // 不启用TLS伪装 → http.Transport使用默认TLS
    }
    id := account.GetTLSFingerprintProfileID()
    if id > 0 {
        return s.GetProfileByID(id)    // 绑定特定Profile
    }
    if id == -1 {
        return s.getRandomProfile()    // 随机选择一个Profile
    }
    // id=0: 使用内置默认Node.js 24.x
    return &Profile{Name: "Built-in Default (Node.js 24.x)"}
}
```

**id=-1随机选择**：从localCache中随机取一个，每次请求可能用不同指纹——高级反检测策略。

### 缓存失效
Redis Pub/Sub通知 → 所有实例刷新本地缓存：
```go
cache.SubscribeUpdates(ctx, func() {
    svc.refreshLocalCache(context.Background())
})
```
