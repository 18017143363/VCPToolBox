## 二、核心功能
| 能力 | 说明 |
|------|------|
| OpenAI兼容 | /v1/models, /v1/chat/completions, /v1/responses, /v1/embeddings |

## 五、本地Docker部署流程
### 前提
- Docker Desktop已安装
- Git已安装
- 有DeepSeek账号
### Step 1: Clone
```bash
cd E:\酒馆部署
git clone https://github.com/CJackHwang/ds2api.git
cd ds2api
```
### Step 2: 创建.env
```env
PORT=5001
DS2API_HOST_PORT=6011
LOG_LEVEL=INFO
DS2API_ADMIN_KEY=147258369plm
DS2API_CONFIG_PATH=/app/config.json
```
### Step 3: 创建config.json
核心字段:
- keys: API访问密钥列表 [147258369plm]
- accounts: DeepSeek账号列表(email/mobile+password) — 当前为空待填
- model_aliases: 模型名映射
- auto_delete.mode: single(请求后删远端会话)
### Step 4: 启动
```bash
cd E:\酒馆部署\ds2api
docker compose up -d
```
### Step 5: 验证
```powershell
irm http://localhost:6011/v1/models  # 应返回12个模型
irm http://localhost:6011/healthz     # 应返回{status:ok}
```
## 六、鉴权模式
| 模式 | 说明 |
|------|------|
| 托管账号模式 | Bearer传入config.keys中的key，服务自动轮询账号 |
| 直通token模式 | 传入token不在config.keys中时，直接作为DeepSeek token使用 |
## 七、并发模型
- 每账号并发 = account_max_inflight(默认2)
- 建议并发值 = 账号数 × 每账号并发
- 等待队列上限 = account_max_queue(默认=建议并发)
- 超出总承载→429 Too Many Requests
