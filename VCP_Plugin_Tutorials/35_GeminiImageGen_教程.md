# ♊ GeminiImageGen (谷歌绘图) 插件小白教程

## 1. 这是什么？
这是谷歌 **Gemini** 模型的绘图插件。
它不仅能**画图**（Generate），还能**修图**（Edit）。
这是其他很多绘图插件做不到的。

## 2. 怎么配置？
你需要 Google Gemini 的 API Key。

打开 `config.env`：
```ini
GeminiImageKey=AIzaSy...
```

## 3. 怎么使用？
**功能一：文生图**
> **你**：画一只飞在天上的猪，戴着礼帽。
> **AI**：(调用 generate) 好的，这是图片。

**功能二：图生图 (修图)**
这是它的杀手锏。你可以给它一张图，让它改。
> **你**：(发一张照片) 帮我在我旁边加一只羊驼。
> **AI**：(调用 edit) 好的，P 好了。

**注意**：修图功能需要你提供图片的 URL（如果是本地图片，配合 FileServer 使用效果最佳）。
