# 🌥️ QwenImageGen (通义绘图) 插件小白教程

## 1. 这是什么？
这是阿里 **通义千问 (Qwen)** 模型的绘图插件。
它的中文理解能力非常强，而且画风比较写实。

## 2. 怎么配置？
你需要 SiliconFlow 的 API Key。
打开 `config.env`：
```ini
SILICONFLOW_API_KEY=sk-xxxxxx
```

## 3. 怎么使用？
**功能一：文生图**
> **你**：画一幅中国山水画，要有意境。
> **AI**：(调用 `GenerateImage`) 好的，请欣赏。

**功能二：图生图 (修图)**
> **你**：(发一张照片) 把这只狗变成一只老虎。
> **AI**：(调用 `EditImage`) 变身成功！

**参数推荐**：
如果你不知道选什么分辨率，就告诉 AI “画个正方形”或者“画个横屏”就行。它支持多种比例（1:1, 16:9, 4:3 等）。
