# 📂 FileOperator (文件大管家) 插件小白教程

## 1. 这是什么？
**这是 VCP 最核心的插件，没有之一。**
你现在看到的这篇教程，就是 AI 使用 **FileOperator** 帮你写进硬盘里的。
它赋予了 AI 对 Windows 文件系统的**完全控制权**。

## 2. 核心能力
它能做几乎所有你在资源管理器里能做的事：
*   **创建/删除** 文件和文件夹
*   **读取/编辑** 文本内容
*   **复制/移动/重命名**
*   **列出目录结构**
*   **搜索文件**

## 3. 怎么使用？
通常你不需要直接命令它，只要你提出需求，AI 会自动调用。

**场景：整理桌面**
> **你**：帮我把 `E:\Downloads` 里所有的图片都移动到 `E:\Photos` 文件夹里。
> **AI**：(列出目录 -> 筛选图片 -> 循环移动) 搞定！已移动 50 张图片。

**场景：写代码**
> **你**：帮我创建一个 Python 项目，包含 main.py 和 requirements.txt。
> **AI**：(创建目录 -> 写入文件) 项目已创建完毕。

**⚠️ 安全警告：**
能力越大，责任越大。请不要让 AI 删除你不确定的系统文件（如 C:\Windows），虽然它通常被限制在 VCP 目录下，但还是要小心！
