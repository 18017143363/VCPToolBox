# 🕵️ SearchEngineTavily (Tavily搜索) 插件小白教程

## 1. 这是什么？
**Tavily** 是一个专门为 **AI Agent** 设计的搜索引擎。
它比 Google 更懂 AI。它不仅能搜到网页，还能自动提取网页里的核心内容，去掉广告和废话，直接喂给 AI。
对于需要做“深度调研”的任务，Tavily 是首选。

## 2. 怎么配置？
1.  去 [tavily.com](https://tavily.com/) 注册（有免费额度）。
2.  打开 `config.env`：
    ```ini
    TAVILY_API_KEY=tvly-xxxxxx
    ```

## 3. 怎么使用？
**场景：深度问答**
> **你**：给我找几家做人形机器人的初创公司，并列出它们的融资情况。
> **AI**：(调用 Tavily) 正在搜索... 正在提取融资数据...
> **AI**：找到了以下 5 家公司：1. Figure AI (融资6.75亿)...

**特点：**
它一次搜索能返回很长的上下文，非常适合需要阅读大量资料的任务。
