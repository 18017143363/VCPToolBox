# 🎨 DoubaoGen (豆包绘图) 插件小白教程

## 1. 这是什么？
这是字节跳动“豆包”大模型的**画图插件**。
如果你觉得部署本地 Stable Diffusion 太难太慢，那用这个插件是最简单的。它是云端生成的，速度快，对电脑配置没要求。

## 2. 怎么配置？
1.  去 [火山引擎](https://www.volcengine.com/) 注册账号。
2.  申请“豆包·文生图”的 API Key。
3.  打开 `config.env` 填入：
    ```ini
    VOLC_ACCESS_KEY=你的AK
    VOLC_SECRET_KEY=你的SK
    ```

## 3. 怎么使用？
直接下令即可。

> **你**：用豆包模型画一只在吃火锅的熊猫。
> **AI**：(调用 API) 正在生成...
> **AI**：画好了！(展示图片链接)

**优点：**
*   **中文理解能力极强**：你不需要像 Stable Diffusion 那样背复杂的英文咒语，直接说中文大白话就行。
*   **速度快**：通常 3-5 秒出图。
