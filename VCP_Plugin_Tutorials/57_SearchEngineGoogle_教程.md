# 🔵 SearchEngineGoogle 插件小白教程

## 1. 这是什么？
这是 `SearchEngine` 的**谷歌分身**。
它是专门用来连接 Google Custom Search API 的组件。

## 2. 教程
**请参考 `36_GoogleSearch_教程.md`。**
本质上它们是同一个东西的不同封装版本。这个版本通常作为 `SearchEngine` 的子模块存在。

## 3. 什么时候用它？
当你明确指定“**必须用谷歌搜**”的时候。
> **你**：用谷歌搜一下这个错误代码，别用百度。
> **AI**：(强制调用 SearchEngineGoogle) 好的。
