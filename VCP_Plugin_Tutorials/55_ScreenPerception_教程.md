# 👁️ ScreenPerception (屏幕感知) 插件小白教程

## 1. 这是什么？
这是 `PyScreenshot` 的升级版。
它不仅能截图，还能**连续感知**。
它可以每隔几秒看一眼你的屏幕，理解你在干什么。

## 2. 怎么使用？
**场景：工作辅助**
> **你**：帮我盯着屏幕，如果那个进度条跑完了（变成 100%），就叫我一声。
> **AI**：(持续监控) ... ... ... 好了！进度条满了！

**场景：上下文理解**
> **你**：我现在看的这个文档，第 3 段说的是什么意思？
> **AI**：(自动看屏幕) 第 3 段是在讲“量子纠缠”，它的意思是...

**注意**：这个插件比较耗资源，不用的时候建议让 AI 停止监控。
