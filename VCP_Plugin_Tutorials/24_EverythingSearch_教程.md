# 🔍 EverythingSearch (光速搜文件) 插件小白教程

## 1. 这是什么？
你用过 Windows 自带的搜索吗？是不是慢得想砸电脑？
这个插件调用了著名的 **Everything** 软件。
它能让 AI 在 **0.1 秒** 内，从你电脑里几百万个文件中找到你想要的那一个。

## 2. 怎么配置？
**前提**：你的电脑上必须安装并运行了 [Everything](https://www.voidtools.com/) 软件。
**设置**：确保 Everything 开启了“HTTP 服务器”功能（在工具 -> 选项 -> HTTP 服务器 中勾选）。

打开 `config.env`：
```ini
EVERYTHING_HOST=127.0.0.1
EVERYTHING_PORT=80  # 默认端口
```

## 3. 怎么使用？
**场景：找回失踪的文件**
> **你**：我不记得把“年度总结.docx”放哪了，帮我找找。
> **AI**：(毫秒级响应) 找到了！它在 `D:\Backup\2025\Old\年度总结.docx`。

**场景：模糊搜索**
> **你**：帮我找找电脑里所有的 MP4 视频，且文件名包含“VCP”的。
> **AI**：搜索到 3 个结果：...

**它是目前最快的文件搜索方案，没有之一。**
