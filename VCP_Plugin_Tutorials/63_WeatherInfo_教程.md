# 🌦️ WeatherInfo (天气预报) 插件小白教程

## 1. 这是什么？
顾名思义，就是查天气的。
它能查**实时天气**，也能查**未来几天的预报**。

## 2. 怎么配置？
你需要一个天气 API Key（推荐 QWeather 和风天气，或 OpenWeatherMap）。
打开 `config.env`：
```ini
WEATHER_API_KEY=你的Key
DEFAULT_CITY=Beijing (默认查哪个城市)
```

## 3. 怎么使用？
**场景：查天气**
> **你**：今天出门要带伞吗？
> **AI**：(查询北京天气) 今天有中雨，建议带伞。

> **你**：上海明天多少度？
> **AI**：上海明天 15-22 度，多云。

**场景：生活建议**
> **你**：这周末适合去洗车吗？
> **AI**：周六周日都是晴天，非常适合洗车。

**小贴士：**
配合 `ScheduleManager`，可以让 AI 每天早上自动发天气预报给你。
