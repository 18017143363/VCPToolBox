# 🌐 ExaSearch (AI专用搜索) 插件小白教程

## 1. 这是什么？
普通的搜索引擎（如百度、谷歌）是给人看的，里面充满了广告和无关信息。
**Exa (原 Metaphor)** 是专门给 AI 用的搜索引擎。
它搜索出来的结果非常纯净，AI 读起来不费劲，所以回答问题的质量会更高。

## 2. 怎么配置？
1.  去 [Exa.ai](https://exa.ai/) 申请一个 API Key（通常有免费额度）。
2.  打开 `config.env` 填入：
    ```ini
    EXA_API_KEY=你的Key
    ```

## 3. 怎么使用？
**场景：复杂问题调研**
> **你**：帮我找几篇关于“Rust 语言在嵌入式开发中的优势”的高质量文章。
> **AI**：(调用 Exa) 这里的搜索结果不是百度那种营销号文章，而是 GitHub 讨论、技术博客、官方文档等干货。

**Exa 的特长：**
它特别擅长找**相似内容**。
比如你给它一篇好文章，让它“找几篇跟这个类似的”，它找得非常准。
