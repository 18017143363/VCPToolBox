# 💡 DMXDoubaoGen (舞台灯光师) 插件小白教程

## 1. 这是什么？
这是一个非常酷炫的**“跨界插件”**。
它把 AI 和 **舞台灯光 (DMX512协议)** 连接了起来。
你可以对 AI 说：“给我来个悲伤的氛围”，AI 就会自动控制你房间里的 DMX 灯光，变成蓝色的、缓慢呼吸的效果。

## 2. 怎么配置？
**硬件要求**：你需要有支持 Art-Net 协议的灯光控制器，或者 USB-DMX 转接器。

**软件配置**：
打开 `config.env`：
```ini
# 你的灯光控制器 IP 地址
DMX_CONTROLLER_IP=192.168.1.50
# 你的豆包大模型 API Key (用于生成灯光参数)
DOUBAO_API_KEY=sk-xxxxxx
```

## 3. 怎么使用？
**场景：氛围控制**
> **你**：我要听摇滚乐，把灯光搞嗨一点！
> **AI**：(调用豆包模型生成红色爆闪的 DMX 信号 -> 发送给灯具)
> **(瞬间，你的房间变成了迪厅)**

> **你**：现在是深夜读书时间。
> **AI**：(调整为暖黄色、低亮度常亮)

**注意：**
这是一个专业插件，如果你家里只有普通吸顶灯，是用不了的哦！
