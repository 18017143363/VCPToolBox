# 🔌 1PanelInfoProvider 插件小白教程

## 1. 这是什么？
想象一下，你的 AI 助手原本是被关在一个“小黑屋”里的，它不知道外面的电脑运行得怎么样。
**1PanelInfoProvider** 就像是在小黑屋上开了一扇窗，让 AI 能够实时看到你服务器的**身体状况**（CPU 忙不忙、内存够不够、硬盘满没满）。

**装了它，AI 就能回答：**
*   “主人，现在的服务器负载有点高，建议稍后再跑大任务。”
*   “报告，硬盘空间只剩 10% 了，请及时清理！”

## 2. 怎么配置？
你需要有一个安装了 **1Panel 面板** 的服务器。

1.  打开文件夹：`E:\VCP\Plugin\1PanelInfoProvider`
2.  找到文件 `config.env.example`，把它复制一份，重命名为 `config.env`。
3.  用记事本打开 `config.env`，修改以下两行：

```ini
# 你的 1Panel 面板地址（记得带 http:// 和端口号）
PanelBaseUrl=http://192.168.1.100:12345

# 你的 API 密钥（在 1Panel 面板设置 -> API 接口 中创建）
PanelApiKey=这里填你复制的一长串密钥
```

4.  保存文件，重启 VCP。

## 3. 怎么使用？
配置好后，你不需要对着 AI 念咒语。你只需要在**角色卡（Agent Profile）**或者**系统提示词**里加入两个神奇的词（变量）：

*   `{{1PanelOsInfo}}` -> 代表系统基础信息（我是 Ubuntu 还是 CentOS？）
*   `{{1PanelDashboard}}` -> 代表实时监控数据（CPU 50%，内存 80%...）

**示例写法：**
> 你是一个服务器运维助手。
> 当前服务器状态：{{1PanelDashboard}}
> 请根据上述状态回答我的问题。

这样，每次你跟 AI 说话时，它都会先看一眼服务器状态，再回你的话！
