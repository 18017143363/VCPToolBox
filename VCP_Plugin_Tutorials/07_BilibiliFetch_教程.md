# 📺 BilibiliFetch (B站字幕提取) 插件小白教程

## 1. 这是什么？
这是一个**“B站课代表”**。
当你给 AI 一个 B 站视频链接时，它能自动把视频里的字幕提取出来，变成文字读一遍。
这样，你让 AI 总结视频内容时，它就不用去“看”视频（这很难），而是直接“读”字幕（这很快）。

## 2. 怎么配置？
如果你要看的视频是公开的，**不需要配置**。
如果你要看**大会员专属**或**需要登录**的视频，你需要配置 Cookie。

1.  打开 `config.env` 文件。
2.  找到 `BILIBILI_COOKIE`。
3.  在浏览器登录 B 站，按 F12 打开开发者工具，找到 Network -> Cookie，把 `SESSDATA=...` 那一长串复制进去。

## 3. 怎么使用？
直接把视频链接扔给 AI 即可。

**场景：视频总结**
> **你**：帮我总结一下这个视频讲了什么：https://www.bilibili.com/video/BV1xxxxxx
> **AI**：(调用插件提取字幕 -> 阅读文字)
