# 🐦 TwitterFetch (推特侦探) 插件小白教程

## 1. 这是什么？
这是一个**只读**插件。
它能让 AI 去 Twitter (X) 上抓取推文。
你可以用它来监控某个博主的动态，或者搜索特定话题的推文。

## 2. 怎么配置？
由于 Twitter API 很贵且限制多，这个插件通常使用**模拟浏览**的方式。
你可能需要配置 Cookie（参考 BilibiliFetch 的方法）。

## 3. 怎么使用？
**场景：监控博主**
> **你**：看看 Elon Musk 最近发了什么推？
> **AI**：(抓取 @elonmusk) 他 1 小时前发了一条关于 SpaceX 的推文...

**场景：话题搜索**
> **你**：搜一下 #AI 这个标签下最近有什么热门讨论。
> **AI**：(搜索话题) 很多人在讨论 GPT-5 的发布日期...

**配合翻译插件：**
它抓下来的英文推文，AI 可以自动翻译成中文给你看。
