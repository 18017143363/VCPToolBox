# 🎨 ZImageGen (综合绘图) 插件小白教程

## 1. 这是什么？
这是 VCP 的**绘图聚合器**。
它就像一个“画图超市”。它后端可以连接 Stable Diffusion、DALL-E 3、Midjourney 等多种引擎。
你只需要对它下令，它会自动选择最适合的模型来画。

## 2. 怎么配置？
打开 `config.env`，填入你拥有的各种 API Key。

## 3. 怎么使用？
**场景：随便画画**
> **你**：画个皮卡丘。
> **AI**：(调用 SDXL Turbo) 咻！画好了（速度快）。

**场景：精细作画**
> **你**：画一个超写实的赛博朋克城市，要 4K 高清，细节丰富。
> **AI**：(调用 DALL-E 3 或 Midjourney) 正在精心绘制...（质量高）。

**它是你的一站式 AI 画廊。**
