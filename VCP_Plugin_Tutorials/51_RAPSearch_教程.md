# 🧠 RAPSearch (思维链搜索) 插件小白教程

## 1. 这是什么？
RAP (Retrieval Augmented Planning) 是一种高级搜索技术。
普通的搜索是：搜 -> 答。
**RAPSearch** 是：搜 -> 思考 -> 发现不够 -> 再搜 -> 再思考 -> 答。
它像一个侦探，通过多轮搜索来解决复杂问题。

## 2. 怎么使用？
**场景：解决难题**
> **你**：分析一下为什么这周的比特币价格会暴跌？
> **AI**：(RAP 启动)
> 1.  先搜“比特币本周价格走势”。
> 2.  发现提到“美联储加息”，于是去搜“美联储最新决议”。
> 3.  发现提到“某交易所被黑”，于是去搜“xxx交易所黑客事件”。
> 4.  **综合回答**：主要是因为加息预期叠加交易所利空...

**优点**：
它不会胡说八道，它的每一个论点都有搜索结果作为证据支撑。
