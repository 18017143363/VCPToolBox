# 🏷️ DailyNoteWrite (智能笔) 插件小白教程

## 1. 这是什么？
这是负责**“落笔”**的插件。
但它不只是简单的“保存文件”，它自带了一个**“AI 标签员”**。
当你让 AI 写日记时，如果 AI 偷懒没写标签（Tag），这个插件会在保存前，自动分析日记内容，补上精准的标签。

**例子：**
*   **日记内容**：“今天研究了鸭货三巨头的财报，发现周黑鸭业绩下滑...”
*   **插件自动补全**：`Tag: 商业分析, 鸭货, 财报, 消费降级`

## 2. 怎么配置？
打开 `E:\VCP\Plugin\DailyNoteWrite\config.env`：

```ini
# 你的日记存成什么格式？(推荐 txt 或 md)
DAILY_NOTE_EXTENSION=txt

# 用哪个 AI 模型来生成标签？(推荐用便宜又快的模型)
TagModel=gemini-2.5-flash-preview

# 标签生成的提示词文件
TagModelPrompt=TagMaster.txt
```

## 3. 怎么使用？
**全自动触发。**
只要任何插件（比如 DailyNote）尝试写入日记，这个插件就会接管。

1.  **自动检测**：它会看最后一行有没有 `Tag: ...`。
2.  **自动修复**：如果有 Tag 但格式乱了（比如用了中文逗号），它会修好。
3.  **自动生成**：如果没有 Tag，它会调用 AI 读一遍日记，生成标签，然后追加到文件末尾。

**为什么这很重要？**
有了这些标签，以后你问 AI：“帮我找找以前关于‘商业分析’的日记”，它就能瞬间找到！
