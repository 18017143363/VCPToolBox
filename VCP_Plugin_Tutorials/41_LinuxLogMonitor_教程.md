# 🚨 LinuxLogMonitor (运维看门狗) 插件小白教程

## 1. 这是什么？
这是一个给**服务器管理员**用的神器。
它能**实时盯着**你服务器上的日志文件（比如 Nginx 日志、系统报错日志）。
一旦出现 `ERROR` 或 `FATAL`，它会立刻通知 AI，AI 再通知你。

## 2. 怎么配置？
配合 `LinuxShellExecutor` 使用。
你需要告诉它监控哪台机器、哪个文件。

## 3. 怎么使用？
**功能一：启动监控**
> **你**：帮我监控 Web 服务器的 `/var/log/nginx/error.log`。
> **AI**：好的，任务已启动。如果发现错误我会叫你。

**功能二：主动查错**
> **你**：查一下数据库服务器最近 1 小时有没有报错。
> **AI**：(调用 `searchLog` 或 `lastErrors`) 发现了 3 条连接超时的错误。

**功能三：日志统计**
> **你**：统计一下今天访问量最高的 10 个 IP。
> **AI**：(调用 `logStats`) 排名第一的是 192.168.1.5...

**有了它，你不用每天自己 SSH 上去 grep 日志了。**
