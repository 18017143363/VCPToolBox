# 📧 EmailSender (邮件助手) 插件小白教程

## 1. 这是什么？
它让 AI 拥有了**发邮件**的能力。
你可以让 AI 帮你写好周报，然后直接发给老板，或者给客户发送节日祝福。

## 2. 怎么配置？
你需要一个支持 SMTP 的邮箱（比如 QQ 邮箱、163 邮箱、Gmail）。

打开 `config.env`：
```ini
# SMTP 服务器地址 (以 QQ 邮箱为例)
SMTP_HOST=smtp.qq.com
SMTP_PORT=465

# 你的邮箱账号
SMTP_USER=123456@qq.com

# 你的邮箱授权码 (注意：不是登录密码！要去邮箱设置里开启 SMTP 获取)
SMTP_PASS=abcdefg123456
```

## 3. 怎么使用？
**场景：发送汇报**
> **你**：帮我给 boss@company.com 发个邮件，标题是“今日工作汇报”，内容是...
> **AI**：正在发送... 发送成功！

**场景：配合其他插件**
> **你**：(配合 Arxiv 插件) 把今天关于 AI 的最新论文列表，整理一下发到我的邮箱里。
> **AI**：好的，已整理 5 篇论文，邮件已发送，请查收。

**安全提示：**
千万不要把你的 `config.env` 发给别人，否则你的邮箱会被盗用！
