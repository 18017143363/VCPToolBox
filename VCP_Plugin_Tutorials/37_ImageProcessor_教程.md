# 👁️ ImageProcessor (全能感官) 插件小白教程

## 1. 这是什么？
这是 AI 的**五官**。
普通的 AI 只能看懂文字。装了这个插件后，AI 就能看懂**图片**、听懂**音频**、看懂**视频**。
当你发一张照片或一段录音给 AI 时，它会先调用这个插件把内容“翻译”成文字描述，然后再进行思考。

## 2. 怎么配置？
打开 `config.env`，你需要配置一个多模态模型（通常使用 OpenAI 的 GPT-4o 或 Google 的 Gemini）。

```ini
API_URL=https://api.openai.com/v1
API_Key=sk-xxxxxx
MultiModalModel=gpt-4o
```

## 3. 怎么使用？
**被动触发，像聊天一样自然。**

**场景一：看图说话**
> **你**：(发送一张猫的照片) 这只猫是什么品种？
> **AI**：(插件后台提取图片信息) 这是一只英短蓝猫。

**场景二：听语音**
> **你**：(发送一段 MP3 录音) 总结一下会议记录。
> **AI**：(插件转录音频) 录音里主要讨论了下个季度的预算问题...

**注意**：处理视频和长音频会消耗较多的 Token 和时间。
