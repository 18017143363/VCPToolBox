# 💻 LinuxShellExecutor (远程指挥官) 插件小白教程

## 1. 这是什么？
它让 AI 变成了**高级运维工程师**。
AI 可以通过 SSH 连接到你的远程 Linux 服务器，执行 Shell 命令。

## 2. 安全机制 (非常重要)
为了防止 AI 删库跑路，这个插件设计了**四级安全防护**：
1.  **Read (只读)**: `ls`, `cat`, `top` 等。AI 可以随便用。
2.  **Safe (安全)**: 一些无害的操作。
3.  **Write (写入)**: `restart service`, `rm file` 等。**需要管理员验证码**。
4.  **Danger (危险)**: 涉及系统核心。**需要二次确认 + 验证码**。

## 3. 怎么使用？
**配置主机：**
在 `hosts.json` 里配置你的服务器 IP 和 SSH 密钥。

**下达指令：**
> **你**：看看 `prod-server` 的 CPU 占用率。
> **AI**：(执行 `top -b -n 1`) 当前 CPU 占用 15%。

> **你**：重启一下 Nginx 服务。
> **AI**：这是一个 Write 级别的操作，请输入验证码 [8848] 以确认。
> **你**：8848
> **AI**：验证通过，服务已重启。

**它还内置了“预设命令”(Preset)，比如一键体检、一键清理缓存，非常方便。**
