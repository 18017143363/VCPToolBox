# 🍌 NanoBananaGenOR (双子绘图) 插件小白教程

## 1. 这是什么？
这是 Google **Gemini 2.5** 模型的绘图插件（通过 OpenRouter 接口调用）。
它的特点是“听得懂人话”。相比于传统的 Stable Diffusion 需要复杂的咒语，它能理解复杂的自然语言描述。

## 2. 怎么配置？
打开 `config.env`，填入你的 OpenRouter API Key：
```ini
OpenRouterKeyImage=sk-or-xxxxxx
```

## 3. 怎么使用？
**功能一：文生图 (Generate)**
> **你**：生成一张图片：夕阳下的山脉，色彩鲜艳，云层壮观。
> **AI**：(调用 `generate`) 好的，这是图片。

**功能二：图生图 (Edit)**
> **你**：(发一张图) 把这图里的天空加上一道彩虹，颜色要更鲜艳一点。
> **AI**：(调用 `edit`) 修改完毕。

**功能三：图片合成 (Compose)**
> **你**：用第一张图的背景，加上第二张图里的人物，合成一张新图。
> **AI**：(调用 `compose`) 正在融合两张图片...

**适合场景**：需要高理解力、逻辑复杂的画面生成。
