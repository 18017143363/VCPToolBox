# 💉 WorkspaceInjector (工作区注入) 插件小白教程

## 1. 这是什么？
这是一个给**程序员**用的高级工具。
当你打开一个代码项目（Workspace）时，这个插件会自动把项目里的**关键信息**（如 `package.json`、`README.md`、目录结构）注入到 AI 的短期记忆里。

## 2. 怎么使用？
**全自动触发。**
只要你在 VCP 里加载了项目文件夹。

**效果：**
你不需要再向 AI 介绍“我这个项目是用什么框架写的”、“依赖了什么库”。
AI 一上来就都知道了。
> **你**：帮我写一个新组件。
> **AI**：好的，我看到你用的是 React + Tailwind，我将遵循这个规范来写代码...

**它大大减少了你跟 AI 解释背景的时间。**
