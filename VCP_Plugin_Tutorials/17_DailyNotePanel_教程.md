# 🖥️ DailyNotePanel (日记面板) 插件小白教程

## 1. 这是什么？
这是一个**“显示器”**。
之前的插件都是在后台默默干活，你看不见。
**DailyNotePanel** 给 VCP 的后台管理界面（Admin Panel）增加了一个**可视化的日记查看页面**。
你可以在浏览器里，像看博客一样浏览 AI 的日记。

## 2. 怎么配置？
**无需配置。**
它是“胶水插件”，只要安装并启用，它就会自动在后台注册路由。

*   **页面地址**：通常是 `http://你的IP:端口/AdminPanel/DailyNotePanel`
*   **API 地址**：`/AdminPanel/dailynote_api`

## 3. 怎么使用？
1.  确保 VCP 正在运行。
2.  打开浏览器，访问你的 VCP 后台地址。
3.  在菜单里找到 **DailyNotePanel**。
4.  **尽情浏览**：你可以按日期筛选，查看某天的详细日记，甚至可以看到 AI 自动打的标签。

**注意：**
如果你打不开页面，请检查 `config.env` 里的端口设置是否正确。
