# 🎨 FluxGen (Flux画图) 插件小白教程

## 1. 这是什么？
**Flux** 是目前最火的开源 AI 绘画模型，画质媲美 Midjourney。
这个插件让你能直接在 VCP 里调用 **Flux.1-schnell** 模型（速度极快版）。

## 2. 怎么配置？
你需要一个 **SiliconFlow (硅基流动)** 的 API Key（国内访问速度快，且通常有免费额度）。

打开 `config.env`：
```ini
SILICONFLOW_API_KEY=sk-xxxxxx
```

## 3. 怎么使用？
直接让 AI 画图。

> **你**：画一只穿着赛博朋克盔甲的猫，站在霓虹灯下的屋顶。
> **AI**：(调用 FluxGen) 正在生成...
> **AI**：![图片](...) 画好了！

**高级参数：**
你可以指定分辨率：
> **你**：画一张竖屏壁纸，分辨率 720x1280。
> **AI**：没问题。

**优点**：生成速度非常快（通常 1-2 秒），而且对你的显卡没要求（云端生成）。
