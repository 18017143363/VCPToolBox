# 🔐 UserAuth (用户认证) 插件小白教程

## 1. 这是什么？
这是 VCP 的**门卫大叔**。
如果你的 VCP 部署在公网上（比如云服务器），你肯定不希望陌生人随便连上来跟你的 AI 聊天。
**UserAuth** 负责管理用户名和密码，确保只有你自己能登录。

## 2. 怎么配置？
打开 `config.env`：
```ini
# 开启认证
AUTH_ENABLED=true
# 设置管理员账号
ADMIN_USER=admin
ADMIN_PASS=your_strong_password
```

## 3. 怎么使用？
**被动生效。**
当你打开 VCP 的网页界面时，会弹出一个登录框。
输入你设置的账号密码才能进入。

**高级功能：**
它还支持多用户管理，你可以给你的朋友也开一个账号，但他只能用你分配给他的功能。
